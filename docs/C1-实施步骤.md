## 2. 论证项（母文档 §5 点名 + 本次补齐）

### 论证 1 — `PaginationCacheStore` 跨平台落盘：做 common 缓存格式

- 数据（`ChapterPaginationTable/PageRecord/fromSlices`，`:27-81`）纯 `Int/Long/List`，零 Android 依赖 → **进 common**。
- 二进制格式（`:89-93` 大端 `MAGIC/VERSION/LAYOUT_VERSION` + `MAX_TABLES_PER_BOOK=32` LRU）是策略 → **进 common**（含 LRU cap/失效语义）。
- `File/DataInput/OutputStream/setLastModified/listFiles` IO 壳 → 按 S18 换 `okio FileSystem/SYSTEM/Buffer/Path/metadata`，目录根由各壳注入（`PlatformIo` 同口径）。`LAYOUT_VERSION=17` 单点失效 choke-point（`:95-100` 文档）保留。
- 结论：**写 common 的缓存格式 + okio IO**，不选“仅 engine-skia 各自落盘”（那会重造双份副本，违反母文档原则）。

### 论证 2 — 增量 path 与共享 `Paginator` 的边界

- 边界线：`Paginator`（common，已共享）拥有**分页规则**（`fillWholeLines/paginateFrom`）；`BoxChapterLayouter.incrementalLayoutForPage`（`:593-749`）拥有**窗口编排**（disk 表定锚 → `blockLo/Hi` 定塑形范围 → `rebuildLocalLines` 建局部流 → 同一 fill 规则重排 → 首尾 edge-snap 保证窗口无缝 tiling，`:674-706` 注释）。
- 可进 common 的：`rebuildLocalLines`（`:754-819`，`consecutiveLeafAdvance` 树感知 collapse 纯几何）、`assembleTempPage`（`:1156-1220`，y 归一化+`contentH` 收尾纯逻辑）、`backfillBlockRanges`（char→block 二分权威映射）、窗口 edge-snap 规则。
- 不可进的：`tempShape/shapeLeaf/shapeBlock` 的 `ParagraphShapes.shapeOf` 调用（StaticLayout 几何生产）。C1-0 先换塑形底座（见 §3 步骤 1），编排再平移，否则把 StaticLayout 依赖带进共享层（母文档 §5 前置警告）。
- `PartialDrawableLayout/PartialSkiaWindow` 的 `skiaLinesSource`（`:646-658`）Q1-b 已恒投影 skia，C1 保留该投影语义，只换塑形输入。

### 论证 3 — TODO「阅读定位不稳定」消化（编排层一起收）

根因（`TODO-未尽事宜.md:5-9`）：(a) 大章临时表 vs 磁盘表 char 定位不一致（临时 block-cut 页存 charStart，重开 disk 表 `pageForChar` 落不同页）；(b) 临时转正 `onBackgroundCanonicalReady` 重锚与 `scheduleSave` 竞态存下旧临时页 char。
收编动作：统一 char 语义为 **canonical 磁盘表权威**（临时页 char 只做显示不持久化；`onSaveProgress` 只接受 canonical slice 或经 `pageForChar` 回锚后的 slice）；`ensurePageRangeShaped` 的 seam 诊断（`:522-537` FWD/BWD）转正为单测断言；设备实测脚本（记保存 char vs restore char 及落页）作为 C1-4 验收项。

### 论证 4 — TODO「三线程优先级契约」消化（编排层一起收）

现状（`TODO-未尽事宜.md:11-13`）：前台 temp shaping / 后台 `canonicalDispatcher` / 后台 `tempPrefillJob` 在 `tempStateLock` 竞争，只有互斥无优先级。
收编动作：契约写入 common 编排宿主 —— **F(前台翻页) > A(相邻预排，可中断) > B1/B2(后台 canonical/preflight，空闲+让步) > P(整书预取，最低)**；`canonical` 阶段采样前台活动（`isActive`/`ensureActive` checkpoint，`BoxChapterLayouter:372-373,388-393` 已有）必要时让位；`tempPrefill` 沿用 `deferCanonical` 同类机制。`Executors` 构造由调用方注入 `CoroutineDispatcher`（前台 `Dispatchers.Default` 高优、后台低优单线程），策略进 common、线程池留壳。
