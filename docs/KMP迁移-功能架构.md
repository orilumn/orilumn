# Orilumns 功能架构（运行时能力 + 数据流）

> 定位：从**功能能力**而非代码模块出发。描述一本书「导入 → 解析 → 排版 → 分页 → 呈现」的流转，以及贯穿的横切能力。与 `KMP迁移-目标结构.md`（代码放哪里）互补。
> **本版修订**：CSS 级联归入浏览器内核层；阅读流水线按「解析→书籍级联→标注投影→用户覆盖→布局断行→分页→渲染」线性顺序重排；书架为独立并行路线；「预处理」明确指标注/划线投影，CJK 间隙等改称「文本整形」。

## 1. 阅读流水线（打开 EPUB 后，数据流顺序）

> 线性：上一步的输出是下一步的输入。这是唯一需要记的阅读逻辑，模块归属见 §10。

```
① EPUB/章节解析 ──▶ XHTML→DOM(Ksoup)；收集 CSS 源(<style> + <link> + 内联 style)
        │
② 书籍 CSS 级联 ──▶ 级联作者样式 + 内联 style → 每个元素的「基础计算样式」(书本原样排印)
        │          (CSS. cascade: origin/importance/specificity/order)
③ 标注/划线投影 ──▶ 按源锚点把 标注·划线·高亮 投影到 Run → 展示 Run(元数据，不改底层文档)
        │
④ 用户 UI 样式覆盖 ─▶ 主题/间距/字号/字体替换（UI>单元素>主题）→ 最终面板样式(压制书本原样)
        │
⑤ 布局 + 断行 ────▶ 最终样式 + 展示 Run → 盒子布局(margin 折叠/嵌套) + 断行 → 连续行流
        │           （此处含「文本整形原名预处理」：CJK↔西文间隙/长串断行 — 与③不同）
⑥ 分页 ──────────▶ 行流切分页 + break-* + CFI 锚点·双向流式·页缓存
        │
⑦ 内核渲染/绘制 ──▶ 按行窗口绝对 Y 绘制（分页/滚动共用）→ 阅读面 UI
```

> **术语澄清**：
> - **③的「预处理」＝标注/划线投影**（展示 Run，元数据覆盖），是阅读功能。
> 文档旧版把「CJK 间隙/长串断行」也叫预处理——它其实是 **⑤断行前的文本整形变换**，属排版引擎内，跟③不是一回事。现归为「文本整形」，不再叫预处理。

## 2. 一本书的旅程（导入 + 书架并行路线）

> §1 已给出「打开章节后」的完整阅读流水线。这里补全它之前的事——导入与书架，它**不经过排版渲染管线**，是并行路线。

```
① 导入    文件选择(mpfilepicker) ─▶ 复制入书目区 ─▶ EPUB(zip) 解包 + 元数据(OPF/spine/nav/NCX)
        ─▶ 写入书籍库 → 书架展示(解码封面)
② 打开    点击书目 → 用「章节+偏移」锚点 → 进入 §1 阅读流水线
        （XHTML→Ksoup DOM + CSS 源即 §1-①，向下继续）
③ 状态    进度/位置 · 主题/间距 · 字体(替换/WiFi 导入) 既服务书架也服务阅读，贯穿全程
```

## 3. 引擎内核层（浏览器内核层）职责

> 这是底层引擎，**CSS 级联在内、解析与布局在内**，向上只暴露「连续行流」。

| 能力 | 职责 |
|---|---|
| HTML→DOM | jsoup→**Ksoup** 容错解析成 DOM；脱壳白名单、`ol` 计数属性、表格 `colspan/rowspan`、文本交错顺序保留 |
| CSS 解析 | 自研 `LightCssParser`（注释/字符串/括号/`!important`/@规则跳过） |
| **CSS 级联** | origin / importance / specificity / order；继承；em/rem/%→px（**属内核职责**） |
| 盒子布局 | margin 折叠、嵌套、背景/边框、`break-*` 感知 → 连续行流 |

## 4. 分页层职责

| 能力 | 职责 |
|---|---|
| 分页 | 把内核产生的连续行流按固定页高切断 |
| break 控制 | `break-inside/break-before/break-after` 原子块整块移动 |
| CFI 锚点 + 双向流式 | 从锚点起先出一页、再反向回填到章首、向前续流；双向缓存窗口 |

## 5. 文本整形（原「预处理」，断行前文本变换）

| 能力 | 职责 |
|---|---|
| CJK↔西文间隙 | 删除多余半角空格，注入固定间隙（0.25em），**不插真实字符** |
| 长串断行 | URL/UUID 等安全位置内部断行 |
| 标点禁则 | 基础标点禁则（后续迭代精细版） |
| 产物 | 干净 Run / 文本，作为内核布局输入 |

## 6. 读者样式覆盖层（内核之上）

| 能力 | 职责 |
|---|---|
| 语义分层覆盖 | UI(间距/行距/密度) > 单元素 > 主题 > 书本原样 > UA；前三层合成一次覆盖，直接覆盖内核级联结果 |
| 主题 / 预设 | Modern / 传统 / 自定义主题对元素族重排 |
| 效果 | 读者意图永远优先于书本；**不参与内核级联计算** |

## 7. 呈现层与 UI（消费分页结果）

| 功能 | 职责 |
|---|---|
| 行窗口绘制 | 「按行窗口绝对 Y 坐标」统一接口，分页翻页/连续滚动复用同一管线 |
| 阅读面 | 手势、翻页（含 OpenGL 卷曲，Android 专属）、进度、亮度遮罩、字体切换 |
| 提示 | Snackbar（替代 Toast） |

## 8. 书架（并行路线）

> **不经过排版渲染管线**，与阅读面并行，只读写书籍库（书目/封面/进度/删除）。

| 功能 | 职责 |
|---|---|
| 导入 | 文件选择(mpfilepicker) → EPUB 解包 + 元数据识别 → 入书目 |
| 列表 / 封面 / 删除 | 书籍库 CRUD + 封面解码（Skia 图片） |
| 与阅读面衔接 | 点击书目 → 用其「章节+偏移」锚点打开阅读面 |

## 9. 横切能力

| 能力 | 职责 |
|---|---|
| 进度/位置 | 章节+字符偏移锚点，随时恢复 |
| 标注/划线/高亮 | 按源锚点投影到展示 Run（元数据覆盖，不改底层文档）——即 §1-③ |
| 设置持久化 | 全局阅读设置 + 每书设置（kotlinx.serialization） |
| 字体库 | 全局/按元素类型替换；WiFi 上传导入；TTF/OTF 解析 |
| 分页缓存 | 缓存行窗口布局，避免深跳全量重排 |
| 平台能力 | 文件系统/路径 · 日志 · mDNS/本地IP · 系统亮度(默认遮罩) · 网络(Ktor) · 数据库驱动(SQLDelight)（虚线层，系统级才 expect/actual） |

## 10. 与实现架构的对照
- 本图「引擎内核 + 分页 + 文本整形」＝实现架构里 `common:engine/{css,html,paging,laying}` + `engine-skia`（断行/绘制）；标注投影＝ `common:engine/text/Run` + 展示构建器；覆盖层/呈现/阅读面＝ `shared-ui`；书架＝ `shared-ui:shelf` + `common:data`（书库）；横切＝ `common:io/net/log` + 各 app 壳 actual。
- 功能边界与模块边界不绑定；依赖方向始终单向（UI → 呈现 → 分页 → 内核 → 文本整形）。
