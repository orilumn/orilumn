## 二、本轮修掉的关键问题（Kotlin 书为什么不能选字）

之前只有「整章重排版」路径留下整章文本缓存；大章从磁盘表或临时表打开时没有这份缓存，
长按取不到原文，所以完全没有反应。现在：

1. 磁盘命中、小章全排、大章临时表三条路径都会准备好与排版同尺的整章文本；
2. 文本同时带「每个排版叶的块尾偏移」，选区据此在标题 / 列表项 / 段落边界截断，
   不会像最初那样从标题一路选到正文里；
3. 平板实测 Kotlin 书（章 9、章 11）长按已能选句并显示手柄。
