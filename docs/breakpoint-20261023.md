## 二、卡住的问题（用户报的）

> 「现在批注没显示出来啊」——复现后确认是**有时显示、有时不显示**（用户自己写下的批注文字就是
> 「为什么有时显示，有时不显示？」，DB 里 id=113）。

### 已查清：保存没问题

平板上拉库（`databases/orilumn.db`）看到新记录都在，`note` 也有：

```
113|39|2|underline|267|295|为什么有时显示，有时不显示？|所有程序都需要…
112|39|2|underline|229|233|用几章来|在几章中
```

⇒ 落笔链路（`完成` → `createSelectionAnnotation` → `AnnotationState.add` → 落库）是通的，问题**只在显示**。

### 根因：`noteBubblePlacements` 的候选太窄，满页时全军覆没

`shared-ui/.../NoteBubbles.kt` 现在只有四个写死的候选：

1. 锚点末行右侧（`contentRight - (last.right + gap)`，默认只给 1 行）；
2. 锚点下方到下一块墨迹之间的空隙；
3. 页脚空白（`contentBottom` 之下）；
4. 左右**页边距兜底**，但要同时满足 `rightMargin >= charW*2` 且 `w >= minWidth`。

满页（正文排到底、行都排满）时 1/2/3 全部不成立，而大屏页边距只有几十像素、`charW*2` 又要 70px 上下，
第 4 条也常常不成立 ⇒ 函数返回空表 ⇒ **一条都不画**。文档里这条早就记成「缺陷 3 的一半原因」，
本来就排在「旁注布点改造」这一步（`docs/文本标注与修订方案.md` §5.15 第 4 步、D-26 §3、§D-29 前置）。

### 顺手查出的第二个问题：障碍物不全

`pageInkRects(...)` 只返回**文字逐字墨迹**（`decorRects` 投影），不含图形 / 表格 / 边框线。
所以现在旁注即使放出来，也可能压在插图上。改造时要把它升成「障碍物集合」。

已核过的几何来源（都在手边，不用新 API）：

- 文字：`pageInkRects(...)`（逐字，页坐标）；
- 图形：`content.pageImages`（`PageImage.xLeft/yTop/yBottom/widthPx/heightPx`）；
- 背景图：`content.pageBackgrounds[].bgSrc != null` ⇒ 整盒算图形；
- 线条：`content.pageBackgrounds[]` 里 `border == true || strokeWidthPx > 0` ⇒ 取盒的四条窄边；
- 表格整体：**还没有 API**（登记在 D-29 前置里，本轮没做）。

块底色（`blockquote` / `div` / `pre` 的非文字区）、`margin` / `padding`、四个页边距一律算空白——
所以 `PageBackground` 只要不是 `bgSrc` / 边框线，就**不进**障碍物表。

## 三、明天开工：§5.15 第 4 步（旁注布点改造）+ 第 5 步（箭头）

方案已经在文档里定死（D-26 §3「退出输入后：旁注布点 + 箭头指向原文」、§5.15 第 4 / 5 条），要点：

- 候选 = 本页**所有**不含四类障碍（文字 / 图形 / 表格 / 线条）的空白矩形，不再写死四个；
- 排序两级：**就近优先**（旁注框与锚点墨迹边到边最短距离），距离相当再比**完整显示优先**（整句不被省略号截掉）；
- 行数不设死上限：一块空白能放几行放几行，空间够就整句显示，页边距只做最后一档兜底；
- 每条旁注配一条箭头：直线优先 → 折线（先竖后横 / 先横后竖取短）→ 弧线（朝远离障碍一侧鼓出）；
  三种都不通就只画旁注不画箭头；只避那四类障碍与已放好的旁注，从块底色 / 内边距 / 页边距穿过是允许的；
- 纯覆盖层：只读几何，不进分页、不进栅格，翻页动画期间整层让位。

改动落点：
