# 断点：批注引线按新规则重做（2026-10-26）

时间：Mon Oct 26 2026 ｜ 主分支本地，**未提交**（工作树脏）｜ 布点部分不动，只改引线

## 一、本轮目标

用户按新的《批注与引线绘制规则》（12 条）改了口径，并报了六个画出来的毛病：

| # | 现象 | 对应规则 |
|---|---|---|
| 3 | 箭头方向与末端引线垂直（箭头两臂退到上一段上） | 5 / 6 |
| 4 | 右下批注从左出线、绕回右侧再指向选区 | 8 / 11 |
| 5 | 正下方批注不从「框与选区的横向重叠段」里出竖线，随意绕行 | 1 / 9 |
| 6 | 行间横穿不走路中间 | 9 |
| 7 | 正右批注没有阻挡却折成三段 | 1 / 4 |
| 8 | 左右两侧的批注不从框的上 / 下边竖着出，而是先横出再折上下 | 2 |

布点（选位置）这一轮**不动**：位置与距离优先、折行其次的既有口径保持原样。

## 二、根因（六条都对上了）

1. **直线判据是严格相等**：出口 / 入口各自沿边可动，代码却要求两端坐标严丝合缝相等才认直线；
   再加上端点按 0.5em 内缩后，一行高的框那一侧区间退化成一个点，而字墨迹中心又差几像素，
   于是「本来一条横线」被折成三段（第 7 条）。
2. **正下 / 正上的出口钉在框中心**：没有「框与选区的横向重叠段」这个概念，一条竖线就能解决时
   也照样绕（第 5 条）。
3. **行间中线的门槛卡在半字高**：正常中文行距（墨迹高约 20、行距约 12）根本判不出「两行之间」，
   规则 9 等于没落地（第 6 条）。
4. **箭头固定 5dp**：末段只剩几个像素时两臂根部退到上一段，看起来像「横线头上长了个竖箭头」（第 3 条）。
5. **左右两侧只有「横出」的出口 / 入口**：没有「竖着从框的上 / 下边出去」的候选，
   也永远走不通 下横上 / 上横下；再加上早停用的是全局最优，前一组端点找到一条折线后
   后面的端点组合连试都不试（第 2 / 8 条）。
6. **没有「倒退」判据**：右下批注「左边已经越过目标字右缘还往左走」在几何上就是背离文字，
   但旧排序只看折数 / 长度，于是绕出去再折回来（第 4 条）。

## 三、现在的实现（都在 `NoteBubbles.kt` 的引线段）

### 3.1 端点

- **直线用两段可用区间的交集**：出口沿框边、入口沿字边各有一段「离角 0.5em」的区间，
  取交集得到共同坐标。交集为空但只差 `max(框 em/2, 2px)` 以内时，按规则 7 后半句**取消内缩**，
  取中间值；但坐标必须仍落在两端那条边的整段范围（`edgeLo/edgeHi`）里，落点不会滑出框外。
- **正下 / 正上**：入口 x 取 `overlapBand(框横向投影, 选区横向投影)` 收 0.5em，优先放在框中心
  对应的那一点；出口是朝文字的那条横边（竖出），另补一条侧边出口。
- **左右两侧**：竖边出口 / 入口照旧，另加框的**上边 / 下边**出口与目标字的**上边 / 下边**入口
  （同一行的 RIGHT / LEFT 也加），这就是「下横上 / 上横下」的候选来源。
- 竖着进时箭头停在**行盒边框**上（`verticalEntryEdge`），不侵入行盒。

### 3.2 形状名次（`arrowForm`）

| 名次 | 线型 |
|---|---|
| 0 | 单段直线 |
| 1 | 一折 L 形；左右两侧「竖出 → 行间横穿 → 竖进」的两折 下横上 / 上横下 |
| 2 | 其它两折（Z 形） |
| 3 | 三折及以上 |

名次排在折数**之前**：规则点名的线型不能因为多一折就丢掉；同为首选的 L 与 下横上 之间
再由折数决胜，所以没有阻隔时 L 压过 下横上。

### 3.3 择优顺序（`ArrowPath.betterThan`）

交叉数（0 优先）→ 不倒退 → 形状名次 → 末段不短于 6px → 折数少 → 穿字少 → 不贴字
（`hug`，行高 0.3 倍内）→ 更短 → 候选顺序。

全撞兜底（`betterFallbackThan`）：不拐回自己的框 → 不横穿锚点那一行 → 交叉最少 → 不倒退 →
形状 → 穿得少 → 更短。

- **不倒退**（`arrowRetreats`）：只看几何——第一段方向与「起点 → 终点」在主轴上的方向相反即算，
  不管布点在左还是右。
- **不横穿锚点行**（`entersInk` + `ArrowTarget.own`）：穿过要指的那一行墨迹再扎回来算「绕到字外面」，
  兜底里也排在交叉数之前。
- **早停**：只有不交叉的单段直线才无条件收手；按折数试时，只有**本组端点**自己找到不差于
  当前折数的通畅路径才停（用 `orderBefore` 判定）。这条是 下横上 能轮到、正右能画直的关键。

### 3.4 行间中线（`arrowGapMidYs`）

- 门槛从「半字高」放宽到**一个字墨迹高**（正常 CJK 行距都在内）；
- 折点候选按「离框中心与目标字中心的纵向中点由近到远」排，最多取 4 条；
- 中线被别的批注框占住时，优先换一侧（另一条行缝），实在不行贴着批注与文字之间的空档。

### 3.5 箭头（`noteArrowHead`）

臂长夹在末段长度的 90% 以内，半宽随臂长等比缩小；末段短到几乎为零时直接不画两臂。
`drawNoteArrow` 改用它，箭头方向严格取末段。
