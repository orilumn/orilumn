# 分页预排原则（记录在案）

状态：已通过原则审查。下列规则为各端统一口径（排版层（上）所有，触发点在用户层，不碰渲染层）。
“遗留”指原则已定、现状未达；“待定”指需拍板的选择。编号沿用（L1/L2/L4–L9 见 2026-09-25 梳理，V 系列为本次审查新增）。
行号均为撰写时快照（重构后已多处漂移），以符号名为准。

## 0. 术语与标记

- 路径两态（L5 落地后为准，现代码中尚无此单一标记，最接近的是 `inProgress` 存活与否）：
  - `PATH_TEMP`：增量路径，活页游标在临时会话（`InProgressPagination`）上；
  - `PATH_FULL`：全量路径，活页游标在磁盘（canonical）分页表上，全章边界有效。
- 两张表：
  - 增量表 = 当章游标 + 塑形窗口 + temp 会话（`forwardPages/backwardPages/pointer`）。只保留当前章。
  - 全量表 = 分页边界（char/block 四元组），可记全书。**只存边界，不存塑形结果**（`ChapterPaginationTable.kt:13-14`）。
  - shape 缓存（`blockShapeCache`）不属于任何表：按叶索引 + 参数周期作用域，参数一变即废（`startAnchorStream:719`），切换路径时保留。
- 切换点定义（尤为重要，后续新旧对照以此为准）：**切换 = 活页游标的归属变更**（`finalizeTempOnLeave` 的 bind、`relayoutTo` 的重锚、`ensure*` 的命中承接）。
  写表（`cache.write` / `bindPaginationTable`）≠ 切换。后台 B1 落盘时 temp 照活，是 buildup 不是 switch。

## 1. 预排优先级队列（高→低）

> **本节阶梯已废止（2026-09-26），以 `线程调度原则.md` §3 为唯一权威。** 废止两处错误：
>
> 1. **原第 2/3 条的「仅全量路径执行」是错的。** 它把"读者当前在哪条路径"当成了"这一档排什么活"，
>    于是把下一页/上一页增量限定在磁盘表路径上、排除了临时表路径。实际相反：这两档是**锚点增量**，
>    按定义跑在章内临时表上，而章内翻页恒走增量（S4）。「temp 路径已由 prefill 覆盖、不得重复」
>    这条 Q1 自洽要求也随之作废——它成立的前提（两档被限定在磁盘路径）已经不成立。
> 2. **原第 3 条的「上页跨章时跳过本步」已被反向裁定。** 现行口径是：目标页为章首页时不是跳过，
>    而是**全量预排上一章**（`线程调度原则.md` §3.3），并且它比「本章全量」更紧急（§3.5）。
>
> 仍然有效的部分：本章全量（B1）在后；其后整章按章号偏离绝对值交错（R7 已落地为
> `orderRemainingChapters`，方向侧先出）。

6. 代际与取消规则（已确认）。
   - 改参 = 新代际：停掉所有后台预排，两张表全废（全章，含本章），重走队列。现状 `layoutEpoch` 的改参 bump 保留，
     补齐“停后台任务 + 全废表”的覆盖面（本章旧表今天没废，见 S2）。
   - 导航（翻页/跳转，不影响版面）= 不换代际，不碰全量路径：只重派增量预塑（`线程调度原则.md` §3 第 2/3/4 档），B1/B2 照跑不误。
     之前担心的“导航不 bump 致废活占道”（V-d）按此口径消解——导航本来就不该取消全量活；残留项只有 B1 被 B2 HOL 阻塞，
     按“新章全量可选提权”处理（见 S7），接受其 best-effort 性质：正确性永不依赖全量路径，翻页总有增量兜底。

## 2. 场景规则

- **S1 改参即时刷新**：只刷**当前页**（供用户观察排版效果），不跑队列、不废他章、不 bump 代际；
  **是否重走预排优先级队列，只在关闭面板时判定**（已确认规则）。锚定当前页首字符/元素，该字符必须保持在首行。
  - 现状偏离（V-a，已实锤）：平板 preview 每 16ms 调一次全量 `prepareRelayout`（`ReaderActivity.kt:587-604`），
    每次废他章全表 + `layoutEpoch++` + `voidPreflight`（`BookDocumentController.kt:1412-1424`）。S1 的“当前页”
    与代码的“全章联动”不能自洽：preview 期必须只动本章（不废他章、不 bump、不跑 B2），退出才走 S2 全套。
    **V-a 已关闭（R4，2026-09-26 核）**：preview 改走 `prepareRelayoutLight`（本章轻刷新，不 bump 代际；
    16ms 节流仍在但只动本章），退出面板走 S2 全套。残留（有意为之，非偏离）：
    节流循环结束会调一次 `requestWholeBookRelayout`，由派发层 epoch 戳限为每代际一趟 B2。
  - 桌面 150ms 防抖单发 vs 平板 16ms 循环：行为收敛到“稳定后单发”，另议。
  - D1 已决（改参后回翻规则）：①当前页首行锚点不变；②回翻以当前页分页点为基准，按屏参倒推上一分页点；
    ③上页排满即显示排满页，不再做标题保护；④上页未排满（仅章头部会如此）：优先查全量命中，命中按 S5 切全量
    并废增量表，未命中以章头部为新锚点、重启队列增量部分，全量路径不动。
- **S2 退出面板**：先 diff（平板 `typographHash`，桌面 `withoutLight()`，两者等价性已确认）。
  无变化零动作；有变化→**停所有后台预排，两张表全废（全章，含本章）**，标路径
  （大章标增量；**小章永恒全量，不进增量路径**——块数 ≤ 阈值永不建 temp 会话，标记恒为 `PATH_FULL`，
  其本章全量（`线程调度原则` §3 第 6 档）在前台当场完成，不进后台队列），跑队列（含 B1 本章 + B2 全书）。
  注：废的是表与会话，已绘制像素保留至新页就绪是渲染层的事，不属废表范围（防闪白不动）。
  磁盘旧表靠 `paramHash` 文件名天然失配变孤儿（trim 回收）。原 L4“本章旧表留不留”按此口径已决：废。
- **S3 直接跳转**（开书/目录/进度条/批注/书签）：先查全量表命中。
  - 命中→绑定 + 定位目标页 + 路径标记（D4 已决，不碰表内容，只动标记：增量使用中跨章/转章头命中
    全量叫**修改**标记（`PATH_TEMP`→`PATH_FULL`，并废增量）；开书直接用旧磁盘表叫**设置**标记（初设 `PATH_FULL`））。
  - 未命中→跑第 1–4 步（锚定在跳转目标）。
  - 现状无命中分支（L5），行为等价物藏在 `ensureChapterLayout` 内部；标记缺失。
  - 同章内 mid-jump 现状是全量 nuke（`relayoutTo`），优化空间：目标落在已塑窗口则只搬指针（效率遗留，不影响正确性）。
  - 开书 B2（L2“不跑”已关闭，R7，2026-09-26 核）：双端宿主开书即派 B2
    （`DesktopReaderHost:126`、`TabletReaderHost:72`，epoch 去重 + defer 门控在内），
    D7 实测整书扫描完成；批注/书签未实现，入口预留走 `relayoutTo` 同链。
- **S4 增量章内不切全量**：章内翻页且未到章首页→始终增量。现状成立（无 mid-session 切换，
  `finishCanonicalBackground:1366-1367` 明示）。边界：到尾跨章、回翻到首页按 S5。
- **S5 到首页/离章**：先查全量表命中。命中→用全量 + 废增量**游标与会话**（shape 缓存保留，见 §0）；
  未命中→跑队列（章头重锚 / 新章锚流 + B1）。回翻落上章末页且上章无表时，尾锚页由
  `shapeTempPageBackward` 从文末倒包一整页（与 -1/-2 链同制式；前向灌撞顶即切倒包，不再只剩末行余渣）。现状流程相符（`resolveHeadArrival` / `finalizeTempOnLeave`），
  实锤缺口 L6：handoff 绑全章时窗口未记全量范围，下一翻重塑并丢弃全章成果。
  D3 已决：空章连跳；仅全空（零有效内容，属书 bug）跳过，**单标题亦停留**——`hasSignificantText`
  （`MarkupElement.kt:42-51`，任一非空白字符即有效）已核实符合要求，标题章必停留，阈值审计关闭；
  连跳经过的章仍记入 R2 日志（合法连跳 vs 误触一眼区分）。
- **S6 视口变化 ≡ 改参**（本次新增，V-b 已实锤平板 bug）：旋转/分屏/resize 后，平板**无任何处理**
  （`ReaderActivity.kt` 监听仅开书一次，之后空转；旧 `viewW/H` + 旧表继续画），桌面靠重建 host 隔离。
  S6 要求：视口变化走 S1/S2 同链（`contentW/H` 已在 `LayoutParamKey` 内，键支持、触发缺失）。
  **V-b 已关闭（2026-09-26 核）**：`ReaderScreen` 的 `LaunchedEffect(pxW, pxH)` 在视口真变时
  （`setViewport` 返回 true）走 `finalizeRelayoutAll` 全套（S2 同链，面板开着时 defer 照旧抑制），
  静态 inset 同步刷新。桌面仍靠重建 host 隔离（双端行为同效，机制不同）。
- **S7 导航细则（不影响版面；已确认规则）**：导航永不换代际、不碰全量路径。
  - 章内增量命中窗口：页切换后立即停在途增量预塑，按新指针重派邻页序列
    （`线程调度原则.md` §3.1 的 +1/−1/+2/−2…，即原「第 2 步 + 第 3 步」推广为整段序列）。
    **原注「上页跨章跳过」已作废**：章首页时改为全量预排上一章（§3.3），且紧急度高于本章全量（§3.5）。
    temp 路径即现状 `scheduleTempPrefill` 重派；磁盘窗路径同语义。
  - 章内 miss（连续翻页）：目标页第一优先，**不废增量表**（不影响版面）。temp 路径按需补塑（现状 `tempNav`
    语义保留）；磁盘窗路径重塑目标窗（窗口滑动，不废表）。已确认规则。
  - 结构性 miss（窗口非法 / 会话 detached / 表过期）：废当前增量表（游标/会话/窗口），以目标为锚重走队列。
  - 跨章未命中全量：废旧章增量表，以新目标页为锚走新章增量路径；全量路径不动。新章全量**提权到其他全量之前**（原「可选」已定：d=1 边界兜底，§3.3/§3.5）。
  - 跨章命中全量：按 S5（用全量 + 废增量）。
