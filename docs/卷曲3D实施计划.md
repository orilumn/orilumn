# 卷曲 3D 实施计划（移植版，2026-11-16）

> **这一版把「自己发明几何」整条否掉，改成照搬成熟实现。**
>
> 上一版（2026-11-15）是我自己推的圆柱模型：整页在折痕处对折，掀起的部分绕过半圈后
> **平铺到另一侧**、盖住当前页，再叠三层沿整条折痕铺满的透明覆盖（纸背压淡、纸卷明暗、落影）。
> 真机上的结果读者读不出来 —— 只见半透明滚轴加几条深浅不一的长条，分不清哪张是纸、
> 哪面是反面。**几何不是「调参不到位」，是模型选错了。**

## 目标

翻页时纸**卷起来**：手指在哪，卷轴就在哪；卷轴一侧的纸被卷进卷筒、其余不画；
新页从卷轴另一侧露出来。读者一眼能认出「这是一张纸在卷」，不需要任何说明。

## 参考实现（照搬，不发明）

| 来源 | 位置 | 搬什么 |
| --- | --- | --- |
| moon+ | `samples/moon/sources/com/flyersoft/views/NewCurl3D.java` | `Mesh3D.curl(...)` 的扫线网格、顶点色明暗、两种影、画序 |
| 多看 | `samples/duokan/sources/fi/harism/curl/CurlMesh.java` | 交叉核对卷筒参数化（同一套圆柱数学） |

**moon+ 的关键结构**（也是我上一版缺的）：

1. 把页面四角**旋转到手指方向**的局部坐标系（`rotateZ(-acos(dir.x))`，平移到手指点），
   于是卷轴永远是「竖直的」——不需要为斜折痕单独写几何。
2. 沿卷轴扫线：`0 → −πR` 分 `mMaxCurlSplits` 段，最后再加一条「纸的另一条边」。
   每条扫线对应一个圈角 θ，屏幕位置是 `R·sin θ` 一类的正向映射。
3. **卷轴之后的纸不画**（不是折回另一侧）。所以画面只有：当前页（平）+ 卷筒 + 新页（平）。
4. 顶点色就是明暗（`mColors`），纸背与正面用不同的明暗系数；影是**独立的两套顶点**
   （投在下面那页上的落影、卷面自阴影），一起送进 GL。
5. 画序：落影 → 纸背 → 正面，全部由渲染器按固定顺序出。

## 原则（不变）

1. 纹理供给不动：页栅格 + 覆盖层两张图，`CurlPageImages` 收，不合成、不新建池。
2. 纸背 = 同一张纸的背面，读者写的字透过来、页码也一样。
3. 几何在 CPU 铺点，光栅/采样/插值在 GPU。
4. **不再有任何「自己发明」的系数**：半径、扫线段数、明暗系数全部取自参考实现，
   要改必须有对照图为证。

## 落地方式（已经跑通的那一段不再动）

纹理与明暗的**绘制手段**已验证可用，保持：

- 纹理：Compose 公共 API `Vertices` + `ImageShader` + `Canvas.drawVertices`
  （跨平台、无平台分叉、无版本门槛；顶点色必须与顶点数等长，传白色 + `SrcOver`）。
- 明暗：几何自带顶点色不可靠（真机随机色），**明暗改为与几何同源的一维渐变**：
  扫线的 θ 是单调的，明暗是 θ 的函数 ⇒ 一条多段渐变精确表达，不需要顶点级着色。

## 步骤

### P1 移植网格（核心，先出图）

- 新建 `curl/CurlMeshPort.kt`：按 `Mesh3D.curl` 逐行移植，输入 = 手指点 + 方向 + 半径，
  输出 = 扫线序列、每条扫线的 (屏幕 x, 材料 x)、圈角 θ、正面/纸背的顶点与索引。
- 保留 `CurlShape` 现有的进度/方向/倾斜语义，只把「形状」换成卷筒，
  与扫线一一对应即可（不引入新的状态机）。
- 验收：**桌面出图**（`shared-ui/build/`）与参考实现的同一姿态肉眼对得上：
  卷筒位置、卷筒宽度、纸背可见范围、新页起点。

### P2 明暗与影

- 明暗系数照抄参考实现的分段（正面 / 纸背各一段），参数不改。
- 两道影照抄：落影（卷筒投在下面那页）+ 自阴影（卷筒靠折痕一侧）。
- 验收：卷筒在图上是一个**有暗边的圆筒**，而不是一条均匀亮带。

### P3 去掉多余覆盖

- 删掉上一版的三条沿整页铺开的透明覆盖（纸背压淡 / 明暗带 / 第二道影）：
  它们就是读者看到的「深浅不一的长条」。
- 纸背压淡只在纸背那一小段上画，不跨整页。

### P4 接回翻页层

- `USE_CURL3D` 打开，3D 优先、退化才退回折页。
- 等图规则、末帧扶正、松手收尾全部沿用。

### P5 验收

- 桌面：6 档进度（0.1/0.3/0.5/0.7/0.9/0.98）× 3 档倾斜，逐张对参考实现的形状。
- 真机：录屏逐帧看（`screenrecord` 后抽帧），不用随手截图猜。
- 判据：① 卷筒是圆筒不是长条；② 纸背能看出是「同一页的背面」；③ 新页起点与手指一致；
  ④ 末帧逐像素等于目标页；⑤ 帧预算与折页持平。
