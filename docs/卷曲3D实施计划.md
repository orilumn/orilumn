# 卷曲 3D 实施计划（移植版，2026-11-16）

> **这一版把「自己发明几何」整条否掉，改成照搬成熟实现。**
>
> 上一版（2026-11-15）是我自己推的圆柱模型：整页在折痕处对折，掀起的部分绕过半圈后
> **平铺到另一侧**、盖住当前页，再叠三层沿整条折痕铺满的透明覆盖（纸背压淡、纸卷明暗、落影）。
> 真机上的结果读者读不出来 —— 只见半透明滚轴加几条深浅不一的长条，分不清哪张是纸、
> 哪面是反面。**几何不是「调参不到位」，是模型选错了。**

## 目标

翻页时纸**卷起来**：手指在哪，卷轴就在哪；卷轴一侧的纸被卷进卷筒、其余不画；
新页从卷轴另一侧露出来。读者一眼能认出「这是一张纸在卷」，不需要任何说明。

## 参考实现（照搬，不发明）

| 来源 | 位置 | 搬什么 |
| --- | --- | --- |
| moon+ | `samples/moon/sources/com/flyersoft/views/NewCurl3D.java` | `Mesh3D.curl(...)` 的扫线网格、顶点色明暗、两种影、画序 |
| 多看 | `samples/duokan/sources/fi/harism/curl/CurlMesh.java` | 交叉核对卷筒参数化（同一套圆柱数学） |

**moon+ 的关键结构**（也是我上一版缺的）：

1. 把页面四角**旋转到手指方向**的局部坐标系（`rotateZ(-acos(dir.x))`，平移到手指点），
   于是卷轴永远是「竖直的」——不需要为斜折痕单独写几何。
2. 沿卷轴扫线：`0 → −πR` 分 `mMaxCurlSplits` 段，最后再加一条「纸的另一条边」。
   每条扫线对应一个圈角 θ，屏幕位置是 `R·sin θ` 一类的正向映射。
3. **卷轴之后的纸不画**（不是折回另一侧）。所以画面只有：当前页（平）+ 卷筒 + 新页（平）。
4. 顶点色就是明暗（`mColors`），纸背与正面用不同的明暗系数；影是**独立的两套顶点**
   （投在下面那页上的落影、卷面自阴影），一起送进 GL。
5. 画序：落影 → 纸背 → 正面，全部由渲染器按固定顺序出。

## 原则（不变）

1. 纹理供给不动：页栅格 + 覆盖层两张图，`CurlPageImages` 收，不合成、不新建池。
2. 纸背 = 同一张纸的背面，读者写的字透过来、页码也一样。
3. 几何在 CPU 铺点，光栅/采样/插值在 GPU。
4. **不再有任何「自己发明」的系数**：半径、扫线段数、明暗系数全部取自参考实现，
   要改必须有对照图为证。唯一的例外是半径封顶 10% 页宽（参考值的 ≈0.108 页宽会把新页的
   正文咬掉，见「当前状态」第 3 条），对照图就是平板尺寸下的 `dev-fwd-p*.png` 两组。

## 落地方式（已经跑通的那一段不再动）

纹理与明暗的**绘制手段**已验证可用，保持：

- 纹理：Compose 公共 API `Vertices` + `ImageShader` + `Canvas.drawVertices`
  （跨平台、无平台分叉、无版本门槛；顶点色必须与顶点数等长，传白色 + `SrcOver`）。
- 明暗：几何自带顶点色不可靠（真机随机色），**明暗改为与几何同源的一维渐变**：
  扫线的 θ 是单调的，明暗是 θ 的函数 ⇒ 一条多段渐变精确表达，不需要顶点级着色。

## 步骤

### P1 移植网格（核心，先出图）—— 已完成

- 新建 `curl/CurlMesh.kt`：按 `Mesh3D.curl` 逐行移植，输入 = 手指点 + 方向 + 半径，
  输出 = 扫线序列、每条扫线的 (屏幕 x, 材料 x)、圈角 θ、正面/纸背的顶点与索引。
- 保留 `CurlShape` 现有的进度/方向/倾斜语义，只把「形状」换成卷筒，
  与扫线一一对应即可（不引入新的状态机）。
- 验收：**桌面出图**（`shared-ui/build/`）与参考实现的同一姿态肉眼对得上：
  卷筒位置、卷筒宽度、纸背可见范围、新页起点。

### P2 明暗与影 —— 已完成

- 两道影照抄：落影（卷筒投在下面那页）+ 自阴影（卷筒靠折痕一侧）。
- 验收：卷筒在图上是一个**有暗边的圆筒**，而不是一条均匀亮带。

  九成时新页占屏幕大半、斜拖时页面四角仍是直角）。

## 当前状态

- `USE_CURL3D = true`：3D 卷曲是默认的翻页动画，网格退化（折痕已在页面外）时才退回折页。
- 几何、纹理、明暗、落影全部按上面「落地方式」那一节实现，逐行照搬参考实现；
  自编的那套（半平面对折、半径跟进度、折痕回收、透视除法、顶点色）已整体删除。
- 与参考实现有意不同、且不再改回去的四处：
  1. **网格只铺掀起的材料那一半**（参考实现把平铺侧也铺进网格），平铺侧由整页绘制负责；
  2. 明暗用渐变叠白实现，不用顶点色（真机顶点色不可靠，且 8 位渐变表达不了大于 1 的乘数）；
  3. **半径封顶取 10% 页宽**（接近参考实现按手指压力算出来的 ≈0.108）。早先试过 3% / 5%，
     读者报「筒太细、折页反面根本看不出来」—— 筒细到一定程度，掀起的纸被压进几十像素，
     纸背只剩一条白边。10% 的代价是筒会盖住露出页靠折痕的那一条（宽度 = 半径），
     翻到一半约 0.03 页宽压在行首上，属于读者接受的取舍。
     另外半径有极小的下限（页宽的 0.05%），只为让收尾的退化网格不出现除零。
  4. **半径还有一条「纸背至少占三成」的上限**（`R ≤ 掀起长度 × 0.7 / π`，参考实现没有）：
     纸卷绕半圈要吃掉 `πR` 的纸，半径超过「掀起长度 / π」时翻起来的那部分整段在筒上、
     一段平铺的纸背都没有，读者看到旧页的字被切断、切断处空无一物（原话「滚筒左侧的
     页面反面呢？为什么不画？」）。0.7 是「筒一眼看得见」与「纸背从起手就有」的交点：
     更小筒又细回去，1.0 则起手那段纸背的轮廓、落影、明暗全都不存在。
- 纸背不能只靠落影（`CURL3D_BACK_SHADOW_*`）：它与旧页同纸同色，一道影只能说明「这里
  有东西」，说明不了「这是一张纸」。纸背的可辨识度只靠**自己的镜像内容 + 折角两条直角边
  的接触影**。**不描边、不压暗**：描一条边、铺一层明暗，读者看到的分别是「卷筒左侧凭空
  多出一条痕迹」和「反面整体比正面暗」，两样都已退役。
- 纸卷**筒内侧有一层缝影，但只落在筒的内壁上、而且只落在它露出来的地方**（`drawCreaseShade`）：
  白纸叠白确实画不出体积，可「整段压暗」会在「纸从筒上绕回平铺段」的切线上留一道硬边（一边是
  纸背、一边是同色卷面），读者判「筒的左侧平白多出一条折痕」；压浅只是把线变浅，线仍在。
  所以这层影只画在**正面那四分之一圈（筒的内壁）的轮廓里**，沿折痕法向做一条渐变：**折痕那一侧
  为 0、越靠背离折痕的筒口越深**。纸背与外圈后画、压在它上面，中段因此被盖掉，
  露出来的只有**卷筒探出折角（平铺的纸背三角形）以外的上下两头** —— 那里看见的正是筒里。
  纸背（纸的正面）与外圈（纸的外侧）都不吃这层影：按整条折痕铺一条矩形式渐变时，影越过卷筒
  落到这两处上，读者判「透到外侧」「没纸的地方也画」。
- 纸背的影只落在**折角那两条直角边**上（各自按边的法向往外铺，宽度 0.7R、浓度 0.62×落影）：
  与折痕平行的自由边挨着纸卷，那里是纸自己压着纸，铺影过去就是读者说的「卷筒左侧那条平行
  痕迹 + 一道影」。直角边跟着折痕一起斜，法向互不相同，所以不能统一按折痕方向铺。
  两条影带铺到纸角就停，转角那个 90° 缺口用一把**以纸角为心的径向扇形影**（`drawCornerShadow`）
  补上：扇形的两条直边就是影带的终止线、边上浓度相同，所以拼起来是一整片。早先两条带子各停
  一条垂线，读者看到的就是「直角处两条阴影带没有融合在一起」；扇形只在自由边退化成一点
  （两条直角边共用一个纸角）时才画。
- **纹理只画在版心材料范围内**（`textureBandOutline`），每段先照自己的轮廓铺一层纸色。
  页栅格只有版心那么大（1585×2400 放在 1840×2800 里），页边距里没有像素：越界采样时
  `Clamp` 会拿版心最边一列去补，把那一列上的墨点拉成横贯页边距的短线（读者报
  「反面页边距上有好几条短横线」）；`Decal` 在这个后端的 `drawVertices` +
  `ImageShader` 下画出来是**不透明白带**，同样不能用。材料坐标沿扫线是线性的，所以「裁到版心
  矩形」以后还是四边形条带 —— 纸背的页边距因此仍是纸，纸卷卷进页边距的一截也只是纸，
  既不抹条纹，也不透出底下那页的字。
  裁剪要**同时看材料 x 和材料 y**：折痕一斜，一条扫线横跨的材料 x 能差大半个页宽，只看行首
  的 x 会把越界那半行也画进来，于是竖着翻没事、往页角斜着掀时页边距上冒出几条短横线。
- 两处只有对着出图才会发现、已经改过来的口径：
  - **卷曲量到屏幕偏移要取负**（`−side ×`）。接反时纸卷鼓向没掀起的那半页、平铺段盖住
    露出页，翻到九成屏幕上仍是大半张旧页、同一段文字叠两三处。
  - **半径不能按进度算**：进度 0.2 时半径 0.2 页、掀起的材料也正好 0.2 页，纸一离开折痕
    就绕满 1 弧度，「翻了两成」看起来几乎没动。按「剩下的纸」算才对。
- 剩余的已知差异（不影响使用，暂不处理）：参考实现那道「自阴影」这里是按筒内壁裁着画的缝影
  而不是整条卷面压暗；落影的衰减用的是线性渐变，参考实现是沿网格顶点的 penumbra 插值。
