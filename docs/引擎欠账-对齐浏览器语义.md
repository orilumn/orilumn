# 引擎欠账：对齐浏览器语义（0.4.7 计划）

> **判定标准**（用户裁定，2026-10-17）：引擎必须支持 HTML/CSS 的浏览器语义，
> **EPUB2/3 范围内的渲染功能都要实现**；文本背景也是 HTML/CSS 规范的一部分。
> 据此，凡「书里写了、浏览器会画、我们画不出或画错」的，都是欠账。
>
> 计划版本：**0.4.7**。记录日期：2026-10-17；现状 `orilumn.versionName = 0.4.5`。
>
> 本文件只谈引擎欠账，与「标注修订」功能的决策**分开记录**（另见
> [`文本标注与修订方案.md`](文本标注与修订方案.md)）。

## 1. 与既有审计文档的关系（重要）

`docs/engine-html-css-capability.md` 与 `docs/roadmap-epub2-3-full-support.md` §4 把下面几条
记为**已达标（T1 / "yes"）**，经代码核对为**过度声明**。本文件以代码为准，旧文档对应行需要修正。

| 旧文档的说法 | 实际 |
|---|---|
| `background-color` → 已生效（盒填充） | 只有**块级盒**会填充；**行内元素背景完全不绘制** |
| `text-decoration` → 已生效（underline/line-through） | 只有布尔；**`line-through` 被画成下划线**（画错），且无颜色/粗细 |
| `mark` → 行内 span + UA `mark` 高亮背景 | UA 规则在，但**行内背景没有绘制路径**，`<mark>` 实际不显示 |

## 2. 欠账清单

| # | 欠账 | 现状（代码证据） | 浏览器语义 |
|---|---|---|---|
| **E1** | **行内元素的 `background-color` 不绘制** | 背景属主只从叶**向上**找祖先（`BoxChapterLayouter.kt:499-510`），行内后代永不被认领；`LineWindowDrawer` 里没有任何行内背景 run；`ua.css:63-64` 自注「行内背景绘制属 P3 视觉层缺口，先落 UA 规则占位」 | 行内非替换元素的**内容区 = 字体 em 盒**（ascent+descent，**不是行高**）；`background-color` 覆盖内容区 + `padding` |
| **E2** | **引擎里没有「行内盒」这个概念** | `isInline`/`InlineBox` 全仓零命中；`padding`/`border` 只在**块盒**（`NormalFlowLayout.kt:748` 容器路径）与**表格单元格**（`:568`）参与几何 | 行内盒有自己的内容区 / 内边距 / 边框 / 外边距；跨行时**按行片段拆盒**（`box-decoration-break: slice` 默认：片段边缘平切，`clone` 则每片带完整边框圆角） |
| **E3** | **`text-decoration` 只有布尔，颜色/粗细/线型全无** | `ComputedStyle.underline: Boolean`（`ComputedStyle.kt:220`）；`UnderlineRun(start, endExclusive)` 无颜色（`UnderlineRuns.kt:14-17`）；绘制恒用行墨色、固定 `0.06em` 粗、基线下方 `0.12em`（`LineWindowDrawer.kt:643-658`）；`parseUnderline` 把 `line-through` 与 `underline` **并成同一个 true**（`StyleComputer.kt:1330`） | `text-decoration-color` / `-thickness` / `-style` 各自独立；`underline` / `line-through` / `overline` 是**不同线型**，各画各的 |
| **E4** | 无 `overline`、无 `text-decoration-skip-ink` 等 | 同上 | 低频，随 E3 一起做 |

> 说明：`visibility: hidden` 与 `overflow`（祖先裁剪）在 roadmap §4.3 里已**如实**记为 parsed-only，
> 不算过度声明，未列入本表。其余以那两份文档为准。

## 3. 交付切法（建议）

1. **一刀：行内盒装饰**（E1 + E2）。这是「行内盒」这一整块语义，含内容区 / `padding` / `border` /
   `background`，跨行按 `slice` 语义拆片段。补完之后：书内 `<mark>`、`<span style="background">`、
   `<span style="border-bottom">` 全部按浏览器语义生效。
2. **一刀：文本装饰全参数**（E3 + E4）。区分 `underline` / `line-through` / `overline`，支持颜色 /
   粗细 / 样式，补 `text-decoration-skip-ink`。

两刀都属**渲染层**（`engine-skia` 绘制 + `css` 计算层），不动排版层算法与用户层。

## 4. 交付口径

- 每刀独立提交，出口：`./gradlew :app:assembleDebug` + 全量单测 + 双路（重/轻）一致性 + 像素 A/B 对照
  （A/B 两个输入都必须当次构建，`shasum -a256` 确认不同版本 —— 见 `AGENTS.md` 发版段）。
- 落地后**修正** `docs/engine-html-css-capability.md` 与 `docs/roadmap-epub2-3-full-support.md` §4 的过度声明。
