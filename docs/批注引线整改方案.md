# 批注引线整改方案（按 2026-10-28 新规则）

本文是**引线绘制**部分的整改计划，取代《旁注布点与引线-实施方案》§6 里关于引线的做法。
规则基线只看 `docs/新版批注与引线规则.md` 的「引线绘制规则」12 条；布点（位置）部分不在本文范围。

- 层级：全部改动在 **shared-ui 用户层**（布线 / 绘制），不碰排版层与渲染层，不涉及 CSS 层叠。
- 影响面：只有旁注引线的形状与端点，不改分页、不改布点结果。

---

## 1. 现状与目标

| 指标 | 现状（真机第 2 章第 1 页） | 整改后目标 |
|---|---|---|
| 「讨论」（正下） | 竖段 109px + 横段 151px，末折被延长到选区右缘 | 一条竖线（≤ 110px），无横段 |
| 同页另外 8 条 | 形状基本合规 | 形状不变或段数更少，无交叉、无新增穿字 |
| 判据 | 交叉 → 不倒退 → 形状 → 末段够长 → 折数 → 穿字 → 贴字 → 长度 | 交叉 → 形状 → 折数 → 穿字 → 长度（见 §4.2） |
| 候选点 | 固定比例：1/4、3/4、0.75、0.5 | 由几何决定：盒边内缩端、对齐点、障碍边、行间中线 |
| 性能 | `NOTE-PLACE route=100ms / 9 条`，`tries=4188` | route ≤ 150ms，tries ≤ 6300 |

## 3. 目标设计

### 3.1 候选点几何化（替代所有固定比例）

沿一条边取点只允许这四类来源（都夹进「内缩 0.5em」的可用区间，区间放不下时按 §3.3 突破）：

1. **内缩端**：区间两端（贴角的合法位置）；
2. **对齐点**：与另一端同坐标的点（能拉出直线的位置）；
3. **障碍边**：本组候选障碍的竖边 / 横边 ± 1px（穿出行间走廊的位置）；
4. **投影点 / 中点**：目标或框中心在边上的投影。

上限：每条边最多保留 6 个（按到目标的距离取近的），沿用 `ARROW_MAX_BEND_COORDS` 的思路，
保证 `tries` 有上界。

### 3.2 折点

保留现有 `emitElbowRoutes`（障碍矩形 + 行间中线 + 框边外 0.35 行高）。其中「框边外 0.35 行高」
只保留给第 3 条的「上横下 / 下横上」——其余形状不允许用它横穿，避免第 10 条失效。

### 3.3 0.5em 的量尺与「突破」

**量尺 = 所选文字的盒子**（2026-10-28 定口），不是整行行框；量法就是现在的
`rectUnion(inkRects)` / `cornerInk`，与布点的「错开一个字」同源。第 5 条、第 9 条里的「行盒」
也按同一个盒子理解：竖进停在选区墨迹的上 / 下边，横进停在选区墨迹的左 / 右边。

「空间不足时允许突破」= 候选点先只取内缩 0.5em 的区间；该区间里没有任何可用点
（区间为空、或点全被挡）时，把候选扩展到**整条边**（两端各留 2px 角部护栏），
并且仍然优先选用落在 0.5em 区间里的点。禁止再退化成「取区间中点」（`clampInset` `:4278`）。

### 3.4 判据顺序（第 6 / 7 / 8 条的落地）

```
交叉数（必须 0） → 形状名次（直线 / L / 下横上） → 折数 → 穿字量 → 长度 → 候选序
```
- 删除 `retreats`：第 3 条要的「下横上 / 下横上」首段本就朝外，判它「倒退」会直接杀掉合规形状；
  首段能不能朝外已由 `endpointsOutward` 硬校验。
- `tailShort` 从判据里删除：第 11 条已经给了「画不下就省末折」的出口，不该再因此换一条更长的路。
- `hug`（贴字）删除或压到最后一位：第 8 条管的是「穿越」，贴边不是穿越。

## 4. 分步实施

每一步单独提交、单独可回退；P2 之后开始有像素变化，必须做真机 A/B。

### P0 注释与规则编号对齐（零行为变化）

- `NoteBubbles.kt` 里约 25 处「引线规则第 N 条」按映射改号：
  `2→3`、`3→2`、`4→6`、`5→9`、`6→5`、`7→4`、`10→11`、`11→7`、`12→（并入 6）`，
  `1→1`、`8→8`、`9→10` 不变。
- 布点代码里的「规则第 N 条」指的是位置规则的 14 条，**不要动**。
- 验收：`git diff` 只有注释；`jvmTest` 全绿。

### P1 判据重排（行为可能微变）

- `betterThan`：删 `crosses` 之后的 `retreats`、`tailShort`;`hug` 删除或降到最后；
  顺序改为 `交叉 → 形状 → 折数 → 穿字 → 长度`。
- 删除 `arrowRetreats` 与 `ARROW_TAIL_MIN_PX`/`tailShort` 的判据用途（`noteArrowHead` 的臂长夹紧保留）。
- 验收：单测里「下横上 / 下横下」类用例不再被否；形状变化限于「原本因倒退/末段短而被换掉」的那几条。

### P2 候选点几何化 + 0.5em 突破（主要收益）

- `arrowBelowExits` / `arrowSideExits` 的 `xs` / `ys` 换成 §3.1 的几何点；
- `arrowBelowEntries` / `arrowSideEntries` / `arrowEntries` 的 `fractions` 同样换成几何点；
- 量尺保持按选区盒子，只改 `clampInset`：区间空时扩到整条边（两端各留 2px），不再取中点；
- 预期：「讨论」的入口被蓝框挡死后，候选扩到选区整条下边，可滑到蓝框右缘外侧（≈1394），
  出口与之对齐 ⇒ 一条竖线。
- 验收：目标页「讨论」横段消失；同页其余 8 条无新增交叉 / 穿字；`tries` 与 `route` 达标。

### P3 末折与横进收口

- 第 11 条：`finish` 里改成**丢掉最后一个点**（停在拐点），不再计算 `xEdge = anchor.right/left`；
  **四角不再排除**（删掉 `!cornerFamily`）。
- 第 9 条（2026-10-28 修订）：高亮标注的竖进端点仍按**整行行框**量（旧结论不变）；
  划线标注的竖进端点改为「该行墨迹 + 这条划线」并集的外侧加一条细缝；横进仍停在字墨迹边，
  横进的 y 夹在字身中部，够不着字下方的划线，往外让只会把箭头推远。
  这样划线标注的箭头不必一路退到行框边框，又不会碰到下划线或墨迹。
- 验收：末折画不下时，箭头落在拐点、方向沿倒数第二段；不出现「箭头悬在选区外」。

### P4 收尾

- 更新 `docs/新版批注与引线规则.md` 的实施注记（补一句量尺口径与判据顺序）；
- 删除迁移期留下的常量与注释；CHANGELOG 记一条。

## 6. 测试与验收

**单测（`NoteBubblesTest.kt`）**

- 新增：规则 4 突破（窄边收缩而非中点）、规则 6 沿边滑到最短（禁止 1/4 跳点）、
  规则 11 停在拐点、规则 6 vs 形状的次序、`retreats` 移除后「下横上」能成立。
- 改写：`squeezed vertical leader turns into a left side L`（`:1785`）、
  `same corner offset gives the same leader for every note on the line`（`:2218`）、
  `leader endpoints keep half an em away from the corners`（`:2303`）——
  断言从「固定比例落点」改成「最短且有唯一解」。
- 保留不动：交叉（`:2083`）、行间中线（`:1965`）、走廊（`:2882`）、穿字（`:2145`）。

**真机 A/B（按 AGENTS.md 的硬要求）**

1. `./gradlew :app:assembleDebug`，装机前记录 `shasum -a 256`，确认新旧包不同；
2. 同一页（第 2 章第 1 页）各截一张，逐像素量引出点 / 折点 / 端点；
3. 抽查 4–5 条不同形态（正下、右下、正右、跨行、贴边），确认无新增交叉与穿字；
4. 看 `NOTE-PLACE` 的 `tries` 与 `route` 是否达标；不达标先砍候选上限，不改判据。

## 7. 风险与回退

| 风险 | 应对 |
|---|---|
| 几何候选变多 → `tries` 爆涨、翻页卡 | 每条边候选上限 6、按距离取近；沿用障碍索引与早停；超预算先减候选 |
| 判据重排后某些批注引线变长 | P1 单独提交，单独 A/B；变长的形态逐条记进 CHANGELOG |
| 0.5em 改行盒后斜向走廊变宽/变窄 | 与布点的「错开一个字」同源校验：`cornerInk` 也改用行盒，两边一起动 |
| 第 11 条停在拐点后箭头落点看着不到位 | 与第 6 条冲突时以「箭头仍指向选区」为准：拐点必须落在选区横向投影内，否则保留原末折 |
