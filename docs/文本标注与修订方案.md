# 文本标注与修订方案（下个 feat 版本）

> 高亮 / 划线 / 批注 / 修改等阅读增强功能的**决策记录**。本文**边讨论边追加**，
> 以免会话压缩后遗忘。计划版本：下个 feat 版本（v1 范围见下）。
>
> 本文件只谈标注修订功能本身；**书内 CSS 语义的引擎缺口与本功能无关**，另见
> [`引擎欠账-对齐浏览器语义.md`](引擎欠账-对齐浏览器语义.md)（0.4.7 计划）。

## 1. 目标与分期

用户原话（2026-10-17）：*这些功能作为**原书 html 的外挂附件**，进入阅读页面时提前处理、注入 html 文档、
并渲染呈现。目前先做**选区、画线、高亮**这些基本功能，稳定以后再添加**批注**，再以后才是真正会改变
html 内容的：**删除、修改、添加文字**。引入修改功能后，要参考 word 的审阅页面，添加**第二种视图模式**，
让用户能看到自己对 epub 的修改内容。这些后面再做，但**目前在架构上要先具备这个框架基础**。*

| 期 | 内容 |
|---|---|
| **v1** | 选区 + 画线（下划线）+ 高亮 + 复制 + 持久化 |
| **v2** | 批注（文本框 / 标注列表面板 / 编辑与删除） |
| **v3** | 内容修改（删除 / 修改 / 添加文字）+ 审阅视图（第二视图模式，参考 Word 审阅） |

平台：Android + 桌面一起做。

## 2. 决策记录（逐条追加）

### D-1 锚点 = 章号 + 章内字符区间（与 `ReadingLocator`/`PageSlice` 同源）

- 表达为 `[charStart, charEnd)`，即用户所说的「原 CFI」；**不新造坐标**。
  （`ReadingLocatorCodec` 存 `chapter:char`；`PageSlice.charStart/charEnd`；页表 `PageRecord` 同源。）
- **所有标注都相对「原书」解算**：书不动，偏移就不动；标注之间**永不互相漂移**；
  排版参数改变（字号 / 边距 / 主题 / 旋转）不影响锚点。
- **装饰类不触发重排**；将来**内容修改**改变文字 ⇒ 该章必须重排一次 —— 这是唯一代价，接受。
- 引擎升级导致归一化口径变化的风险：**暂不处理**（还没有用户），与书签/阅读进度同一风险等级。

### D-2 渲染 = 专用「区间装饰通道」，不注入 CSS 标记，也不用 `border`

- 依据：`text-decoration` 在 CSS 里是「每元素一套、绘制时重合」，**无法与书内已有的下划线共存**
  （只能有一条线，且当前连颜色都改不了）；`border` 是「不得已」手段，**不采用**。
- 规范对应物：**CSS Custom Highlight API（`::highlight()`）** —— 样式挂在**区间**上而不是节点上，
  因此不去抢书作者元素那个「每元素一套」的槽位，可带自己的颜色 / 粗细 / 位置叠加在文字装饰之上。
- 本引擎里对应 **run（区间 + 样式）** 机制。
- 这条通道**同一个东西**同时服务：**临时选区**、**持久标注**、将来**审阅视图的标记**。
- 颜色随记录直达绘制，**不进 CSS 级联** —— 它是「用户侧叠加标记」，不是覆盖书样式的声明
  （故不涉及《样式层叠优先级》的 tier 之争）。

### D-3 标注层 = 两种应用模式，共用锚点与存储

| 模式 | 载体 | 用途 | 动树 / 重排 |
|---|---|---|---|
| **装饰模式（区间）** | 区间装饰通道（D-2） | 高亮、划线、选区、审阅视图标记 | 否，零重排 |
| **内容模式（节点）** | 注入 / 改写 `MarkupElement` | 将来删 / 改 / 加文字（v3） | 是，该章重排 |

- v1 只跑**装饰模式**；**内容模式的位置预留好** —— 这就是用户要的「框架基础」。
- 内容模式下注入会碰「import 时算结构 / open 时 relink」的持久化快路径
  （`PersistedChapterFile`；`MarkupElement.children` 是 `val`，注入 = 重建节点）。
  两条路待 v3 时定：**(a)** relink 之后受控就地插入（保叶身份与字符偏移，快路径不退化）；
  **(b)** 该章 open 时重算结构（丢持久化收益）。

### D-4 绘制归属与缓存

- **「字符区间 → 纸面矩形」只能在 `engine-skia` 做**（`LineAligner` 是 `internal`，只在渲染层可见）。
  用户层（`shared-ui`）只提供「章号 + 字符区间 + 样式」，消费结果。
- **持久标注烘焙进页面位图**：`contentRevision` 已是 `rememberPageContent`（`PageContent.kt:87/91/96/164`）
  与 `PageRasterKey` 的失效键 ⇒ 标注一改，bump 它，行与位图自动重画。位图池是**内存**的
  （`PageRasterStore`，非落盘）⇒ 无旧像素残留。翻页动画 / 预栅格 / 两级分辨率全部自然一致。
- **拖拽中的选区**不能每帧重烤（一页栅格 ~0.2s）⇒ 走**轻量覆盖层**路径，几何与烘焙同源，
  只是「即时画」而非「烘焙」。

### D-5 通道契约草案（渲染层定义，用户层消费）

```kotlin
// engine-skia（渲染层）：输入是章内字符区间 + 样式；输出是 DrawLine 上的行内 run
enum class DecorKind { BACKGROUND, UNDERLINE }   // 将来 OVERLINE / LINE_THROUGH

data class DecorRange(
    val start: Int,            // 章内字符偏移（与 ReadingLocator / PageSlice 同源）
    val endExclusive: Int,
    val kind: DecorKind,
    val argb: Int,
    val thicknessPx: Float? = null,
    val offsetPx: Float? = null,
    val priority: Int = 0,     // 叠加次序（例如选区压过标注）
)
```

- 归集的现成 seam：`styledSegments` 的每个 `StyledSegment` 都带 `node`（`StyledText.kt:55-60`），
  照 `collectUnderlineRuns` 的写法扩展即可。
- 绘制次序按规范：块背景 → 行内装饰背景 → 文字 → 下划线 / 着重号。

### D-6 存储 = SQLDelight 表（数据库），不用每书一个附件文件

- 新增一张标注表（终态表 + 一条迁移），与 `reading_states` 同源、同库、同事务。
- 形态（草案）：

  ```sql
  CREATE TABLE annotations(
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    bookId INTEGER NOT NULL,
    chapter INTEGER NOT NULL,
    charStart INTEGER NOT NULL,      -- 含
    charEnd INTEGER NOT NULL,        -- 不含（与 PageSlice 同口径）
    kind TEXT NOT NULL,              -- highlight / underline / note / ...
    color INTEGER,                   -- ARGB
    note TEXT,                       -- 批注文本（v2）
    createdAt INTEGER NOT NULL,
    updatedAt INTEGER NOT NULL
  );
  CREATE INDEX annotations_by_book_chapter ON annotations(bookId, chapter);
  ```

- 删书时与 `books` 同事务一并删除（不留孤儿）。
- **代价（已接受）**：标注不再是一个「用户可见、可随手拷走」的附件文件；
  将来导出「改过的 EPUB」要**另写一个导出器**（从库里取记录 → 生成补丁/新书），
  而不是像附件文件那样「天然就是补丁」。这是选 A 换取事务安全与查询便利的明账。
- **加一层接口**：读写走一个共享层的存储接口，DB 只是它的一个实现；
  将来若要做「可导出的附件」，在接口下再加一个实现，不必动上层。

### D-7 选区单位 = 英文按词、中文按句

- 英文「词」：文档空白 + 常规标点，撇号 / 连字符连缀。
- 中文「句」：以全角句末标点（`。！？…；` 等）断句，闭引号 / 闭括号归前句。
- **关键收益**：两者都**不需要分词器**，**不开平台 `BreakIterator` 缝**，纯共享层可做。
- 待细化：句末标点集合、换行是否算句边界。

### D-8 跨页 v1 必做；不跨章

- 交互模型：**拖手柄到页边缘 → 自动翻页并继续扩选**（移动端标准做法）。
- **手柄接力规则**：手指位置不动，翻页后手柄跳到**新页最靠近手指那一侧的行**，继续跟随手指。
- **不跨章**：拖到章末页边缘即停住（选区封顶到章末），保持「一条标注 = 一个章内区间」的模型。
- 存储不受影响：跨页只是**同一章内的区间变长**。
- 渲染：选区跨页时，每页只画该页与选区的**交集**；翻页动画期间选区覆盖层如何呈现，待细化。
- **架构约束**：自动翻页**不能**复用滑动翻页的手势会话（同一根手指正在拖手柄），
  需由选区逻辑驱动一条**独立的翻页路径**。

### D-9 桌面鼠标：只能拖选，不能拖动翻页

- 需要按**指针类型**分流（触摸 / 鼠标），而不是两套 `pointerInput` 硬抢。
- 鼠标**拖拽 = 文本拖选**（桌面最自然）；**不允许拖动翻页**。
- 鼠标**点击左右页边距**翻页（「页边空白区」= **左右页边距**；上下页边距不算）。
- 桌面翻页**主要依靠键盘**（左右箭头，现有能力）。
- 鼠标点**正文区**的行为**暂空着**（本轮不定义）。
- 触摸端的滑动翻页与三区点按**保留**（只改桌面鼠标）。
- 后果：桌面鼠标的**跟手滑动动画随之取消**（键盘与点击翻页仍走动画）。
- 分流按**指针类型**，不按平台——Android 平板接鼠标同样走鼠标语义。
- 实现注意：现有三区点按按屏宽 1/3 判定，桌面「点左右页边距翻页」要改成按**版心几何**
  （内容左/右缘之外的页边距区域）。

### D-10 放大镜：移动端要，桌面不要

- 纯**用户层**（shared-ui）实现：复用页栅格位图放大绘制，不涉及排版层与渲染核心。
- 待细化：触发时机（长按 / 拖手柄）、放大倍数、形态（圆形）、位置偏移。

### D-11 移动端：三区点按保留，长按进入选区

- 点按三区（左 1/3 后退 / 右 1/3 前进 / 中间切栏）**必须保留**——这是移动端的主要翻页方式。
- **长按**是进入选区的唯一入口；进入选区后，点按改为「清除选区」（不翻页）。
- 桌面无「长按」语义，改由鼠标拖选进入（见 D-9）。

### D-12 动画与选区互斥（时间维）

- 翻页动画 / 滑动会话进行中 → **不响应**长按与选区手势（现有 `ctl.isBusy()` 守卫扩用）。
- 选区手势进行中（长按起手 → 抬手，或按住手柄拖动）→ **不播任何翻页动画**；
  跨页翻页一律**瞬切**（要不要极短淡入见待决）。
- 选区**已存在但未在操作** → 翻页不受限（点按 / 滑动 / 键盘），翻页后选区保留，各页只画交集。
  - 触摸端例外（D-11）：有选区时**点按 = 清除选区**、不翻页 ⇒ 此时翻页走滑动或键盘。

### D-13 颜色体系：用户可自定义调色板

- 高亮与划线**各自一组色槽**（4–5 个）；每个槽的**颜色与透明度**（ARGB）由用户自定义。
- 两类各有一个**默认色槽**（新建标注时用它）。
- 归属：**全局**（`ReaderSettings`），跨书统一——与字体 / 主题同类。
- 记录存**解析后的 ARGB 快照**：改调色板**不回溯**已有标注（墨迹已干）。
- 颜色仍**不进 CSS 级联**（延续 D-2）：它是标注自身颜色，不是覆盖书样式的声明。
- 界面设计**待定**（色槽编辑、透明度滑条、默认色设置）。

### D-14 已有标注可编辑 / 删除（v1 必做）

- 入口：**长按已有标注 → 该标注的编辑菜单**（改色 / 删除）；长按空白 → 新建选区。
  语义统一为「长按 = 针对此处」。
- 跨页标注是一条记录，菜单作用于整条。

## 3. v1 交互规格（提案，实现前定稿）

> 下面这些是配套的量化细节，方向已认可，具体数值可在实现时微调。

### 3.1 长按与手柄

- 长按时长用系统的 `longPressTimeoutMillis`（Android ≈500ms），不自造。
- 长按后**手指不抬起、直接移动 = 扩选**；**抬手 → 出菜单 + 显示两端手柄**。
- 手柄：视觉圆点 ~12dp，**命中范围 ~44dp**；贴在选区首 / 末行下缘；贴屏幕边自动内移。
- 长按选中的单位按 D-7（英文词 / 中文句）。

### 3.2 浮动菜单

- v1 项：**高亮（展开色槽）/ 划线（展开色槽）/ 复制 / 取消**（批注 v2 再加）。
- 位置：选区上方；贴顶则放下方；跟随选区变化。
- 阅读层目前零 `Popup` 使用 ⇒ 需确定用 Compose `Popup` 还是自绘覆盖层（与栅格层同制）。

### 3.3 跨页自动翻页

- 触发：手柄进入距左 / 右页边 ≤ 24dp 并**持续 ≥ 300ms** → 翻一页；手指不放则每 400ms 再翻。
- 翻页**瞬切**（D-12），且**等目标页就绪再继续**（栅格 ~0.2s，不等会白一帧）。
- 到章末 → 停住（D-8 不跨章），并给提示（见 3.5）。

### 3.4 放大镜（移动端）

- 圆形，直径 ~96dp；倍数 ~1.5x；中心悬在手指**上方 ~56dp**；贴屏幕边自动内移。
- 内容复用页栅格位图放大绘制（`PageRasterStore.obtain`），**纯用户层**。
- 出现时机：长按开始 + 拖手柄时（跟随当前拖动的手柄）。

### 3.5 其它

- 章末停住提示：移动端轻触感；桌面一句 snackbar。
- 复制：内容 = 选区章内区间的**原文**（跨样式不带格式）；需新增宿主 `textOf(chapter, start, end)`
  与**剪贴板 expect/actual**（全仓目前零剪贴板代码）。复制后保留选区并提示「已复制」。
- 桌面键盘扩选（Shift+箭头）v1 不做。
- 高亮默认以 **~45% 不透明度**铺背景（荧光笔感）；划线粗细 / 位置刻意与书内下划线错开
  （更粗 ≥0.08em、更靠下），避免与书自带的线糊在一起。

## 4. 待决事项（讨论中）

1. **视图模式状态位**：`CLEAN` / `REVIEW` 表示「当前用哪种视图显示这本书」；
   `REVIEW` 才连同将来的内容修改一起显示。v1 恒为 `CLEAN`、不暴露界面，为 v3 预置位置。
   待定：**归属全局还是按书**、是否持久化。
2. **改调色板是否回溯已有标注**：D-13 定为「存快照、不回溯」，是否需要「应用到已有」按钮。
3. **颜色设置界面**：色槽编辑、透明度、默认色的形态。
4. **鼠标点正文区**的行为（D-9 暂空）。
5. **跨页翻页要不要极短淡入**（D-12 瞬切之外的备选）。
6. **垂直滚动 / 竖排模式**：均未实现；将来上线时选区需另行适配（v1 只服务翻页模式）。
