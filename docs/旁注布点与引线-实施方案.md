# 旁注布点与引线：实施方案（2026-10-23）

> 本文是旁注布点与引线的**唯一现行方案**：布点、分配、引线三部分全部按本文实现，
> 不沿用任何此前的排序键、判据或引线形态。
>
> 状态：**Step 0 文档完成，Step 1 起待做**。

## 0. 口径（2026-10-23 用户定稿）

### 0.1 布点评分：扣分制

1. **综合分数，扣分制**：右、折行、距离、下、上、左各设罚分，距离越远扣得越多，总分最低者胜。
2. **右侧的空白通常最大，优先级压过「单行」**：不再给「同一行单行」单独的优先级；
   行尾只够几个字的小缝会被「截断罚分」压下去，让整句放得下的右侧空白（含右侧页边距）胜出。
3. **标注本身占空白**：已放好的旁注框要进入障碍表，后面的标注不得重叠、不得紧贴。
4. **标注与文字之间要留 margin**：默认 **1em**；**放在所选文字右侧时要更远**（要画水平箭头），
   取 **1.8em**。
5. **标注的最终宽度要综合字体、字号、行距、margin 计算**：不是「整句宽和空白宽取小」这么粗，
   而是先算整句所需宽度，再看这块空白扣掉 margin 后够不够；够就单行、按文字宽收窄，
   不够才按可用宽折行，并据此得到行数与高度。

### 0.2 空白区怎么取位

1. **上方的标注**：优先用空白矩形的**底部**（离下方文字最近）。
2. **下方的标注**：优先用空白矩形的**顶部**（离上方文字最近）。
3. **左右两侧的标注**：**垂直居中于锚点整段**（多行时取整段并集中心）；空白装不下时在空白内 clamp。
4. 其余同栏空白：取离锚点最近的位置。

### 0.3 标注之间的先后

候选（最近距离）更近的先挑；一样近，**文字更长（字数更多）的先挑**（占地大，先给它选）；
前两者都相同，按正文流顺序（锚点自上而下，同高按 id）。
先挑者拿走自己的位置，后来者只能让位，**不做两两互换**。

### 0.4 引线与箭头

按「所选正文」和「标注文字」的相对关系换线型：

1. **标注完全在右侧**：
   - 与所选文字之间**没有别的文字**：直线，接**标注左侧边的垂直中点**与**文字右侧中点**；
   - 中间隔着字：**弧线**，从**标注左下角**连到**正文右下角**。
2. **标注完全在左侧**：直线从**标注右侧中点**连**文字左侧**；被字挡住时用弧线绕。
3. **标注与文字在水平方向重叠**：从两者**最近的位置**拉直线。
4. **标注偏上**：从**标注底部**指向**文字上部**；**标注偏下**：方向相反（从标注顶部指向文字下部）。
5. 「没有别的文字隔开」只用于**右侧标注**，指标注与所选文字之间没有其他文字。
6. 两端必须接住：起点在标注框边界上，终点在所选文字的墨迹边界上，**中间不留缝**；
   箭头尖在文字一侧。
7. 换线型的触发是「线路中间会与其他文字、标注、图等内容重叠」；避让对象是逐字墨迹、图形、
   表格、线条、其他标注框。块底色、`padding` / `margin`、页边距仍算空白。
8. 除小图标形态外**必须画**：直线 → 弧线 → 一折 → 两折 → 三折 → 「压字最少、再最短」照画。

## 1. 扣分制评分模型

### 1.1 单位与罚分表

一切距离以**旁注行高** `u = 旁注字号 × 1.38` 为单位，避免不同 DPI / 字号下分数漂移。

| 项 | 罚分 | 说明 |
|---|---|---|
| 侧别 · 右 | `0` | 第一优先；右侧页边距与版心内右侧空白同权 |
| 侧别 · 下 | `2` | 同栏、锚点下方 |
| 侧别 · 上 | `3` | 只有下方没有可用空白才启用 |
| 侧别 · 同栏其他 | `4` | 斜向、被文字挤出的空隙 |
| 侧别 · 左 | `6` | 最后退路 |
| 距离 | `边到边距离 / u` | 框到锚点**最近一行墨迹**的边到边距离 |
| 截断 | `+6` | 整句放得下不扣；截断（含省略号）扣 6u |
| 小图标 | 不入评分 | 一条都分不到时的兜底形态 |

**总分 = 侧别罚分 + 距离罚分 + 截断罚分**，取最小。

解读（也是本轮要的「右侧压过单行」）：

- 右侧行尾只够 4 个字的小缝：距离约 `0.5u`，但截断 `+6u` ⇒ 约 `6.5u`；
- 右侧页边距能整句放下：距离约 `1.5u`，不截断 ⇒ 约 `1.5u`，**稳赢**；
- 下方贴边整句：`2 + 0.5 = 2.5u`，仍输给右侧整句（`1.5u`），但赢过行尾小缝；
- 左侧整句：`6 + 距离`，只有在右侧 / 下方 / 上方都排不下时才可能胜出。

截断罚分 `6u` 是「整句优先」和「不许为完整远走」的交界：整句空白在 6u 以内就压过近处截断，
超过 6u 才让位给就近截断。四个常数集中在 `NoteLayout` 一处，真机可调。

### 1.2 同分决胜

`(总分, 距离, 框上边, 框左边, annotationId)` 依次比较，保证同一输入结果恒定。

### 1.3 单行不再是独立优先级

「同一行单行」只是宽度计算的结果：整句在可用宽内放得下就一行，放不下才折行。
侧别与截断罚分已经承担了「大块空白压过行尾小缝」的取舍，因此**不再给单行加分或减分**。

## 2. 空白与障碍

### 2.1 障碍集合

| 类别 | 来源 | 用于布点 | 用于引线 |
|---|---|---|---|
| 文字（行框） | 逐字墨迹合并成行 | ✅ | — |
| 文字（逐字墨迹） | 渲染层只读几何 | — | ✅（可穿两字之间） |
| 图形 / 背景图 | `pageImages`、整盒背景图 | ✅ | ✅ |
| 表格 | 框线 + 单元格文字 | ✅（整体几何仍缺，登记） | ✅ |
| 线条 / 描边 | `pageBackgrounds` 的边框带 | ✅ | ✅ |
| 列表圆点 / 编号 | `DrawLine.listMarker`（行属性） | ✅ | — |
| 已放好的旁注框 | 本页分配结果 | ✅ | ✅ |

块底色、`padding` / `margin`、行距、行右侧未排满处、首行缩进、四边页边距**都算空白**。

### 2.2 极大空闲矩形

- 页面边界 = 整页（含四边页边距），四周各留 `0.5em`，避免框贴屏幕边；
- 障碍按 **margin（1em）外扩**后做极大空闲矩形（MaxRects），等价于「框与障碍至少隔 1em」；
- 已放旁注框按同一 margin 外扩；
- 候选框互不重叠是硬约束（分配阶段再校验一次）。

### 2.3 表格整体

表格整体矩形仍缺只读几何，本轮维持「框线 + 单元格文字」避让，**不按表格整体矩形**处理；
登记在 D-29 前置里，不阻塞本轮。

## 3. 候选框尺寸（字体 / 字号 / 行距 / margin）

```
em      = 正文主字号 × 0.72            // 旁注字号；取本页正文按行内字数加权的主字号
lineH   = em × 1.38                    // 旁注行高
padX    = em × 0.35                    // 单侧内缩（排版与绘制同源）
margin  = em × 1.0                     // 标注与障碍、标注与标注
sideGap = em × 1.8                     // 右侧标注与所选文字的距离（留给水平箭头）
```

计算顺序（每个「批注 × 空白」）：

1. `desired = 整句宽 + 2 × padX`（整句宽用与绘制同源的估算，不另造尺子）；
2. `available = 空白宽 − margin − 靠文字那一侧的间距`（右侧候选用 `sideGap` 代替该侧 `margin`）；
3. `desired ≤ available` ⇒ **单行**，框宽 = `desired`；
   否则 ⇒ **折行**，框宽 = `available`，行数 = `ceil(整句宽 / (available − 2 × padX))`；
4. 行数受空白高约束：`capacity = floor((空白高 − 2 × margin) / lineH)`；
5. 显示字数 ≥ 4（整句不足 4 字按整句）才保留候选；`显示字数 == 总字数` 为完整，否则截断；
6. 框高 = 实际行数 × `lineH`。

**宽度是「文字 + 字体 + 行距 + margin」一起算出来的**：同一段文字在不同宽度的空白里得到
不同的行数 / 高度 / 完整度，评分时用的就是这套最终尺寸，不再拿估算宽当分数依据。

## 4. 空白内取位

以「锚点墨迹并集」与空白矩形的关系取位：

| 关系 | 水平 | 垂直 |
|---|---|---|
| 上方（空白底边 ≤ 锚点顶边） | 锚点中心，clamp 在空白内 | `y = 空白底边 − margin − 框高`（**贴空白底部**） |
| 下方（空白顶边 ≥ 锚点底边） | 同上 | `y = 空白顶边 + margin`（**贴空白顶部**） |
| 右侧（空白在锚点右侧，且纵向有交集） | `x = max(空白左边 + margin, 锚点右边 + sideGap)` | 垂直中心对准**锚点整段并集**的中心；空白装不下时 clamp 进空白 |
| 左侧（空白在锚点左侧，且纵向有交集） | `x = min(空白右边 − margin, 锚点左边 − margin)` | 同上 |
| 同栏其他 | 最近边取位 | 最近边取位 |

- 「垂直居中」以**锚点整段并集**的中心为基准（多行锚点不做「逐行最近」）。
  空白的纵向范围通常只覆盖锚点的一部分，因此居中点会先被 clamp 进空白：
  - **锚点跨两行以上时，正文大多已经排满页宽**，右侧只在**末行**之后才空出来 ⇒
    框自然落在末行高度上（这就是用户要的结果，不需要额外规则）；
  - 如果空白是整段高的页边距，clamp 不生效，框就落在**段落正中**。
  两种结果都由「整段中心 + clamp」自然得到，不另设分支。
- 右侧优先：同一块右侧空白里，先试单行，再试折行；折行后不足 4 字就放弃这块，
  交给下方 / 上方，不硬塞行尾小缝。

## 5. 分配（谁先挑、单向让位）

1. **先挑顺序**：最近候选距离更小 → 批注文字更长（字数多）→ 正文流顺序（锚点 top、id）。
2. **单向让位**：按上述顺序各取自己分数最低、且不与已选框冲突（含 margin）的候选；
   先挑者永不被挤走；**不做两两互换**。
3. 每放好一条，立刻把它的框（外扩 margin）加入障碍表；后续标注的候选不得与之重叠。
4. 页边距同侧的框再按锚点纵序做一次一维排布（间距 = 1em），避免同一页边距里叠在一起。
5. **一条都分不到**（或所有候选项都显示不足 4 字）：在原文墨迹**右下角外侧**画小省略号图标，
   不重叠、不压字、不画箭头、不参与其他标注的避让。

## 6. 引线

### 6.1 关系判定（顺序固定，四类互斥）

```
若 框与锚点墨迹的「水平投影重叠 ≥ 1px」:
    框中心在锚点中心上方 ⇒ 上方；否则 ⇒ 下方        // 走「垂直规则」
否则若 框完全在锚点右侧（框左边 ≥ 锚点右边）:
    右侧                                          // 走「右侧规则」
否则若 框完全在锚点左侧（框右边 ≤ 锚点左边）:
    左侧                                          // 走「左侧规则」
否则:
    同栏其他 / 斜向                                // 归侧边规则，起点取朝正文的角
```

「水平重叠」用投影长度判断，不用中心点，避免「斜靠」被误判。

### 6.2 线型与端点

| 关系 | 首选 | 起点 | 终点 |
|---|---|---|---|
| 右侧 · 无字隔开 | 水平直线 | 标注左侧边垂直中点 | 文字右侧中点 |
| 右侧 · 有字隔开 | 贝塞尔弧 | 标注左下角 | 正文右下角 |
| 左侧 · 无遮挡 | 水平直线 | 标注右侧边垂直中点 | 文字左侧中点 |
| 左侧 · 有遮挡 | 贝塞尔弧 | 标注右侧边中点 | 文字左侧（近端） |
| 上方 | 垂直直线 | 标注底边中点 | 文字顶边（近端字） |
| 下方 | 垂直直线 | 标注顶边中点 | 文字底边（近端字） |
| 水平重叠 / 斜向 | 最近点直线 | 两框最近点 | 两框最近点 |

- **「无字隔开」判据**：起点到终点的线段与任一障碍（逐字墨迹 / 图 / 表 / 线 / 其他标注框）
  不相交（贴边不算）；右侧专用，左侧按同一判据决定直线或弧线。
- **弧线**：三次贝塞尔，两控制点沿弦的 1/3、2/3 处向**远离障碍**的一侧偏移，
  拱高上限 `min(0.3 × 弦长, 2u)`；不越过遮挡就加大拱高再试，最多三档。
- **折线兜底**：一折（先竖后横 / 先横后竖）→ 两折 → 三折（4 段）；
  拐点取端口与附近障碍边界坐标，最后取「压字最少、再最短」照样画。
- **两端必须接住**：起点落在标注框边界上、终点落在锚点字墨迹边界上（gap = 0）；
  起点优先在朝正文那条边，被挡才换到角或邻边。
- **箭头尖**在文字一侧，方向沿末段（弧线取终点处切线）。

### 6.3 避让与必画

- 逐字墨迹（自己的锚点字除外）：容差 0.5px；
- 图形 / 表格 / 线条 / 其他标注框：容差 1px；
- 已画引线：只做交叉惩罚（尽量不交叉，不硬堵死）；
- 不得拐回自己的标注框；
- **除小图标外不返回空**：所有形态全撞时取「穿得最少 → 最短」的一条画出。

## 7. 全流程

```
输入：批注[]（文字、锚点墨迹、逐字墨迹、颜色）+ 四类障碍 + 页面/版心几何
  │
  ├─ A. 尺寸：em / lineH / padX / margin / sideGap（§3）
  ├─ B. 障碍：行框 + 图 + 表 + 线 + 列表圆点，按 margin 外扩
  ├─ C. 空白：MaxRects 算整页极大空闲矩形（含四边页边距）
  ├─ D. 候选：每条批注 × 每块空白 → 取位（§4）→ 算宽/行数/高 → 完整/截断
  │        score = 侧别罚分 + 距离/u + 截断罚分
  ├─ E. 分配：近 → 长 → 顺序；单向让位；放好的框进障碍；排不下 → 小图标
  ├─ F. 引线：关系判定（§6.1）→ 直线 / 弧线 / 折线 → 全撞也画
  │
  └─ 输出：NoteBubble[]（位置、尺寸、行数、颜色、箭头）
```

`noteBubblePlacements(...)` 仍是纯函数；只读几何，不进分页、不进栅格，翻页动画期间整层让位。

## 9. 测试计划（摘）

### 9.1 尺寸

| 用例 | 断言 |
|---|---|
| 短句 + 宽空白 | 单行，框宽 = 整句宽 + 2×padX |
| 长句 + 窄空白 | 折行，框宽 = 空白宽 − 2×margin，行数正确 |
| 窄空白不足 4 字 | 不产生候选，交给下级或小图标 |
| 同一段文字换空白宽 | 单行 / 折行 / 截断三档稳定复现 |

### 9.2 取位与评分

| 用例 | 断言 |
|---|---|
| 右侧页边距整句 vs 行尾 4 字小缝 | 选右侧页边距 |
| 下方贴边整句 vs 左侧整句 | 选下方 |
| 上方空白存在但下方也有 | 选下方 |
| 空白高度不足居中 | clamp 进空白，仍不越界 |
| 多行锚点、只有末行右侧有空白 | 框落在末行高度（整段中心被 clamp） |
| 多行锚点、整段高的页边距 | 框落在段落正中 |
| 同一输入两次 | 结果完全相等 |

### 9.3 分配

| 用例 | 断言 |
|---|---|
| 两条竞争同一块空白 | 近的先挑；一样近长的先挑；先挑者不动 |
| 已放旁注框 | 后一条不重叠、不紧贴 |
| 满页 | 小图标，不消失 |
| 同锚点两条 | 页边距里上下排开 |

### 9.4 引线

| 用例 | 断言 |
|---|---|
| 右侧无字 | 水平直线，起终点在框边与字墨迹边 |
| 右侧隔字 | 弧线，不穿字，两端接住 |
| 左侧无遮挡 / 有遮挡 | 直线 / 弧线 |
| 水平投影重叠 · 标注在上 / 在下 | 从底边 / 顶边出发的垂直线 |

| 折线兜底 | 一折 → 两折 → 三折，最多 4 段 |
| 全封死 | 仍返回箭头，不返回 null |

## 11. 风险与退路

| 风险 | 退路 |
|---|---|
| 扣分常数在不同 DPI / 字号下漂移 | 距离一律以旁注行高归一；常数集中一处，真机只调这一处 |
| 截断罚分 6u 太大 / 太小 | 真机看「整句 vs 就近」的取舍，调 `NOTE_TRUNC_PENALTY` |
| 1em margin 让窄页边距放不下 | 右侧页边距本来就宽，先看是不是被障碍误判；确需才降到 0.75em |
| 弧线拱高不足绕不开 | 拱高三档递增，再不行走折线，最后压字最少照画 |
| 左侧总被用到 | 查右侧 / 下方是否漏了候选（多为障碍外扩把可用宽吃光） |
| 标注互相挤 | 放好的框按 margin 外扩进障碍，且先挑顺序固定 |
| 表格整体缺几何 | 维持框线 + 单元格文字避让，登记 D-29 前置 |
