> 不沿用任何此前的排序键、判据或引线形态。

## 0. 口径（2026-10-23 用户定稿）

### 0.1 布点阶梯：由近到远 + 固定方向顺序（2026-10-23 四稿，用户定口）

一条批注的候选位置按下面顺序**逐格尝试**；前一步放得下**整句**，就绝不再往后看：

1. **所选行右侧**（末行优先，末行放不下再逐行向上）：
   先试整句单行；单行放不下、折成几行能放下，仍放右侧；
2. **紧邻的右下方**：单行不行就折行；
3. **紧邻的右上方**（同样单行 → 折行）；
4. **紧邻的正下方**（右侧不可用才看这里）；
5. **紧邻的正上方**；
6. **隔 1 行**：右下 → 右上 → 下 → 上；
7. **隔 2 行、隔 3 行……** 同样四向顺序，直到锚点所在**段 / 块**的边界；
8. **本段 / 本块内由近到远的其余位置** ——**这时才允许用左侧页边距**；
9. **相邻段 / 块**，仍由近到远，右下 → 右上 → 下 → 上 → 左；
10. 以上位置**都只能截断才放得下**时，才进**截断档**：按同一顺序允许省略号，
    至少显示 **4 个字**；
11. 连 4 个字都放不下（或整页确实没有空白），在所选文字**右下角**放一个**小椭圆「…」**：
    宽约 **0.5em**、高度再小些，点开即批注，**不画箭头、不参与其他标注的避让**。

- 「紧邻」「隔 n 行」都以**正文行**为单位（一行一行数），不是「若干像素」。
- **同一行有多条批注（2026-10-24 真机反馈修订）**：不再并排占行尾，改为**竖向成组**——
  先按同一列宽把每条的高度算出来，整组放得进上方就放上方、否则放下方；
  上方时最右的排最下、最左的排最上，下方时最右的排最上，这样引线不会交叉。
  两边都放不下整组时不抢位，交给各自的阶梯逐条处理。
- **整句永远压过截断**：截断档不是「这条批注自己试到最后就截断」，而是**全页所有批注的
  整句档都试完**之后，才对仍没位置的批注统一开截断档（§1.4）。
- 左侧是最后退路：本段内靠右 / 上下都放不下才看左侧；相邻段落里同理。
- **多行选区以末行为基准行**：只有第 1 步（右侧）会逐行向上多试几次；
  右下 / 右上 / 下 / 上以及后面各环都以末行为基准。

### 0.2 空白区怎么取位

1. **右侧**：垂直居中于**该行**（先末行，末行放不下再逐行向上），水平贴该行文字右缘 + 1.8em；
   空白装不下时在空白内 clamp。
2. **右下 / 右上**：贴锚点的**右下角 / 右上角**，贴不下才在空白内挪；
   框左边与所选文字只隔横向 `marginX`（**0.1em**）。水平箭头的空档只有「放在所选文字右侧」
   那一种摆法需要，由 `sideGap` 单独给；右下 / 右上走斜线或折线，不必白留一格。
3. **正下 / 正上**：贴锚点**底边 / 顶边**，水平与锚点对齐；若批注比所选文字长、紧贴后只剩一条
   短竖线，同一侧再远一行还有整句位置时就放远一行（2026-10-24 真机反馈第 5 条）。
4. **左侧**：垂直居中于该行，贴该行文字左缘（**本段用尽后才允许**）。
5. 其余同段 / 邻段空白：空白内离锚点最近的一角。

一律**贴住锚点**：不为了「居中」把框推到离原文很远的地方。

### 0.3 标注之间的先后

1. **同一行先成组**：按正文行分组，行自上而下；组内**从右到左**（锚点靠行尾的先挑），
   先按 §0.1 的「同一行多条」整行判一次右侧；
2. 组内 / 组间都**先占先得**：每条按自己的阶梯取第一个可用位置，后来者只能跳过，
   **不做两两互换**；
3. **三个档位是全页统一推进的**：先让所有批注跑「整句档」，再让剩下的跑「截断档」，
   最后剩下的才退成小椭圆（§1.4）；
4. 同一输入结果恒定（排序键不用浮点近似）。

### 0.4 引线与箭头

按「所选正文」和「标注文字」的相对关系换线型：

1. **标注完全在右侧**：
   - 与所选文字之间**没有别的文字**：直线，接**标注左侧边的垂直中点**与**文字右侧中点**；
   - 中间隔着字：**正交折线**绕开（2026-10-24 真机反馈第 2 条：不再用弧线）。
2. **标注完全在左侧**：直线从**标注右侧中点**连**文字左侧**；被字挡住时用正交折线绕。
3. **标注与文字在水平方向重叠**：从两者**最近的位置**拉直线。
4. **标注偏上**：从**标注底部**指向**文字上部**；**标注偏下**：方向相反（从标注顶部指向文字下部）。
5. 「没有别的文字隔开」只用于**右侧标注**，指标注与所选文字之间没有其他文字。
6. 两端必须接住：起点在标注框边界上，终点在所选文字的墨迹边界上，**中间不留缝**；
   箭头尖在文字一侧。
7. 换线型的触发是「线路中间会与其他文字、标注、图等内容重叠」；避让对象是逐字墨迹、图形、
   表格、线条、其他标注框。块底色、`padding` / `margin`、页边距仍算空白。
8. 除小椭圆形态外**必须画**：直线 → 一折 → 两折 → 三折 → 「压字最少、再最短」照画；
   全程只用折线，没有弧线。

## 1. 阶梯的执行口径

### 1.1 环与方向

| 环 | 范围 | 环内位置顺序 |
|---|---|---|
| 0 | 锚点**末行** | ①该行右侧（末行 → 逐行向上）②右下 ③右上 ④正下 ⑤正上 |
| 1…n | 距锚点行 n 条正文行 | 右下 → 右上 → 下 → 上 |
| 段内其余 | 同段 / 同块的剩余空白 | 由近到远；**含左侧** |
| 相邻段 | 其他段 / 块 | 由近到远；**含左侧** |

- **右下**：框左边 ≥ 该行文字右缘（留 `marginX`），框顶边在该行下方；
  **右上**：同上，框底边在该行上方；
  **下 / 上**：框与该行在水平方向有重叠；
  **右侧**：框左边 ≥ 该行文字右缘，垂直居中于该行（空白不够高才在空白内 clamp）。
- 环号 = 框最近的一行与锚点末行之间隔了几条**正文行**（同一条行算 0）。
- 取位一律**贴住锚点**：右下贴锚点的右下角、右上贴右上角、下 / 上贴对应边，
  贴不下才在空白内 clamp；**不为了居中把框推到远处**。

### 1.2 「放得下」的三档

| 档 | 判据 | 什么时候跑 |
|---|---|---|
| **整句** | 折行后能显示**全部**字数 | 第一轮：全页所有批注 |
| **截断** | 显示 ≥ **4 个字**（整句不足 4 字按整句） | 第二轮：整句档全部失败后，剩下的批注 |
| **小椭圆** | —— | 第三轮：截断档也失败 |

- 框尺寸按 §3 由字号 / 行距 / margin 算出，不用估算宽直接比。
- 「放得下」同时要满足：不与文字、图形、表格、线条、**已放好的旁注框**相交，
  四周间距 ≥ 0.1em，右侧与所选文字 ≥ 1.8em（留给水平箭头），且框在页面内（离屏幕边 0.5em）。
- 块底色、`padding` / `margin`、行距、行右侧未排满处、四边页边距**都是空白**。

### 1.3 同一行多条

1. 按正文行分组，组内先按同一列宽把每条的高度算出来；能折行就折，不急着截断。
2. **优先整体**：整组高度放得进上方就放上方，否则放下方；两边都放不下就整组不抢位，
   交给各自的阶梯逐条处理。
3. 上方成组：**最左的锚点排最上、最右的排最下**；下方成组：**最右的排最上、最左的排最下**。
   框与框之间留纵向 `marginY`，同一列左边对齐。
4. 下方成组时，第一条（最右）尽量留在「行右侧」原位，先挑者的位置不被后来者挤走；
   其余按锚点次序往下排。
5. 占不到的批注仍走自己的阶梯，不回抢这一行的同一列。

### 1.4 三档推进与单向让位

1. **档位是全页统一推进的**：先把所有批注的「整句档」跑完，再开「截断档」，
   最后剩下的才退成小椭圆——**不允许某一条批注自己先截断、把位置抢下来**。
2. 同一档内，顺序为：**正文行自上而下 → 行内从右到左**；先占先得。
3. 已放好的框立即进障碍表（含 margin 外扩）；后到的批注只能跳过，**不做两两互换**。
4. 同一输入结果恒定：排序键只用整数 / 稳定坐标，不用浮点近似。

### 1.5 段 / 块边界

- 渲染层给**每一行**带上所属块序号（同一叶 / 同一块的各行同号），用户层按它分组；
  这是 Step 9 的前置改动（`DrawLine` 加一个字段，不动排版与分页）。
- 块序号缺失时（旧数据 / 单测只给行框）退化为**行距断段**：与上一行的间隙大于
  上一行行高的 **1.5 倍**即视为换段。
- 段界只决定第 7 → 8 → 9 步的先后（本段内用完才去相邻段），不影响「整句 / 截断」两档。

### 1.6 小椭圆（最后的兜底）

- **视觉尺寸**：宽约 **0.5em**、高约 **0.32em** 的椭圆（最小 1dp），里面一个「…」；
  比以前 1.5em 的圆点小得多，不抢正文。
- **位置**：划线 → 线右端下方；高亮 → 高亮区**右下角**外侧，间隔 0.1em，**不压字**。
- **点击热区**单独向外扩到不小于 1.2em × 1.2em（透明），视觉尺寸不变。
- **不画箭头、不进障碍表**（不挡别的旁注）；同一锚点掉出多个小椭圆时，沿右下角向下错开一个图标高。
- 整页确实没有空白时宁可只留小椭圆，也不压字硬塞。

## 2. 空白与障碍

### 2.1 障碍集合

| 类别 | 来源 | 用于布点 | 用于引线 |
|---|---|---|---|
| 文字（行框） | 逐字墨迹合并成行 | ✅ | — |
| 文字（逐字墨迹） | 渲染层只读几何 | — | ✅（可穿两字之间） |
| 图形 / 背景图 | `pageImages`、整盒背景图 | ✅ | ✅ |
| 表格 | 框线 + 单元格文字 | ✅（整体几何仍缺，登记） | ✅ |
| 线条 / 描边 | `pageBackgrounds` 的边框带 | ✅ | ✅ |
| 列表圆点 / 编号 | `DrawLine.listMarker`（行属性） | ✅ | — |
| 已放好的旁注框 | 本页分配结果 | ✅ | ✅ |

块底色、`padding` / `margin`、行距、行右侧未排满处、首行缩进、四边页边距**都算空白**。

### 2.2 极大空闲矩形

- 页面边界 = 整页（含四边页边距），四周各留 `0.5em`，避免框贴屏幕边；
- 障碍按 **margin（四周 0.1em）外扩**后做极大空闲矩形（MaxRects），
  等价于「框与障碍至少隔 0.1em」；
- 已放旁注框按同一 margin 外扩；
- 候选框互不重叠是硬约束（分配阶段再校验一次）。

### 2.3 表格整体

表格整体矩形仍缺只读几何，本轮维持「框线 + 单元格文字」避让，**不按表格整体矩形**处理；
登记在 D-29 前置里，不阻塞本轮。

## 3. 候选框尺寸（字体 / 字号 / 行距 / margin）

```
NoteStyle（可配，批注样式 D-29 落地的接口）
  fontPx          = 正文主字号 × 0.72   // 默认值；字号可单独设置
  fontFamily      = null                // 默认跟随界面；批注样式从这里进来
  lineHeightRatio = 1.38
  padEm           = 0.35
  marginXEm       = 0.1                 // 横向留白（只有右侧摆法另给 sideGap）
  marginYEm       = 0.1                 // 纵向留白
  sideGapEm       = 1.8
  edgeEm          = 0.5

em      = style.fontPx                 // 旁注字号
lineH   = em × lineHeightRatio         // 旁注行高
padX    = em × padEm                   // 单侧内缩（排版与绘制同源）
marginX = em × marginXEm               // 标注与障碍、标注与标注的横向距离
marginY = em × marginYEm               // 同上，纵向
sideGap = em × sideGapEm               // 右侧标注与所选文字的距离（留给水平箭头）
edge    = em × edgeEm                  // 离屏幕边的距离
```

样式只影响旁注自己，不改正文排版；将来「批注样式」设置页只替换 `NoteStyle`，
布点与引线的代码不跟着改。

计算顺序（每个「批注 × 空白」）：

1. `desired = 整句宽 + 2 × padX`（整句宽**实测**：与绘制同一套文字测量，见下）；
2. `available = 空白宽 − marginX − 靠文字那一侧的间距`（右侧候选用 `sideGap` 代替该侧 `marginX`）；
3. `desired ≤ available` ⇒ **单行**，框宽 = `desired`；
   否则 ⇒ **折行**，框宽 = `available`，行数由实测折行结果给出；
4. 行数受空白高约束：`capacity = floor((空白高 − 2 × marginY) / lineH)`；
5. 显示字数 ≥ 4（整句不足 4 字按整句）才保留候选；`显示字数 == 总字数` 为完整，否则截断；
6. 框高 = 实际行数 × `lineH`。

**宽度是「文字 + 字体 + 行距 + margin」一起算出来的**：同一段文字在不同宽度的空白里得到
不同的行数 / 高度 / 完整度，布点时用的就是这套最终尺寸，不再拿估算宽当判据。

> **整句宽必须实测，不能按「一个字多宽」粗估。** 粗估哪怕只窄一两个像素，摆位就会判成
> 「整句放得下」、画出来却被 `Text` 补一个省略号——真机上是「整页都是空白，批注却折成两个字」。
> 实测用的是绘制那条 `Text` 真正吃的字号 / 行高 / 基础样式（含字距），并在整句宽里留出
> 绘制侧「框宽与内缩各自取整」的 1px 损耗；折行与「能读几个字」也按实测行数与可见末字判定。
> 粗估实现只保留给纯逻辑单测，不参与真机布点。

## 4. 空白内取位

§0.1 / §1.1 决定「试哪一块空白、试哪个方向」，本节只负责在这个方向下把框摆正：

| 关系 | 水平 | 垂直 |
|---|---|---|
| 右侧（同一行） | `x = max(空白左边 + marginX, 该行文字右缘 + sideGap)` | 垂直**居中于该行**；空白装不下时 clamp |
| 右下 | 左边贴「该行文字右缘 + marginX」；右边不够再贴空白右缘向左展开 | `y = 该行底边 + marginY`（贴该行下方） |
| 右上 | 同上 | `y = 该行顶边 − marginY − 框高`（贴该行上方） |
| 正下 | 水平与锚点对齐，空白不够就 clamp | `y = 锚点底边 + marginY` |
| 正上 | 同上 | `y = 锚点顶边 − marginY − 框高` |
| 段内 / 相邻段其余 | 空白内离锚点最近的一角 | 同左 |

- 「垂直居中」以**这一行**为基准：第 1 步就是所选**末行**，末行放不下再逐行向上。
  不再以「整段并集中心」为基准——那会让多行选区的旁注跑到段落正中，离正在读的行很远。
- 一行右侧的空白通常不够高：框高超过空白高度就 clamp，仍不够就折行 / 换方向，不越界。
- **贴边优先**：右下 / 右上先贴锚点那一角，只有贴不下才在空白内挪；不为了居中把框推到远处。
- 同一块右侧空白里，先试单行，再试折行；折行也放不下整句就按阶梯往后走（§0.1 第 2 步起）。

## 5. 分配（三档推进、单向让位）

1. **分组**：按正文行把批注分组（多行选区归入**末行**），行自上而下，组内从右到左
   （锚点靠行尾的先挑）。
2. **第一档（整句）**：
   - 先按 §1.3 处理「同一行多条」——全员单行放右侧，放不下就从右到左逐条占（单行 → 折行）；
   - 这一行右侧没占到的，从阶梯第 2 步（紧邻右下）起按 §1.1 的环与方向继续找；
   - 每一步都要求**整句**放得下；整句放不下的位置直接跳过，**不在这一档截断**。
3. **第二档（截断）**：第一档跑完全页后，仍没位置的批注按同一顺序再找一遍，
   这次允许省略号，但至少显示 **4 个字**。
4. **第三档（小椭圆）**：第二档仍没位置的，在锚点右下角退成小椭圆（§1.6）。
5. **单向让位**：先占者永不被挤走；每放好一条立即把框（外扩 margin）加入障碍表；
   **不做两两互换**。
6. **一维排布**：同一侧页边距里最终落下的框，仍按锚点纵序做一次上下 / 左右排布
   （间距 `marginY` / `marginX`），避免贴在页边距里的两条叠在一起；排布不得把框推回障碍上。
7. **确定性**：同一输入两次结果完全相等（排序键只用锚点位置、块号、行号、批注 id）。

## 6. 引线

### 6.1 关系判定（顺序固定，四类互斥）

```
若 框与锚点墨迹的「水平投影重叠 ≥ 1px」:
    框中心在锚点中心上方 ⇒ 上方；否则 ⇒ 下方        // 走「垂直规则」
否则若 框完全在锚点右侧（框左边 ≥ 锚点右边）:
    右侧                                          // 走「右侧规则」
否则若 框完全在锚点左侧（框右边 ≤ 锚点左边）:
    左侧                                          // 走「左侧规则」
否则:
    同栏其他 / 斜向                                // 归侧边规则，起点取朝正文的角
```

「水平重叠」用投影长度判断，不用中心点，避免「斜靠」被误判。

### 6.2 线型与端点

| 关系 | 首选 | 起点 | 终点 |
|---|---|---|---|
| 右侧 · 无字隔开 | 水平直线 | 标注左侧边垂直中点 | 文字右侧中点 |
| 右侧 · 有字隔开 | 贝塞尔弧 | 标注左下角 | 正文右下角 |
| 左侧 · 无遮挡 | 水平直线 | 标注右侧边垂直中点 | 文字左侧中点 |
| 左侧 · 有遮挡 | 贝塞尔弧 | 标注右侧边中点 | 文字左侧（近端） |
| 上方 | 垂直直线 | 标注底边中点 | 文字顶边（近端字） |
| 下方 | 垂直直线 | 标注顶边中点 | 文字底边（近端字） |
| 水平重叠 / 斜向 | 最近点直线 | 两框最近点 | 两框最近点 |

- **「无字隔开」判据**：起点到终点的线段与任一障碍（逐字墨迹 / 图 / 表 / 线 / 其他标注框）
  不相交（贴边不算）；右侧专用，左侧按同一判据决定直线或弧线。
- **弧线**：三次贝塞尔，两控制点沿弦的 1/3、2/3 处向**远离障碍**的一侧偏移，
  拱高上限 `min(0.3 × 弦长, 2u)`；不越过遮挡就加大拱高再试，最多三档。
- **折线兜底**：一折（先竖后横 / 先横后竖）→ 两折 → 三折（4 段）；
  拐点取端口与附近障碍边界坐标，最后取「压字最少、再最短」照样画。
- **两端必须接住**：起点落在标注框边界上、终点落在锚点字墨迹边界上（gap = 0）；
  起点优先在朝正文那条边，被挡才换到角或邻边。
- **箭头尖**在文字一侧，方向沿末段（弧线取终点处切线）。

### 6.3 避让与必画

- 逐字墨迹（自己的锚点字除外）：容差 0.5px；
- 图形 / 表格 / 线条 / 其他标注框：容差 1px；
- 已画引线：只做交叉惩罚（尽量不交叉，不硬堵死）；
- 不得拐回自己的标注框；
- **除小椭圆外不返回空**：所有形态全撞时取「穿得最少 → 最短」的一条画出。

## 7. 全流程

```
输入：批注[]（文字、锚点墨迹、逐字墨迹、颜色）+ 四类障碍 + 页面/版心几何
  │
  ├─ A. 尺寸：em / lineH / padX / margin / sideGap（§3）
  ├─ B. 障碍：行框 + 图 + 表 + 线 + 列表圆点，按 margin 外扩
  ├─ C. 空白：MaxRects 算整页极大空闲矩形（含四边页边距）
  ├─ D. 候选：每条批注 × 每行 × 每个方向 → 取位（§4）→ 算宽 / 行数 / 高，
  │        按阶梯顺序排成一条候选链（环 0…n → 右 / 右下 / 右上 / 下 / 上 → 段内 → 相邻段 → 左侧），
  │        每个候选标出「整句」还是「截断」
  ├─ E. 分配：三档推进（整句 → 截断 → 小椭圆）；同一行成组、从右到左；
  │        单向让位，放好的框进障碍，仍排不下 → 小椭圆
  ├─ F. 引线：关系判定（§6.1）→ 直线 / 弧线 / 折线 → 全撞也画
  │
  └─ 输出：NoteBubble[]（位置、尺寸、行数、颜色、箭头）
```

`noteBubblePlacements(...)` 仍是纯函数；只读几何，不进分页、不进栅格，翻页动画期间整层让位。

## 11. 风险与退路

| 风险 | 退路 |
|---|---|
| 逐行外扩把旁注送得太远 | 先查同环的右侧 / 右下是否漏了候选（多为障碍外扩把可用宽吃光）；到邻段也仍要贴锚点，不居中 |
| 段界判错（块号缺失） | 退化为「行距 > 上一行行高 × 1.5 即换段」；真机看跨段位置，必要时补齐块号 |
| 左侧迟迟不用、页边距空着 | 这是口径（本段用尽才允许左），先查本段各环是否真的都试过，不提前用左 |
| 同一行多条互相挤 | 竖向成组，按锚点左右次序排上下；整组放不下才交给阶梯，仍留 `marginX` / `marginY` |
| 小椭圆太小点不中 | 视觉尺寸不变，点击热区单独扩到 1.2em |
| 折线绕不开 | 一折 / 两折 / 三折逐级试；再不行按「穿得少、更短」照画，至少保留指向 |
| 标注互相挤 | 放好的框按 margin 外扩进障碍，且先挑顺序固定 |
| 表格整体缺几何 | 维持框线 + 单元格文字避让，登记 D-29 前置 |
