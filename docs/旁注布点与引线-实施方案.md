## 0. 口径（2026-10-23 用户定稿）

### 0.1 布点阶梯：整句 + 环 + 折行 + 就近 + 方向顺序（2026-10-31 定稿）

一条批注的候选位置按下面的字典序**逐格尝试**：

0. **先保整句**：能整句放下的候选一律先于截断候选（规则 7 / 11：截断是最后手段）。
   2026-10-29 用户定口，**取代此前「环数绝对第一优先」**：截断不再能靠「环数近」抢在整句前面。
   **段的阶梯已删除**（2026-10-27 用户定口）：范围只由空白是否连成一片决定，
   可以跨过 p / pre / div / blockquote / ul / ol / table 的边界；占满版心的行是分割行。
1. **环先分家，同环内先折行、再就近**（2026-10-31 用户定口，取代 2026-10-29「就近第一、宽度第二」）：
   本行（上一行 / 下一行的左右也算 0 环）那一圈先于隔行的；同一环里**一行放得下的空位先于
   要折两行的**，折行相同才比「额外引线长度」——候选框到选区的边到边最短距离，减去该方向的
   自然留白（正右 / 正左 `sideGap` 1em，正上 / 正下 1em，四个斜向是「一个字的横向走廊 + 2px 近侧」
   的合成），**差一个行高以内算同档**。真机「用 val 声明」：左侧那格几乎贴着字、只多 24px
   却要折成两行，右上同环有一行放得下的空位、只多走 80px；旧口径按「56px 跨了一个行高档」
   选了左边。方向名次最后。
2. **方向名次最后**：
   得到「额外引线长度」；
   这个值越小越先，差值按 0.5px 分桶（≤0.5px 归 0），同桶算同距。同距才按
   四个角 → 正右（本行右边还剩 1em 以上空白时提到最前）→ 正左（本行左侧有缩进时提到最前）
   → 正上 → 正下；满行的左右页边距排在四个角之后。
   - 自然留白内的候选额外长度为 0，所以短行行尾的正右仍按方向顺序优先；
     只有正右 / 斜向被推到更远（越过后面的字、落到别的行行尾）时，才让给更贴选区的方向。
   - **例外一**：本行有多条批注，最右那条能放正右时，正右先归它。
   - **例外二**：右上 / 右下会完整挡住右侧批注朝自己锚点的上下出线通道时，
     本条先走左上 / 左下，再回到右上 / 右下；这一条是硬约束，排在就近之前。
3. **每个环都带那一行自己的左右两侧**：上一行 / 下一行的左右属于本行相邻空间（0 环），
   更远的行按环数；别的行右侧对本行就是右上 / 右下。那一行不是锚点行时，这一列要从
   **靠近锚点的那一端**用起（贴住本行，留 2px），不按那一行垂直居中——否则行距一大，
   框就被摆到离锚点整整一行远（2026-10-29 用户定口，真机「用 val 声明」）。
4. **左侧按环参与排序**，不再只在最后才允许；本行有缩进时只有最左那条可以优先左侧。
5. **满行的左右页边距可以用**（相邻一圈的满行也一样），但排在四个角之后；
   满行仍是分割行，不把上下空白连起来。
6. **多行选区不再强制先末行**：首行、末行的候选同环竞争，按
   整句 → 就近 → 同侧 → 环 → 折行 → 方向比较。基准行仍是末行（用于分组与方向分类），
   但首行那一圈也生成并参与竞争；首行、末行同距、同方向时仍贴末行（`onBaseRow` 只做最后决胜）。
7. **放不下整句**：同一环所有整句候选都不行，才用这一环的截断候选；所有环都不行才退成小椭圆，
   截断至少显示 4 个字。
8. **已有批注让位**：环 0 的整句候选只要挡路批注让一让就能放下，就先让位（§5.2）；
   让位优先于隔行；截断候选不搬动别人。
9. **综合安排**：全部落位后按 §5.4 调整同一行、同一块空白里的多条批注——
   **按选区在这一组里的位置定堆叠先后**：这一组里最靠两端的贴正文行、夹在中间的往外推
   （中心在外、两侧靠内，2026-11-02 用户定口，2026-11-03 修正口径：只在这一组内部比，
   不拿正文行中线当基准）；其余按「长的放外侧、短的放内侧」把走廊留给短批注的引线；
   右边还有批注时，左边那条不留在选区右边，翻到左上 / 左下（见 §5.4 第 0.1 条）。

- 「紧邻」「隔 n 行」都以**正文行**为单位（一行一行数），不是「若干像素」。
- **同一行有多条批注**：先让最右那条占正右，其余逐个独立安置、从左到右，每条按自己的链取位；不要求成列或对齐。
- **整句与截断的先后由环决定**：不再全页跑完整句档才开截断档，见第 0 / 7 条。
- **左侧不是最后退路**：它按环参与排序；满行页边距排在四个角之后，正左排在四个角之后、正上 / 正下之前。
- **多行选区以末行为基准行**用于分组和方向分类；但首行的 0 环候选同样生成，不再有
  「末行那一圈放不下才轮首行」的硬阶梯（2026-10-27 用户定口）。

### 0.2 空白区怎么取位

**留白两档（2026-11-02 用户定口，取代 2026-10-27「上下左右一律 1em」）**：
1em 只留给**引线横着出去**的那一侧（框朝正文的一侧，即正右 / 正左的近侧）；
其余横向侧——远侧、正上 / 正下的左右、四个斜向的非出线侧——默认 **0.5em**，
空间不足可压到 **2px**。纵向远侧仍按旧口径 1em → 0.1em。

- **正右 / 正左**近侧固定 `sideGap`（1em），不压（箭头空档）。
- **正上 / 正下**近侧固定 1em（竖直引线空档），推不出就不生成。
- **四个斜向（右上 / 右下 / 左上 / 左下）纵向近侧只留 2px**：横向特意错开一个字，那一个字
  不是摆放留白，而是 **L 形引线的走廊**——引线从框的侧边横着出去，沿走廊走到选区
  那一角的外侧，再竖着进字下 / 字上。纵向推到 1em 会把批注送离锚点，读者反而看不出
  这条批注在说哪段字（2026-10-27 用户定口：「不要画成单线，更不要推远」）。
  **横向近侧**首选 1em，压缩档 2px；远侧与非出线侧按 0.5em → 2px。
- **非出线横向侧**（正右 / 正左的远侧、正上 / 正下的左右、斜向的远侧）：首选 0.5em，
  压缩档 2px。0.5em 是纯留白，不画线；收紧后同一块空白能放下更长的整句。
- **纵向远侧**（正上 / 正下、斜向）：首选 1em，压缩档 0.1em（本轮只调横向）。

换句话说：**先试非出线侧 0.5em → 压到 2px → 换位置**；正侧与正上 / 正下的近侧 1em
是硬门槛，只有斜向的横向近侧允许在压缩档收到 2px。

> 2026-10-24 曾允许「正下 / 正上最后一档收到 0.1em」「四个斜向也收近侧」，
> 目的是把批注塞进两行之间的行距；2026-10-27 收回：正上 / 正下那条缝不够 1em 时
> 近环不成立；四个斜向的近侧反过来固定 2px，用错开的一个字画 L 形引线。
> 2026-11-02 进一步把「非出线横向侧」从 1em 收到 0.5em（不足 2px），
> 1em 只留给横线引线真正经过的那一侧。


1. **右侧**：垂直居中于**该行**，水平隔 `sideGap`（**1em**，也是箭头空档）贴该行文字右缘；
   空白装不下时在空白内 clamp。**右侧离版心右缘还有 1em 以上空白就生成**；
   满行也生成右页边距那一列，只是排在四个角之后（§0.1 第 5 条）。
2. **右下 / 右上**：**框左缘在所选文字第一个字的左缘**（多行选区取**末行第一个字**）
   **向右一个汉字**处，横向近侧首选 1em、压缩档 2px（见上）；
   纵向近侧固定 2px（这个错开量就是引线走廊）。不是贴整个选区右缘，
   也不是对齐第二个字；只有一个字时按一个字宽兜底。
3. **左下 / 左上**：**框右缘在所选文字末字符**（多行选区取**末行末字符**）
   **向左一个汉字**处；横向近侧同样 1em（压缩档 2px），纵向近侧 2px。
4. **正下 / 正上**：贴锚点的**字墨迹**底边 / 顶边（不是行盒边——行盒上下各半段行距是空白，
   见 §2.1），水平与锚点对齐；近侧固定留 1em（2026-10-27 用户定口），**推不出就不生成**；
   左右两侧是非出线侧，按 0.5em → 2px 收。
   **只认横向压住锚点的那条空白带**：右侧那一列是「右」，
   不是「下」。若批注比所选文字长、紧贴后只剩一条短竖线，同一侧再远一行还有整句位置时
   也按环数：近环能放下就先用近环，近环放不下才放远一行（2026-10-27 环数绝对优先）。
   右下 / 右上**不适用**这条让位。
5. **左侧**：垂直居中于该行，水平隔 `sideGap`（1em）贴该行文字左缘；左侧按**环数**参与排序，
   名次排在四个角之后、正上 / 正下之前。满行的左页边距也可以用，但同样排在四个角之后。
6. 其余空白：空白内离锚点最近的一角。

**认空白带要留容差**（2026-10-31 真机「用 var 声明」）：障碍按 `marginY` 外扩后，空白带的上下缘
会比「行盒边 + 2px」晚 / 早几像素；斜向的 y 正好落在带外 1~2px 时，整块宽空白会被漏掉，只剩
页边距那条窄缝，框被挤到页左（框右缘离选区右缘差了四个字）。判带时按一个 `marginY` 容差认，
落位仍把框顶推进真正的空白里（`top = max(行盒底 + 2, 带顶)`），所以容差只影响「认不认这条带」。

一律**贴住锚点**：不为了「居中」把框推到离原文很远的地方。

### 0.3 标注之间的先后

1. **初始放置**：同一行先给最右那条占正右，再从左到右算；按**基准行**（多行选区取**末行**）
   分组，行自上而下。每条按自己的候选链取第一个可用位置，初始阶段先到先得。
2. **先保整句，再看就近，同近才比同侧、环与折行**（2026-11-02 用户定口）：
   每条批注的候选链按「整句 → 就近档 → 精确距离 → 同侧 → 环 → 折行 → 首选侧 → 方向」推进——
   同样放得下整句时，离原文近的先占；差出一个行高才按环与折行分先后。截断不再因为「近」抢在
   整句前面。段的阶梯已删除（2026-10-27 用户定口）。
3. **让位**：新批注的环 0 整句候选放不下、且挡住它的是已放批注时，才请对方上下 / 左右
   让一让（不要求两边占着同一块空白，挪完还在它自己的空白里即可）；让不出就不让。
   `attemptBeside` 只在自己旁边找空，不移动别人。
4. **综合安排**：全部落位后按 §5.4 做一次调整——同一块空白里真的叠在一起的几条按
   **选区在这一组里的位置**定堆叠先后（两端贴正文、中间往外，2026-11-02 用户定口、
   2026-11-03 修正口径；这条比折行优先）；其余（正上 / 正下压着选区的）仍按「长的放外侧、
   短的放内侧」平移。沿这块空白自己的内→外轴动，不改变行、不改变方向；任何一步不满足
   空白边界或框间距就保持原样。
5. **文字位置**：同一行多条批注里偏左的那几条用左边的位置（左上 / 左下 / 正左）、偏右的
   用右边的位置（2026-11-02 用户定口；按这一行几条批注的整体跨度分左右 —— 与第 4 条
   「在组内靠两端还是靠中间」用的不是同一条中线，这一行只有本条时不论左右）；同一块大空白里
   文字靠上用上边、靠下用下边；批注不得重叠，引线尽量不交叉。
6. 同一输入结果恒定（排序键不用浮点近似）。

### 0.4 引线与箭头（2026-10-24 用户定稿：只画正交线）

**只允许横线、竖线、折线**：不画斜线、也不画弧线。两端必须垂直：

1. **第一段必须垂直于批注框边**：从左边 / 右边出去是横线，从上边 / 下边出去是竖线；
2. **最后一段必须垂直于所选文字的框边**：从文字下面进来是竖线，从文字右边进来是横线。

**最短优先（2026-10-24 用户定口）**：标注与正文之间画直线可行，就画直线；
起点和终点都**不一定在中心点**，更不固定在所选文字的起点。

- **先定终点**：标注在正文**右侧**（正右 / 右下 / 右上）时，指向**对应正文行的终点**——
  与框纵向最近的那一行里**最靠右的那个字**。框在文字右侧就进它的**右侧面**；
  框偏上就进**上边靠末端**；框偏下就进**下边靠末端**。标注在左侧时对称地指向**起点**。
- **再找出口**：沿框上朝目标的那几条边取点（文字在左就从左边出去、在右就从右边出去、
  在上 / 下就从上 / 下边出去），第一个点与入口对齐——能直接画直线就一定是直线；
  其余点给折线留余地。两端仍严格垂直框边。
- **方向定了就取最短的两端**（2026-10-30 用户定口）：线型一旦选定，出口沿框边、入口沿字边
  取点时，唯一的对齐目标是**另一端**——离另一端最近的落点（0.5em 区间端头）才是首选，
  框心只是没有对齐目标时的兜底。**0.5em 区间的两头永远留在候选池里**，不许被「就近取前几个」
  截掉：真机「函数体」的框宽 916px，框心附近的几条字边占满候选，离入口最近的端头反而被挤掉，
  引线只好从框中间出去，比从框左端出去多走 360px。
- **不通才折**：直线被字挡住时按一折 → 两折 → 三折 → 四折绕开；
  通畅路径的择优顺序是**折数少（直线优先）→ 已画引线交叉少 → 更短**。
- **正下 / 正上**（法线摆法）改在与选区**横向重叠的那一段**里上下对穿，通常一条竖线就到
  （2026-10-25 修正，旧口径「框中心 → 最近字的那条边」作废）。
- 右下 / 右上不再固定从框左边中点出、也不再指向最左那个字（上一版的 L 形口径作废）。
- 两端必须接住：起点在批注框边界上，终点在所选文字的墨迹边界上，中间不留缝；箭头尖在文字一侧。
- 避让对象：逐字墨迹、图形、表格、线条、其他批注框；块底色、`padding` / `margin`、页边距仍算空白。
- 除小椭圆形态外**必须画**：直线 → 一折 → 两折 → 三折 → 四折 → 「压字最少、再最短」照画。

> **2026-10-25 修正（六条真机反馈，细见 §6 与 `docs/breakpoint-20261026.md`）**：
> ① 直线改成「两段可用区间的交集」，放不下 0.5em 内缩时按规则 7 取消内缩，正右不再折成三段；
> ② 左右两侧补「竖着从框的上 / 下边出去」的出口与对应入口，被字挡住时走走 下横上 / 上横下；
> ③ 正下 / 正上用横向重叠段定入口，一条竖线解决；④ 行间横穿走两行正中（门槛放宽到一个字高）；
> ⑤ 新增「不倒退」与「不横穿锚点行」两条劣选判据；⑥ 箭头两臂夹在末段以内。
> 择优顺序随之改为：不交叉 → 不倒退 → 形状 → 末段够长 → 折数 → 穿字 → 贴字 → 长度。

## 1. 阶梯的执行口径

### 1.1 环与方向

| 环 | 范围 | 环内位置顺序 |
|---|---|---|
| 0 | 锚点**末行**（多行选区的首行也在本环生成） | ①右上 ②右下 ③左上 ④左下 ⑤该行正右（短行右侧空白足时提到最前）⑥正左（本行左侧有缩进时提到最前）⑦正上 ⑧正下；满行的左右页边距排在四个角之后 |
| 1…n | 距锚点行 n 条正文行 | 该行自己的左右 + 右上 → 右下 → 左上 → 左下 → 正左 → 正右 → 正上 → 正下 |
| 空白其余 | 同一片空白里更远的行 | 由近到远；**含左侧** |

- **右下 / 右上**：框**左缘**在所选**末行第一个字右移一个汉字**处，近侧再留 2px
  （那个错开的量就是 L 形引线的走廊）；框顶边在该行下方 2px / 框底边在该行上方 2px 处；
- **左下 / 左上**：框**右缘**在所选**末行末字符左移一个汉字**处，近侧同样留 2px，
  上下同右下 / 右上；
- **下 / 上**：框与该行在水平方向有重叠；近侧 1em 是竖线引线的空档，推不出就不摆这个方向；
- **右侧**：框左边 ≥ 该行文字右缘 + `sideGap`，垂直居中于该行（空白不够高才在空白内 clamp）。
  该行右侧离版心右缘还有 1em 以上空白时，正右提到四个角之前；满行时仍生成左右页边距那一列，
  但名次排在四个角之后（§0.1 第 2 / 5 条）。
- 环号 = 框最近的一行与锚点末行之间隔了几条**正文行**（同一条行算 0）；越过别的批注也算跨行。
- 取位一律**贴住锚点**：右下贴末行第一个字的右下方、左下贴末字符的左下方、下 / 上贴对应边，
  贴不下才在空白内 clamp；**不为了居中把框推到远处**。
- **左侧那条批注的画线空档**（§0.1 0c）：右下 / 右上 / 正下 / 正上框的**左缘下界**是
  「这一行左侧那条批注第二个字的左缘」= 它首字左缘 + 一个汉字。空白够时这条限自然满足；
  正下 / 正上原本会为了塞满整行把框 clamp 到页左，现在从这条线起排（框收窄、折行变多），
  左侧批注首字那一格始终空着。

#### 顺序怎么比（字典序，2026-10-29）

候选之间的先后是**一个元组的字典序**，不是加权求和：

```
key(c) = ( 是否整句, 越过的批注行数, 是否挡住出线, 正右被占分组,
           就近档, 折行数, 额外引线长度, 环数, 首选侧, 方向名次, 是否基准行, 留白档,
           斜向离角落基准的横向偏移, top, left )
```

- **整句在最外层**（2026-10-29 用户定口）：截断是最后手段，范围内还有整句能放下就先放整句。
- **越过别的批注**（规则第 10 条）仍是硬约束：框与锚点之间隔着别的批注，排在没隔的后面。
- **就近档**（2026-10-29 用户定口）：额外引线长度按**一个行高**分档，差不到一行算「同样近」。
  算法是候选框到选区的边到边最短距离减去该方向的自然留白：正右 / 正左减 `sideGap`（1em），
  正上 / 正下减 1em，四个斜向减「一个字的横向走廊 + 2px 近侧」的合成。
- **同档挑最宽**：同一就近档里折行数越少（框越宽）越先，然后才是精确的额外引线长度。
  这一条取代了「环数在最外层」：隔一行那块再宽，也要先让近的那块里折行最少的赢。
- **方向名次**：就近相同才比它。
  **右上(0) → 右下(1) → 左上(2) → 左下(3) → 正右(10) → 正左(20)
  → 正上(30) → 正下(40) → 兜底(50)**。
  正右在「本行右边还有 1em 以上空白」时提到最前（-2），有缩进时本行最左那条的正左同样提前，
  两者都比四个角更先。否则正右排在四个角之后、正上 / 正下之前（满行的右页边距也走这一档）。
  正上 / 正下压到最后：它们要占 1em 的竖线空档，推不出就宁可不摆。
  两条例外：本行最右那条能放正右时先给它（前提是正右不会把句子挤成比同档最宽位置更多的行，
  2026-10-29）；右上 / 右下完整挡住右侧批注的上下出线通道时，
  本条按左上 → 左下 → 右上 → 右下排（`blocksExit` 是就近之前的硬键）。
- **正右被占**：本行正右已被别的批注占住时，正右让到所有其他方向之后（硬键，排在就近之前），
  再按「正左 → 正上 → 正下」的名次取位；本行最左那条的首选左不受影响。
- **基准行**：首行、末行同距、同方向时选末行（`onBaseRow`），只做最后决胜。
- **段已删除**：不再有「本段 → 相邻段」的阶梯，范围只由空白是否连成一片决定（§1.5）。
- **留白档**：同一方向上先要非出线侧 0.5em，不够压到 2px；正侧与正上 / 正下近侧 1em 不压，
  四个斜向的横向近侧首选 1em、压缩档 2px，纵向近侧固定 2px（L 走廊）（§0.2、§3）。
- **斜向离角落基准的横向偏移**（2026-10-27 用户定口）：右上 / 右下的默认位置是
  「首字右偏一个字」（`cornerRightX`），左上 / 左下是「末字左偏一个字」。同一方向里
  先比离这个基准的偏移，再比 top——否则更靠右的页边距列会凭「框更高」抢走角落那份位置
  （真机「以这种方式声明的变量」被推到右移 6.5 字处）。偏移为 0 的候选就是基准点。
- **top / left**：最后只是稳定决胜项，保证同一输入结果恒定。
- **行数上限**：折出来的行数不得超过单行字数（一行 N 个字最多 N 行），否则换更宽的空白。

字典序的好处是「谁优先」一眼可读、加规则只加一位、也不会像加权评分那样出现
「两项各让一点就反超」的怪结果（旧扣分制就是这样退役的，§12）。代码里对应
`orderedNoteCandidates`：`compareBy(环 + 越过).thenBy(整句).thenBy(折行数).thenBy(额外引线长度).thenBy(方向名次).thenBy(角落基准偏移)…`。

### 1.2 可读档（整句 / 截断 / 小椭圆）

| 档 | 判据 | 什么时候用 |
|---|---|---|
| **整句** | 折行后能显示**全部**字数 | 同一环里最先试 |
| **截断** | 显示 ≥ **4 个字**（整句不足 4 字按整句） | 同一环的整句候选都不行时，再试这一环的截断 |
| **小椭圆** | —— | 所有环都失败之后 |

- **不再全页统一推进**：每条批注沿自己的链走「环 k 整句 → 环 k 截断 → 环 k+1 整句……」，
  所以近环的截断可以先于远环的整句（§1.4）。
- 框尺寸按 §3 由字号 / 行距 / margin 算出，不用估算宽直接比。
- 「放得下」同时要满足：不与文字、图形、表格、线条、**已放好的旁注框**相交，
  与障碍的横向间距 ≥ 2px、纵向 ≥ 0.1em（非出线横向侧空间够时按 §0.2 先要 0.5em），
  正右 / 正左与所选文字隔 `sideGap`（1em，留给箭头），且框在页面内（离屏幕边 0.5em）。
- 块底色、`padding` / `margin`、行距、行右侧未排满处、四边页边距**都是空白**。

### 1.3 同一行多条

1. 按**基准行**分组（多行选区取**末行**），组内**先让最右那条占正右，再从左到右**依次计算。
   **预排只认正右**（2026-10-27 用户定口）：正右放不下就作废，它按正常顺序与其他批注一起
   从左到右取位，不借预排去占右上 / 下方 / 左侧——否则最右那条会先挑走本行共享空白里
   离正文最近的一格，最长的一条反而贴着正文。
2. **每条各自独立安置**（2026-10-24 用户定口）：先算的那条按自己的阶梯取第一个可用位置，
   位置定下就定下；后算的那条同样走自己的阶梯，**不要求排进同一列、也不要求左缘对齐**，
   更不会为了凑成一列去移动先算那条。
3. 因此同一行可能一条在行右、一条在行右下（或行右上 / 下一行），各自贴着自己的锚点；
   多条共享同一块大空白时，落位后再按对应文字在正文中的先后、长的外侧短的内侧
   做一次综合安排（2026-10-27 用户定口）。
4. **只有一种情况会动别人**：这条批注的环 0 整句候选放不下，且挡住它的是已放批注
   （同一条行、别的行都算；不要求两边占着同一块空白，挪完还在它自己的空白里即可）——
   这时才请那些批注上下 / 左右让位（§5.2）。
   让完仍放不下就**不让**，这条继续走后面的候选；`attemptBeside` 不移动别人。

### 1.4 逐条推进（整句 + 就近 + 宽度）

1. **不再全页统一推进三档**：每条批注沿自己的候选链走「环 0 整句 → 环 0 截断 →
   环 1 整句 → 环 1 截断 → …」，链内顺序是**整句 → 就近档 → 精确距离 → 同侧 → 环 → 折行 → 方向**
   （2026-11-02 用户定口，取代 2026-10-31「整句 → 环 → 折行 → 就近」）。所有候选都放不下才退成小椭圆。
2. 整句都放不下时才走截断档，截断档内部用同一套顺序挑。
3. 初始顺序为：**正文行自上而下 → 行内先最右那条 → 再从左到右**；行自上而下是硬顺序
   （上一行走完才轮到下一行，不会因为下一行有几条而提前）。
4. 已放好的框立即进障碍表（含 margin 外扩）；后到的批注可以请同一块空白的环 0 批注让位，
   或在自己旁边找空；全部落位后再做一次长外短内的综合调整。
5. 同一输入结果恒定：排序键只用整数 / 稳定坐标，不用浮点近似。

### 1.5 空白连通范围（段界已删除）

- 2026-10-27 用户定口：**不再按 p / pre / div / blockquote / ul / ol / table 等段落截断搜索范围**。
  搜索范围 = 基准行所在的、由「空白连成一片」决定的连续区域：相邻行只要没顶满版心，
  上下空白就相连，可以跨过段落边界；遇到顶满版心的分割行（规则 6）为止。
- 分割行左右两侧的页边距空白可以用，但名次排在四个角之后；它仍然不把上下空白连起来。
- 渲染层给每行带的块序号只留给「缺失行几何时按行距断段」的退化路径，不再参与布点阶梯。

### 1.6 小椭圆（最后的兜底）

- **视觉尺寸**：**固定 16.5 号**（宽 1em、高 0.64em，按屏幕密度换算成像素，最小 4×3px）。
  这号不跟批注字号滑块走，也不跟正文字号走：读者怎么调这两处，这颗记号都一样大
  （它是「这里有批注」的固定标记）。图形是**自己画的**扁椭圆——实心的标注色底 + 一个横排「…」，
  颜色跟标注颜色走，不引外部图标。底色取**标注色按自身透明度在纸面上合成后的不透明版**
  （高亮色本身带 45% 透明度，那是给正文铺底用的；直接铺在记号上会把底下的字透出来），
  所以它压在正文上也**不透出底下的字**，也因此不再画描边；三点按**合成后**的底色明暗取对比色
  （浅底配墨色、深底配纸色，拿标注色原值判会挑出纸色三点、落在浅底上几乎看不见）。
- **位置**：**咬住划线右端、与划线垂直居中**——划线类用这条标注自己的落墨带（跨行时跟最后一行），
  背景高亮没有线，就按「线会长在哪里」算：被标注文字的下缘，图标以它垂直居中、挂在这段高亮的右端，
  **图标左缘再压进 0.3em**（咬住线尾，不是悬在旁边），这 0.3em 压住改标注原文是**有意的**。
  右端贴住页面右缘时依次退到线下方、原文右端内侧、线上方、线左侧。
- **点击热区**单独向外扩到不小于 1.2em × 1.2em（透明），视觉尺寸不变。
- **不画箭头、不进障碍表**（不挡别的旁注）；同一锚点掉出多个小椭圆时，向下错开一个图标高。
- 整页确实没有空白时宁可只留小椭圆，也不压字硬塞。

## 2. 空白与障碍

### 2.1 障碍集合

| 类别 | 来源 | 用于布点 | 用于引线 |
|---|---|---|---|
| 文字（行框 → **字墨迹**） | 行框按逐字墨迹收紧纵向上 / 下缘 | ✅ | — |
| 文字（逐字墨迹） | 渲染层只读几何 | — | ✅（可穿两字之间） |
| 图形 / 背景图 | `pageImages`、整盒背景图 | ✅ | ✅ |
| 表格 | 框线 + 单元格文字 | ✅（整体几何仍缺，登记） | ✅ |
| 线条 / 描边 | `pageBackgrounds` 的边框带 | ✅ | ✅ |
| 列表圆点 / 编号 | `DrawLine.listMarker`（行属性） | ✅ | — |
| 已放好的旁注框 | 本页分配结果 | ✅ | ✅ |

块底色、`padding` / `margin`、行距、行右侧未排满处、首行缩进、四边页边距**都算空白**。

**行距怎么用（2026-10-27 用户定口）**：文字障碍**纵向收紧到字墨迹**（行框上下各约半段行距
不再是障碍），横向**仍取整行**——收窄横向会把「词与词之间的小缝」当成能放批注的地方（禁止）。
行距那点净空（正常 CJK 只有几像素）对**正上 / 正下**已经**不再用来塞批注**：它们要 1em 的
竖线空档，塞进去引线就短到看不见。**四个斜向**不受这条限制：它们本来就近侧只留 2px，
贴着行放，靠横向错开的一个字折 L 形引线。行盒**有边框**时边框属于「线条 / 描边」，
仍是硬障碍，框压不进去。

### 2.2 极大空闲矩形

- 页面边界 = 整页（含四边页边距），四周各留 `0.5em`，避免框贴屏幕边；
- 障碍按**最小留白**外扩后做极大空闲矩形（MaxRects）：**横向 2px、纵向 0.1em**；
  候选再按**留白档**把近侧 1em、非出线侧 0.5em 补回去（§0.2、§3）；
- 已放旁注框按 `marginX` / `marginY`（0.1em）外扩，批注与批注之间仍至少隔 0.1em；
- 候选框互不重叠是硬约束（分配阶段再校验一次）。

### 2.3 表格整体

表格整体矩形仍缺只读几何，本轮维持「框线 + 单元格文字」避让，**不按表格整体矩形**处理；
登记在 D-29 前置里，不阻塞本轮。

## 3. 候选框尺寸（字体 / 字号 / 行距 / margin）

```
NoteStyle（可配，批注样式 D-29 落地的接口）
  fontPx          = 正文主字号 × 0.72   // 默认值；字号可单独设置
  // 正文主字号 = 读者字号 × 字号缩放 × 密度（`TypographicProfile.bodyPx`），**与页内构成无关**；
  // 读者拖的倍率乘在这里（1 = 默认）。早先取「本页字数最多的那一档字号」，代码页 `pre`（0.8em）
  // 占优时旁注会小 20%、切排版主题重新分页也跟着变（2026-11-01 定口改成读者字号口径）。
  fontFamily      = null                // 默认跟随界面；批注样式从这里进来
  lineHeightRatio = 1.38
  padEm           = 0.35
  marginXEm       = 0.1                 // 批注与批注的横向最小间距（障碍横向外扩改用 2px）
  marginYEm       = 0.1                 // 纵向最小留白（障碍纵向外扩仍用它）
  sideGapEm       = 1                   // 正右 / 正左与文字的距离（也是箭头空档）
  edgeEm          = 0.5

em      = style.fontPx                 // 旁注字号
lineH   = em × lineHeightRatio         // 旁注行高
padX    = em × padEm                   // 单侧内缩（排版与绘制同源）
padRight = if (末字是句末标点) 2px else padX  // 句末标点自带右侧空白，右内缩可收紧
marginX = em × marginXEm               // 标注与障碍、标注与标注的**最小**横向距离
marginY = em × marginYEm               // 同上，纵向
preferredMargin = 1em                  // 近侧 / 纵向的首选留白（2026-10-24 用户定口）
farGap  = em × 0.5                     // 非出线横向侧的首选留白（2026-11-02 用户定口）
sideGap = em × sideGapEm               // 正右 / 正左与所选文字的距离（留给箭头）
edge    = em × edgeEm                  // 离屏幕边的距离
```

留白两档（同一方向上依次尝试，**先非出线侧 0.5em，再压到 2px**）：

| 档 | 近侧（朝正文） | 非出线横向侧 | 纵向远侧 | 什么时候用 |
|---|---|---|---|---|
| 首选 | 正右 / 正左 `sideGap` = 1em；正上 / 正下 1em；四个斜向横向 1em、纵向 2px | 0.5em | 1em | 空间够时一律先试这一档 |
| 压缩 | 正侧与正上 / 正下 **1em 不变**；四个斜向横向 2px | 2px | 0.1em | 首选档放不下、且压紧确实换来更少折行 / 更完整句子时 |

**近侧没有第二档**（2026-10-27 用户定口）：正下 / 正上原先允许把近侧压到行距空档 / 2px，
代价是引线只剩几像素、批注贴在原文上——真机「用 var 声明」那条就贴在下画 2px 处看不到箭头。
现在它们近侧 1em 是硬门槛，放不下就交给下一环 / 页边距那一列。
**四个斜向反过来**：纵向近侧固定 2px，横向错开的一个字就是 L 形引线的走廊，推远反而离锚点更远；
横向近侧首选 1em，只有 1em 处放不下、且压紧确实换来更少的折行 / 更完整的句子时，才收到 2px。

**1em 只留给引线横着出去的那一侧**（2026-11-02 用户定口）：正右 / 正左的近侧是 1em；
非出线侧（远侧、正上 / 正下的左右、斜向的非出线侧）是纯留白，首选 0.5em、压缩档 2px。
句末标点（`。！？` 等，含其后收尾引号 / 括号）自带右侧空白，右内缩从 `padX` 收到 2px，
框可以更窄；文字测量不变，所以不会因此多折一行。

样式只影响旁注自己，不改正文排版；将来「批注样式」设置页只替换 `NoteStyle`，
布点与引线的代码不跟着改。

计算顺序（每个「批注 × 空白 × 方向 × 留白档」）：

1. `desired = 整句宽 + padX + padRight`（整句宽**实测**：与绘制同一套文字测量，见下；
   `padRight` 在句末标点时收到 2px）；
2. `available = 空白宽 − 非出线侧留白 − 近侧留白`（近侧留白：正侧取 `sideGap`、正上 / 正下取
   `preferredMargin`、四个斜向横向取 1em / 2px；非出线侧取 0.5em / 2px，见上表）；
3. `desired ≤ available` ⇒ **单行**，框宽 = `desired`；
   否则 ⇒ **折行**，框宽 = `available`，行数由实测折行结果给出；
4. 行数受空白高约束：`capacity = floor((空白高 − 纵向远侧留白 − 近侧留白) / lineH)`；
5. 显示字数 ≥ 4（整句不足 4 字按整句）才保留候选；`显示字数 == 总字数` 为完整，否则截断；
6. 框高 = 实际行数 × `lineH`。

**宽度是「文字 + 字体 + 行距 + margin」一起算出来的**：同一段文字在不同宽度的空白里得到
不同的行数 / 高度 / 完整度，布点时用的就是这套最终尺寸，不再拿估算宽当判据。

> **整句宽必须实测，不能按「一个字多宽」粗估。** 粗估哪怕只窄一两个像素，摆位就会判成
> 「整句放得下」、画出来却被 `Text` 补一个省略号——真机上是「整页都是空白，批注却折成两个字」。
> 实测用的是绘制那条 `Text` 真正吃的字号 / 行高 / 基础样式（含字距），并在整句宽里留出
> 绘制侧「框宽与内缩各自取整」的 1px 损耗；折行与「能读几个字」也按实测行数与可见末字判定。
> 粗估实现只保留给纯逻辑单测，不参与真机布点。

## 4. 空白内取位

§0.1 / §1.1 决定「试哪一块空白、试哪个方向」，本节只负责在这个方向下把框摆正：

| 关系 | 水平 | 垂直 |
|---|---|---|
| 正右（右侧留白 ≥1em；满行也用页边距，名次靠后） | `x = 该行文字右缘 + sideGap`；非出线远侧 0.5em / 2px | 垂直**居中于该行**；空白装不下时 clamp |
| 右下 | 左边 = 末行第一个字左缘 + 一个汉字；横向近侧 1em（压缩档 2px）；非出线远侧 0.5em / 2px | `y = 该行底边 + 2px` |
| 右上 | 同右下 | `y` 使框底边 = 该行顶边 − 2px |
| 左下 | 右边 = 末行末字符右缘 − 一个汉字；横向近侧 1em（压缩档 2px）；非出线远侧 0.5em / 2px | 同右下 |
| 左上 | 同左下 | 同右上 |
| 正下 | 水平与锚点对齐，左右两侧 0.5em / 2px，空白不够就 clamp；**左缘另受左侧批注首字那一格的限制** | `y = 锚点底边 + preferredMargin` |
| 正上 | 同上 | `y` 使框底边 = 锚点顶边 − `preferredMargin` |
| 正左（按环参与排序，名次在四个角之后、正上 / 正下之前） | `x = 该行文字左缘 − sideGap` | 垂直居中于该行 |
| 同一片空白的其余位置 | 空白内离锚点最近的一角 | 同左 |

- 「垂直居中」以**这一行**为基准（多行选区取**末行**）。
  不再以「整段并集中心」为基准——那会让多行选区的旁注跑到段落正中，离正在读的行很远。
- **满行的页边距列按「页边距档」算**：满行在相邻一圈时，几何上可能被算成右上 / 右下，
  但它的框落在页边距里，名次改用正右 / 正左那一档（10 / 20），排在四个角之后。
- 一行右侧的空白通常不够高：框高超过空白高度就 clamp，仍不够就折行 / 换方向，不越界。
- **贴边优先**：右下 / 左下先贴末行首 / 末字符那一侧，只有贴不下才在空白内挪；不为了居中把框推到远处。
- 同一块右侧空白里，先试单行，再试折行；折行也放不下整句就按阶梯往后走（§0.1 第 2 步起）。
- **正下 / 正上不再吃左侧页边距**（§0.1 0c）：这一行左侧还有批注时，框的左缘从「左侧批注
  第二个字的左缘」起排——原来是「能塞满整行就 clamp 到页左」，结果一条长批注正好压住
  左侧那条批注接进首字的空档。

## 5. 分配（整句 + 就近 + 宽度、独立取位、有限让位、综合安排）

1. **分组**：按**基准行**把批注分组（多行选区归入**末行**），行自上而下；同一行先让
   **最右那条**去占正右，再从**左到右**处理其余批注；
2. **逐条推进**：每条批注沿自己的候选链走，链内顺序是整句 → 就近（差一个行高以内算同档）
   → 同档挑最宽（折行最少）→ 环数 → 方向（2026-10-29 用户定口）。候选**按圈分批**要来
   （环 0 整句 → 环 0 截断 → 环 1 整句 → …），新一批并进链里按上面的顺序重排，所以
   「整句优先」只在**已经要到的候选**里成立：更外那一圈的整句，要等本圈截断也放不下才会被
   要进来（每条都全页算一遍太贵）。行内**各按自己的候选链独立取位**
   （彼此不要求成列、不对齐），**上一行走完才轮到下一行**；
3. **全部落位后综合安排**：按 §5.4 做一次平移调整——同一个角上叠在一起的按选区左右定
   堆叠先后，其余按「长的放外侧、短的放内侧」。

### 5.1 取位（每条批注）

1. 按 §1.1 的字典序取候选链（整句 → 就近档 → 精确距离 → 同侧 → 环数 → 折行数 → 首选侧 → 方向名次 → 留白档）；
2. 沿链扫一遍，同时记下两个落位：
   - **现成的**：链上第一格原样就能放下的（不挪任何人、也不挪自己）；
   - **挪出来的**：靠「自己沿空白滑开」或「请挡路的批注让位」（§5.2）才放下的那一格，
     取其中最靠前的一格。让位问几环：**环 0 与环 1**（2026-10-29 用户定口）——
     隔一行那块空白里如果能靠别人让一让就放下，比「自己滑到隔两行」更近；再往外就让不起了。
3. 两者按「整句 → 就近档 → 环 → 折行数 → **同一方向再比零头** → 链序」比，赢的那个才落地：
   跨方向不比那几十像素的零头（两侧的「自然留白」本来就不一样长），交给链序，
   免得「滑开 10px」输给「换到另一侧」；
4. **挪出来的位置不是定案**（2026-10-29 用户定口）：它可能已经被挤出隔两行，
   而再往外一圈还有一条真正贴着选区的空白。所以先记着它，继续沿链往下看，
   必要时再要下一圈候选——**看几圈 = 当前环数 + 就近档**（被挤出去几档就再看几圈）；
   找到更靠前的现成位置就换过去，刚才那份挪动作废；
   让位只是**一份还没落地的搬运清单**（§5.2），丢弃它不需要回滚任何框；
5. 现成的位置一旦出现就直接落地（这一带不会再有更靠前的），不再多要候选——保性能；
6. 所有环都走完仍没有位置 → 退成小椭圆（§1.6）。
   截断候选不搬动别人：让位只在整句候选上发生，截断候选只能找现成的空位。

### 5.2 让位（同一列里上下让一让，让出来要真能放下）

- **触发条件**：候选`conflict`到已放批注（不要求两边在同一块空白，挡路框挪完还在
  它自己的空白里即可）。**正右 / 正左 / 四角**的挡路框往上下让；**正上 / 正下**的挡路框
  往左右让，**左右都让不出去时连上下也试**（只对隔行的候选开放；环 0 还有别的方向可选，
  先别动「不该动的那条轴」）。后面那行的批注不许把前面那行的已放框挤走（硬顺序），
  但「在旁边找空」不移动别人，不受这条限制。
- **先算后动**：让位算出的是一份**搬运清单**（挡路的几条挪到哪儿、新批注落在哪儿），
  采信时才真的挪；所以「算完又找到更近的位置」时直接丢掉清单即可（§5.1 第 4 条）。
- **怎么让（贴边重排，2026-10-24 用户定口）**：
  1. 把挡路的那几条**整体**推到这块空白的**上缘**或**下缘**（两向都试，取位移小的；
     一样大取上移），挡路框之间的相对次序不变；
  2. 新批注在剩下的那条空档里**重新算框**（`noteBoxFit`：宽了不折行、窄了折行，
     行数由空档高度决定），**只要整句放得下就算成功**——折行与不折行都认；
  3. 新框的高度夹取到它原本想待的位置（本行垂直居中），贴着让位后的挡路框，
     不被甩到空档另一头。
- **让位后必须复核**（任一不满足就整体作废、谁都不动）：
  1. 每个被移的框仍在**它自己的空白矩形**里（空白已含横向 2px、纵向 0.1em 最小留白）；
  2. 被移的框彼此不冲突，也不与**没让位**的批注冲突；
  3. 新框落在这次用的空白矩形里，且与让位后的挡路框、没让位的批注都不冲突；
  4. 新框真的整句放得下（含折行）。
- **上 / 下都可让时取位移小的**（一样大取上移），保证同一输入结果恒定。
- **让不出就不让**：两条方向都越界 / 撞别人 / 整句放不下，就保留原位置，
  新批注继续走链上的下一格（含隔行的环）。
- 截断档**不搬动别人**（不为一条要截断的批注去动已放好的框）。

### 5.3 档位推进与确定性

1. **不再全页统一跑完整个整句档**：每条批注沿自己的链推进到「环 k 整句 → 环 k 截断」；
   近环的截断先于远环的整句。
2. **小椭圆**：所有环都走完仍没位置的，在锚点右下角退成小椭圆（§1.6）。
3. **每放好一条立即把框（外扩最小 margin）加入障碍表**；初始放置**不做两两互换**。
4. **综合安排**：全部落位后按 §5.4 做一次长外短内的平移调整（只动同一块空白里的两条，
   不按侧别、不按文字位置相邻），不改变行与方向；再按 §5.4 第 0 条定同一行里的堆叠先后、
   按第 0.1 条把右边还有批注的那几条翻到左侧。
5. **确定性**：同一输入两次结果完全相等（排序键只用锚点位置、行号、批注 id）。

### 5.4 综合安排（中心在外、右侧有批注时靠左）

0. **堆叠先后：中心在外、两侧靠内**（2026-11-02 用户定口，2026-11-03 修正口径，**比折行优先**）：
   同一行几条批注堆在同一块空白里、朝同一个方向叠着时，**按选区在这一组里的位置**定先后：
   这一组里**最靠两端的贴正文行，夹在中间的往外推**。「两端 / 中间」只在这一组自己内部比，
   不能拿**正文行框中线**或这一行全部批注墨迹的并集当基准：被批注的词常常只占行的一小段，
   行首的代码、行尾别的空白里的批注会把中线拉偏，最靠边的那条反而被算成「最靠中」推到最外面
   （真机当前页：`are` / `boxes` / `of` 全在半行右段，按行中线排就把 `are` 推到了 `boxes` 外面）。
   两条同样靠边（都在两端）时，才退回「离正文行中线越远越靠内」；仍一样远时短的靠内、长的往外。
   斜向按**框心**判，不要求「整块落在选区左边 / 右边」：真机「boxes」那条的框左缘压着选区
   末尾半个字，按整块判会直接退出排序，与左侧那条挤在同一层。
   「排反」的判据是**深度区间完全分开**，不是只比内缘——两条并排、只差十来像素时内缘看着
   已经在外，实际仍叠在同一层，引线照样会挤。
   整组从内到外重新打包（三条以上两两互换会被中间那条挡住）。**打包不是一条挨一条往外码**：
   每条先占自己现在的位置，只跟已经码好的同组框真的相撞时才往外让（2026-11-02 用户定口：
   「靠外是有必要才靠外」）；让完再沿深度轴往里收，收到最近能放的一格为止（不越过引线需要的
   空档、不出自己那块空白）。左右两侧页边距里那几条仍按列一条挨一条码——它们本来就并排在行旁。
   正上 / 正下压着选区的不在此列（没有「串到另一侧」的问题），仍按下面 1～5 条；
   选区一样靠边时退回「长的放外侧」。
0.1 **右边有批注的，左边那条靠左**（2026-11-02 用户定口）：这一条在整行里偏左、框却落在
   选区**右边**时，会横在右边那几条的引线出口上方（用户原话：「它会挡住右边的出线，不是
   明摆着应该放左上角吗」）⇒ 翻到左侧：右缘贴着选区左缘，那里压着正文就一小步一小步往外挪，
   翻完仍与别的框互不打架才成立。行矩形含行距，框只搭到上一行行距的一小截不算压字。
   规则第 8 条的**例外**那几条（等本行最右那条落位后回到右上）不翻面，以免与 2026-10-25 的定口冲突。
1. **触发**：两条批注的空白矩形有重叠（同一个大的空白区）、文字长度不同。
   **不按侧别分家，也不要求文字位置相邻**（2026-10-27 用户定口）。
2. **朝外方向**：由这块空白相对锚点正文的位置决定——正文在空白上方就「向下」、在下方就
   「向上」、在左侧就「向右」、在右侧就「向左」。候选名叫正下还是右下不参与判断：同一块
   空白里的正下、右下、左下共用同一个深度轴；右侧页边距里的正右、右上、右下同理。
3. **方向**：把短的那条放到长的那条原来的**内缘**，长的那条紧贴短的外缘（中间留 2 倍 margin，
   与让位一致）。两条直接交换内外位置，**不能只交换上缘/左缘**：短框比长框矮（窄）多少，
   两条之间就会空出多少——真机上曾因此空出 52px。换完长框的外缘仍在原来的空白里。
4. **边界**：换完两条都必须仍在各自的空白矩形里，且不与彼此、不与任何别的已放框冲突；
   任一不满足就保持原样。
5. **只平移**：不改变基准行、不改变方向名次、不改变框大小，因此不会把上一行的批注
   拖到下一行旁边。最多迭代 4 轮，同一输入结果恒定。

## 6. 引线

### 6.1 终点与出边（2026-10-25 三改：直线先、竖着进出、重叠加宽）

**只画正交线**：横线、竖线、折线，不画斜线、不画弧线。两端必须垂直；
但**起点和终点都不固定在中心点**——先按下面的规则定终点，再沿框边、字边找落点。

```
布点方向                     终点（入口）                              出边（第一段）
正右 RIGHT                  该行最右那个字的右侧面                    左边 · 横；被字挡住时上边 / 下边 · 竖
正左 LEFT                   该行最左那个字的左侧面                    右边 · 横；被字挡住时上边 / 下边 · 竖
右下 BELOW_RIGHT            文字下边靠末端 / 右侧面                    左边 · 横；框在字上 / 下时上边 / 下边 · 竖
右上 ABOVE_RIGHT            文字上边（靠框近的那端）/ 右侧面            左边 · 横；框在字上 / 下时上边 / 下边 · 竖
左下 BELOW_LEFT             文字下边靠起点 / 左侧面                    右边 · 横；框在字上 / 下时上边 / 下边 · 竖
左上 ABOVE_LEFT             文字上边靠起点 / 左侧面                    右边 · 横；框在字上 / 下时上边 / 下边 · 竖
正下 BELOW                  朝框的那条行盒边，x 取框与选区的横向重叠段   上边 · 竖；另补一条侧边 · 横
正上 ABOVE                  朝框的那条行盒边，x 取框与选区的横向重叠段   下边 · 竖；另补一条侧边 · 横
```

- **先定终点**：先按规则 12 定指哪一头——框中心落在那一行的左半就指**行首那个字**，
  右半就指**行尾那个字**；单行选区同样适用（右上角的框贴着选区开头，再指行尾要横穿整行）。
  一头定下来后，右侧摆法进该字的上 / 下边靠末端（框偏上进上边、偏下进下边），
  左侧摆法对称靠起点；「那一行」= 与框纵向最近的那一行（跨行选区仍先按规则 12 选首行 / 末行）。
- **端点离四角至少 0.5em**（规则 7）：每条边上的可用区间是「内缩 0.5em 之后」的那一段；
  框或字短得放不下 0.5em 时自动退回中点。
- **这半个字是「尽量」，不是硬约束**（规则 4 的后半句）：第一遍只在 0.5em 区间里取点；
  这一遍没拿到一条干净直线时，再放开「突破」枚举一遍——唯一目的是让出口与入口能对齐成
  一条直线。第二遍的结论要过三道闸：**通畅**（不许拿穿字换直线，规则 8）、**折数真的更少**、
  且**不许突破到行盒两头的角上**（两端的 2px 护栏上那条）：突破到字缝 / 框缝上是「空间不足」，
  突破到角上是「懒得折」，后者比多折一下更难看。
  真机「讨论」就在这一档：出口被相邻批注框顶到只剩框右那条缝（1398），入口在 0.5em 区间里
  只能落 1391，差 7px 折成三段；放开突破后入口取 1398，一条竖线到底。
  突破这一遍的候选数放宽一倍：能对齐的那条缝往往是最靠外的一条，按「离框心远近」排序它
  排最后，只留 6 个会被直接截掉（「讨论」的 1398 正是第 7 个）。
- **斜向的落点是唯一的，不是区间**（2026-10-27 定口）：规则 12 定下哪一头之后，末端就钉在
  「**那一头的选区角再向内 0.5em**」这一个点上，不许再在区间里挑「更短」的点。
  同样的缩进、同一行的一批批注因此画出同一段横向引线（旧实现按 {1, 0.75, 0.5} 三个比例挑，
  同样的缩进能算出 2px / 8px / 14px / 24px 好几种横向）。
  只有这个点被框自己盖住、且框离行盒不足一条细缝（< 8px、竖段画不下箭头）时，才改指另一头——
  这一条只对单行选区生效（多行选区的另一头在别的行上，落点就对不上那一行的边）。
- **直线 = 两段可用区间的交集**：出口沿框边、入口沿字边各有一段区间，取共同坐标就是直线。
  交集为空、但两边只差 `max(框 em / 2, 2px)` 以内时，按规则 7 后半句**取消内缩**取中间值；
  放宽有底线——坐标必须仍落在两端那条边的整段范围里，落点不会滑出框边 / 字边。
  没有这条放宽，一行高的框（区间退化成中点）遇到字墨迹中心差几像素，正右批注就会被折成三段。
- **竖着进**（框在字的上方 / 下方）时箭头停在**整行行框**的上 / 下边（引线规则第 9 条）。
  2026-10-28 试过改成「所选文字墨迹的边」，真机 A/B 立刻退回：终点压在字的边上会被 0.5px
  容差判成穿字，整条路变成「不通畅」，四角的走廊 L 于是全部退化成一条直线
  （「用 val 声明」「用 var 声明」两条最明显）。「行盒」= 选区墨迹的口径只管第 4 / 5 条的量尺。
  **正下 / 正上**的横向落点取「框与要指那一行的横向重叠段」：重叠段里一条竖线就到，
  只有斜靠得厉害时才退到靠起点 / 靠末端的那几个字。
- **正右 / 正左**除了朝正文的那条竖边，还把框的**上边 / 下边**补成出口、目标字的
  **上边 / 下边**补成入口：这就是规则 2 的「下横上 / 上横下」，沿行间空隙横穿，
  不再「从左边出去、绕到右侧再折回来」。同一行的左右两侧也补这一对竖出入口。
- 正下 / 正上另补一条「侧边出去 + 一折竖回文字」的出口：文字横向错开时，它比绕回正上方少一段。
- **斜向引线优选 L 形**（2026-10-27 定口：规则 2）：通畅路径本来没走成走廊时，收尾改走
  「错开的那一个字」让出来的走廊——从**框的侧边**横着出去，沿走廊走到近那一端的选区角外侧，
  再竖着进字下 / 字上，箭头落在竖段末端。
  这是规则 2 的**线型首选**；第 11 条照常适用（2026-10-31 用户定口，撤销 2026-10-28 的
  「四角末折不得省略」）：走廊竖段短到画不下箭头时省掉末折，箭头落在横段末端、方向随横段
  ——真机「函数体」照旧画那个 1px 末折，箭头被按比例缩到 0.9px，读者只看见一根没有箭头的横线。
  出口取离正文最远的那条框边往里半个 em（竖段≈框高，箭头才画得下）。
  落点按**三档**找（2026-10-28 真机：四角「很多个不是 L」）：
  1. **近哪头**（§6.1）；
  2. 那一头被框自己盖住、或走廊不足 `max(4px, 0.2em)` 时，改指**同一选区的另一头**
     ——与「缝 < 8px」无关：长批注的框常伸到正文底下把近端盖住，而框离正文并不近，
     旧判据于是根本不试另一头；缝很窄时两头都试，挑更好的那条。
     两头都在选区内，不换到整行的最左字去（旧实现曾让正下方的批注指回行首）；
  3. 两头都画不成**干净**的路（那一竖扎进下一行的字里）时，在收角带里再扫几处字缝落点。
  整条收角带都被框盖住、一个干净 L 也扫不出来，才退回通畅路径。
- 右下 / 右上 / 左下 / 左上不再固定从框左边中点出、也不再指向最左那个字（上一版口径作废）。

### 6.2 线型名次与择优（2026-10-25：形状 → 折数 → 穿 / 贴 → 长度）

| 名次 | 线型 | 说明 |
|---|---|---|
| 0 | 单段直线 | 规则 1；横或竖，两端沿边滑到同一坐标（取区间交集） |
| 1 | 一折 L 形 | 规则 3；斜向摆法的首选，正右 / 正左被挤得对不齐时也归这里 |
| 1 | 下横上 / 上横下（两折） | 规则 2；只在左右两侧**被字挡住**时算首选：竖出 → 行间横穿 → 竖进 |
| 2 | 其它两折（Z 形） | 中间那段取行间中线或障碍边界 |
| 3 | 三折及以上 | 绕「一整条竖向 / 横向障碍带」，最多 4 折（5 段） |

- **完整择优顺序**（通畅路径）：**交叉数（0 优先）→ 形状名次 → 折数少 → 穿字少 → 更短 → 贴字
  → 是否突破 0.5em → 候选顺序**（2026-10-28 定口：`不倒退` 与 `末段够长` 两条没有规则依据，已删；
  第 8 条「不穿文字」压在长度之前）。
  规则 7（两条引线不得交叉）仍然排第一，宁可多折一次也要绕开已经画好的那条。
- **形状名次排在折数之前**：规则点名的线型（正右单段、斜向 L、左右 下横上）不能因为多一折就丢掉；
  同为首选的 L 与 下横上 之间再由折数决胜，所以没有阻隔时 L 压过 下横上。
- **末段画不下箭头不换路**：不再按末段长短换一条更长的路径，一律在 `finish` 里按第 11 条
  省掉末折（箭头落在倒数第二段的末端）；**四个角同样适用**（见 §6.1）。省掉末折后若剩下的
  是横段，箭头只走到**最近那条选区边框外 2px**（从右往左停在右边框外、反之停在左边框外），
  不再伸到选区中段——那样箭头会叠在选区底色上，既看不清也看不出指的是哪条边
  （2026-10-31 用户定口，真机「函数体」）。
- **省掉末折后横段离框边远一点**：横段原先只差 1px 贴着框底平行着走，像框底下多了一条影子。
  现在出线口挪到横段要去的那个角上（留 3dp 圆角余量），再下（上）去这段空隙的一半
  （离字墨迹 2px 打住）才转过去；空隙太窄、或挪过去会碰字 / 别的框 / 图形 / 划线，就保持原样
  （2026-10-31 用户定口）。
- **全撞兜底**：不拐回自己的框 → 不横穿锚点那一行 → 交叉最少 → 不倒退 → 形状 → 穿得少 → 更短。
  照样画，不留空（规则 8：实在没路时宁愿穿越，但穿得越少越好）。
- **早停**：只有拿到**不交叉的单段直线**才无条件收手；按折数试时，只有**本组端点**自己找到
  不差于当前折数的通畅路径才停（不然前一组端点找到的折线会让后面的端点组合连试都不试，
  竖着出 / 竖着进的 下横上 永远轮不到）。
- 「无字隔开」判据：线段与任一障碍（逐字墨迹 / 图 / 表 / 线 / 其他标注框）不相交（贴边不算）。

### 6.3 避让与必画

- 逐字墨迹（自己的锚点字除外）：容差 0.5px；
- 标注划线（本页所有读者下划线 / 波浪线 / 删除线，含这条批注自己的）：容差 1px，横段还不许贴边；
- 图形 / 表格 / 线条 / 其他标注框：容差 1px；
- 已画引线：只做交叉惩罚（规则 11），不硬堵死；
- **不倒退**（规则 8）：第一段与「起点 → 终点」在主轴上的方向相反（先退出去再折回来）视为劣选，
  同等条件下让位给顺着目标方向起步的走法。判据只看几何，不看布点在左还是右。
- **不横穿锚点那一行**：箭头只能停在目标行墨迹（或行盒）的边上；穿过这一行再扎回来算「绕到字外面」，
  一律劣选，兜底里也排在交叉数之前。
- **行间横穿走中线**（规则 9）：两行文字之间的垂直中线作为折点候选，最多取最近的 4 条；
  中线被别的批注框占住时先换一侧，两侧都被占住才贴着批注与文字之间的空档走，以不穿字为准。
  「两行之间」按**一个字墨迹高度**认行距——正常 CJK 行距（两三成行高）都在内，段间大空档不算。
  行底算**标注划线**：下划线 / 波浪线比字墨迹低一截，中线从线带下缘量起（按整行算，不按单个字算），
  否则波浪线所在的那条缝，中线正好落在波峰上；本页所有标注划线同时是**硬障碍**（不只是这条批注
  自己的），线带边也不做折点来源，免得贴着线抹过去（2026-10-31 真机「函数体」）。
- **箭头两臂夹在末段以内**（规则 5 / 6）：臂长不超过末段长度的 90%，半宽随臂长等比缩小；
  末段只剩几个像素时两臂一起变小（或干脆不画），不会退到上一段上，也不会与末端引线垂直。
- 不得拐回自己的标注框；
- **除小椭圆外不返回空**：所有形态全撞时按 §6.2 的兜底顺序「穿得最少、再最短」照画。

## 6.4 端点与行盒

- 两端必须接住：起点落在批注框边界上、箭头末端落在目标一侧的边界上；
- 箭头尖在文字一侧，方向严格沿最后一段；
- **高亮标注**：竖着进时停在**行盒边框**上，行盒已经和批注框叠在一起时退回字墨迹边，
  免得箭头从框里长出来；
- **下划线标注**（含删除线）：箭头可以进到行盒以内，但停在「这一行的墨迹 + 这条划线」并集的外侧，
  再留一条细缝——不得触及下划线或墨迹；从下方进来时停在线下缘，从上方进来时停在墨迹上缘
  （2026-10-28 用户定口，见 `docs/新版批注与引线规则.md` 第 9 条）。

## 6.5 端点方向、框外折点与规则 10（2026-10-26 真机三条）

真机复核后又暴露三处，都落在「线是怎么走的」这一层（布点不动）：

1. **端点方向必须朝外**：只校验「第一段 ⊥ 框边、末段 ⊥ 字边」还不够——从行盒内部往上折
   同样满足垂直，画出来就是箭头倒着指回行间。现在每条候选都带「这个端点落在框 / 字的哪条边」
   （左 / 右 / 上 / 下），第一段必须**离开框边朝外**、末段必须**从字边外侧进**，
   方向反了的候选直接不采用。
2. **框外的折点要有地方放**：正右 / 正左摆法遇到「框和正文在同一行、中间隔着别的字」时，
   规则 2 要的是 上横下 / 下横上，可这时相邻两行墨迹的中线往往不存在（段首上方是段间距，
   `arrowGapMidYs` 按一个字高截掉了），折点池里没有框外的 y，三段画法根本生成不出来，
   只能退成「横着出、贴着框边竖着爬、再横着进」的之字形。现在框的上 / 下沿各让出
   三分之一行高的一个折点位，V-H-V 才有地方落。
3. **规则 10 的省略末折照字面执行**：末段短到**画不下箭头**（≈0.25 行高，跟 5dp 臂长同量级）
   时省掉这一折，引线与箭头截止在选区盒子边线的延长线上。门槛不能再放宽到半行高——
   行距正常、末折十几像素时读者要的是那条竖线，不是一根横线。**四个斜向不适用这一档**
   （省掉就成了一条单线，见 §6.1）。
   同时「不倒退」改成只判**主轴**（整体横向跑几百像素、纵向只差两像素时，先竖着让开这一行
   不算回头路），否则干净的 上横下 会被误杀。

## 7. 全流程

```
输入：批注[]（文字、锚点墨迹、逐字墨迹、颜色）+ 四类障碍 + 页面/版心几何
  │
  ├─ A. 尺寸：em / lineH / padX / margin / sideGap（§3）
  ├─ B. 障碍：行框 + 图 + 表 + 线 + 列表圆点，按 margin 外扩
  ├─ C. 空白：MaxRects 算整页极大空闲矩形（含四边页边距）
  ├─ D. 候选：每条批注 × 每行 × 每个方向 → 取位（§4）→ 算宽 / 行数 / 高，
  │        按字典序排成一条候选链（整句 → 就近档 → 折行数 → 额外引线长度 → 环 →
  │        右 / 右上 / 右下 / 左上 / 左下 / 上 / 下 / 左 → 留白档），
  │        每个候选标出「整句」还是「截断」；段界不再参与，只按空白连通范围分环
  ├─ E. 分配：每条按「环 k 整句 → 环 k 截断 → 环 k+1 整句……」推进；
  │        同一行先最右那条占正右、其余从左到右，每条独立取位；环 0 整句放不下时
  │        请挡路批注上下 / 左右让位，
  │        或在旁边找空；让不出就不让；全部落位后长外短内综合安排
  ├─ F. 引线：终点（右侧取末端、左侧取起点，跨行先定指哪一头）→ 沿边挑落点（直线取区间交集，
  │        放不下时取消 0.5em 内缩）→ 直线 / L / 下横上 / 正交折线；行间横穿走中线、
  │        不倒退、不横穿锚点行；箭头两臂夹在末段内 → 全撞也画
  │
  └─ 输出：NoteBubble[]（位置、尺寸、行数、颜色、箭头）
```

`noteBubblePlacements(...)` 仍是纯函数；只读几何，不进分页、不进栅格，翻页动画期间整层让位。

真机上一页：锚点「函数体」在行首，同一行的另一条长批注先占了正右那一列，
结果这条被顶到隔两行的右上角——而右侧那一列明明还放得下两条。

用户四条口径：

1. **让位的优先级一定高于隔行**：本行（环 0）的候选只差别人让一让，就先让别人让，
   不许直接跑去隔一行、隔两行。
2. **让出空间以后要真能让新批注放下**，包括折行与不折行；除非无路可让。
   ——所以让位不再用「位移 = 新框高 + marginY、新框 y 固定」，改成**挡路框贴到空白上 / 下缘、
   新批注在剩余空档里重新折行夹取**（§5.2）。
3. **空白计算不能只看「最近 / 最深」**：上一行右侧对下一行就是右上角，凭什么不能用。
   ——取空白带改成「面积前 3 + 横向最近 1 + 进深最大 1」，每个环都补该行自己的正右候选（§0.1 0e）。
4. **行距也是空白**（除非行盒有边框）：行盒上下各约 10px，读者已经用 0.1em 的间距
   避开正文重叠了。 ——文字障碍纵向收紧到**字墨迹**、横向仍取整行；正下 / 正上 的 1em
   改成量到字墨迹，最后一档收到 0.1em（§0.2、§2.1）。

### 9.1 尺寸

| 用例 | 断言 |
|---|---|
| 短句 + 宽空白 | 单行，框宽 = 整句宽 + 2×padX |

### 9.2 阶梯与取位

| 用例 | 断言 |
|---|---|
| 所选段末行右侧整句单行放得下 | 直接放右侧，不进右下 |
| 锚点在段中行、整行顶到版心右缘（右侧只剩页边距） | **不产生正右候选**，从右下开始 |

| 右侧要折 3 行、正下方能一行放下 | 取**正下方**（同一圈里不折行优先、行数越少越优先） |
| 右侧要折 2 行、右下要折 3 行 | 仍取右侧（行数少的赢，方向是行数相同才比） |
| 右侧单行 / 折行都放不下 | 去紧邻右下 |

## 11. 风险与退路

| 风险 | 退路 |
|---|---|
| 逐行外扩把旁注送得太远 | 先查同环的右侧 / 右下是否漏了候选（多为障碍外扩把可用宽吃光）；到邻段也仍要贴锚点，不居中 |
| 段界判错（块号缺失） | 退化为「行距 > 上一行行高 × 1.5 即换段」；真机看跨段位置，必要时补齐块号 |
| 左侧迟迟不用、页边距空着 | 这是口径（本段用尽才允许左），先查本段各环是否真的都试过，不提前用左 |
| 同一行多条互相挤 | 各自独立取位（不强行成列）；只有「同一块空白且真能腾出位置」时才垂直让位，否则交给阶梯，仍留 `marginX` / `marginY` |
| 小椭圆太小点不中 | 视觉尺寸不变，点击热区单独扩到 1.2em |
| 折线绕不开 | 一折 / 两折 / 三折逐级试；再不行按「穿得少、更短」照画，至少保留指向 |
| 标注互相挤 | 放好的框按 margin 外扩进障碍，且先挑顺序固定 |
| 表格整体缺几何 | 维持框线 + 单元格文字避让，登记 D-29 前置 |

  **从右到左**——最右边那条先算、先拿走离本行最近的一格，左边的只能跳过；「同一行」按

  上一行的整句档走完才轮到下一行，下一行有几条成组也不再提前抢位。成组时某一格放不下就
  不占位、留给下一条，不留空洞。
- 2026-10-24 **不折行优先 + 右被占就让位（用户定口）**：折行的优先级原来压过位置，同一圈里
  「更靠右但折成四行」会赢「正下方一行放下」。现在候选之间按**字典序**比
  「段 → 环 → 折行数 → 方向 → 距离」：距离优先，距离相同比折行数（不折行优先、行数越少越优先），
  行数相同才比方向（右 → 右下 → 右上 → 下 → 上 → 左）。同一行成组也照这个口径，
  右侧有多块空白列时先挑折行最少的那列，不为「更高」先折行。另外，这一行右侧已经被别的旁注
  占住时，右侧的**剩余**空间让到「左」之后（仍排在兜底方向之前），不再为「更靠右」把框推远。
  截断档与最后的小椭圆不变：整句档全页跑完才开「至少 4 字」的截断档，最后才退成小椭圆。
- 2026-10-24 **折行数压过远近（用户定口）**：上一版是「环 → 折行数」，本行还剩一条能塞下整句的
  窄列时，哪怕要折十几行也轮不到隔一行只折三行的位置（真机上一句 29 字的批注被压成了 15 行）。
  现在改成**段 → 折行数 → 环 → 方向 → 距离**：不折行优先、行数越少越优先，行数相同才比远近。
  同一行成组也加了一条闸门——组里任何一条折的行数比自己单独能拿到的整句候选多，就整组不成，
  免得「段间空白能一行放下，却被挤进页边距那条两三个字宽的窄列」。
- 2026-10-24 **右下 / 右上改口径 + 引线只走正交（用户定口）**：右下 / 右上不再贴整个选区的右缘，
  而是**左缘对齐所选文字第二个字**（第一个字向右一个字），框不再整条跑到选区外面；
  引线从**左边中点横着出去**，向左走到所选文字最左那个字的左缘，再 90° 竖回文字，
  所以这两种摆法不需要为箭头留空档（只有正上 / 下 / 左 / 右这种「正对」才需要）。
  全部引线只画横线、竖线、折线：**第一段必须垂直于批注框边，最后一段必须垂直于所选文字的框边**，
  斜线与弧线一并退役；绕不过去时折数从一折加到四折。
- 2026-10-24 **Step 9g 口径（四条用户要求）**：①同一行多条不再统一竖向排列，改成行内从右到左
  **逐个独立安置**；②别的空白都放不下时，可以请**占着同一块空白**的已放批注（同一条行、
  别的行都算）在垂直方向让一让，让不出足够空间就不让；③位置优先级：正右**只对段末行**，
  段末行按「右 → 右下 → 右上 → 左下 → 左上 → 下 → 上 → 左」，正右被占时挪到「左」之前；
  右下 / 右上以**末行第一个字右移一个汉字**为横向基准，左下 / 左上以**末行末字符左移一个汉字**
  为基准；④留白改为三档：空间够时上下左右一律先留 1em，不够先收**远离正文那一侧**到 0.1em，
  还不够才换位置，正右 / 正下 / 正上 / 正左的近侧 1em 不轻易收（只有斜向摆法最后一档才收）。
  「短竖线改走 L 形」的门槛同步收到**半行**，免 1em 留白把所有斜向引线都改道。
- 2026-10-24 **Step 9h：给左侧那条留画线空档（用户定口）**：同一行有多条批注时，右侧那条落到
  这一行**下方 / 上方**（右下、右上、正下、正上）的框，左缘不得越过**左侧那条批注第二个字的左缘**
  （= 它首字左缘向右一个汉字），也就是左侧批注第一个字的下方（或上方）要空着——那条批注的
  引线正好要从这一格接进首字。正下 / 正上与其它摆法不同：它们原来「能塞满整行就 clamp 到页左」，
  一条长批注于是压住左侧那条的空档；现在从这条线起排，框宽随之收窄、折行变多，
  左侧那条没有时照旧可以摊到页左。左下 / 左上不受这条约束（本来就贴着末字符往左摆）。
  同时明确：**右侧优先级降低只针对非段末行**——段末行（含只有一行的段落）正右仍是第一优先级。
- 2026-10-24 **Step 9i：正右改成看留白（用户定口）**：原先按「这一行是不是段末行」判正右，
  结果标题行、`pre code` 代码行这类**段中间但右边全是空白**的行拿不到正右。现在判据换成：
  **锚点末行右侧离版心右缘还有 1em 以上空白 ⇒ 正右就是第一优先级**，不看它在不在段中间；
  整行顶到版心右缘、只剩页边距的行仍只在段末行时试正右。段末行那半条规则由上一轮保留。
- 2026-10-24 **Step 9j：让位优先于隔行、行距可用（用户定口）**：真机上一页，锚在行首的那条
  批注被同行另一条长批注挤到隔两行的右上角，而右侧那一列还放得下两条。原因是三处口径
  把想要的结果排除了：①分配先扫完整条候选链、全失败才谈让位，而链里正好有一个隔两行的位置；
  ②让位只肯整体挪「新框高 + marginY」，挪完必越界，没有「挡路框贴边、新批注在剩余空档里重新
  折行」这条路；③取空白带只留「最近 / 最深」两块，锚在行首时左侧页边距窄缝把正文右侧大空白
  挤掉，上一行右侧根本不成候选。加上④行盒上下那半段行距被当障碍，段间距永远用不上。
  现在：**让位排到隔行之前**（环 0 的候选边占边问让位，让成就不往外走）；
  **让位改成贴边重排**（挡路框推到空白上 / 下缘，新批注重新折行夹取，折行与不折行都认，
  除非无路可让）；**每个环都补该行的正右候选**、空白带不再只留两块；
  **文字障碍纵向收紧到字墨迹、横向仍取整行**，正下 / 正上 的近侧 1em 量到字墨迹、
  最后一档收到 0.1em，两行之间那段行距因此可以放批注（行盒有边框时边框仍是硬障碍）。
  同时「正下 / 正上」只认横向压住锚点的空白带，免得右侧那一列冒出「横向在页边距、却叫正下」
  的候选把让位挤掉。折行数仍是段内第一判据，让位落在折行档之后、环之前。

- 2026-10-26 **引线按新 12 条规则重做（用户六条真机反馈）**：①直线不再是「两端坐标严格相等」，
  改成**两段可用区间的交集**；交集差在 `max(框 em/2, 2px)` 以内时按规则 7 **取消 0.5em 内缩**，
  但落点仍夹在两端那条边的整段范围内——正右批注即使只有一行高、字墨迹差几像素，也画一条横线；
  ②**正下 / 正上**的入口 x 改取「框与选区的横向重叠段」，通常一条竖线就到；
  ③左右两侧补**竖着从框的上 / 下边出去**的出口、目标字上 / 下边的入口，被字挡住时走
  **下横上 / 上横下**，不再从左边出去再绕回右侧；④行间中线门槛从半字高放宽到**一个字墨迹高**
  （正常 CJK 行距都判得出），折点候选按离框与目标中点由近到远排序、最多 4 条，中线被占先换一侧；
  ⑤新增两条判据：**不倒退**（第一段与起点→终点在主轴反向即劣选）与**不横穿锚点行**；
  ⑥线型改成**形状名次**（直线 → 一折 L / 左右下横上 → 其它两折 → 三折以上），形状先于折数；
  ⑦箭头两臂夹在末段 90% 以内，末段很短时随之缩小；⑧早停只对「不交叉的单段直线」无条件成立，
  按折数试时只有本组端点自己找到不差于当前折数的通畅路径才停。新增 7 条回归，

- 2026-10-27 **批注布点六条定稿**：删除段落阶梯，环数绝对第一（近环截断先于远环整句）；
  同环先整句再比折行；多行选区不再强制先末行，按环数 / 距离 / 折行 / 相互影响综合判断；
  满行左右页边距可用但排在四个角之后（方向名次已由下条取代：四个角 → 正右 → 正左 → 正上 → 正下）；

  短的放内侧」的综合安排，避免长批注挡住短批注的引线。

- 2026-11-01 **旁注字号基数改为读者字号口径（用户定口：设置必须真的说了算）**：此前基数取
