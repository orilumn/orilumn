## 0. 第四轮口径（2026-10-23 深夜，现行，覆盖旧表述）

> 用户原话：右边「同一行高度能放下，就放同一行；同一行放不下，考虑折行，批注垂直位置对准
> 正文行中间；折行也放不下，再考虑下面等等」。人类习惯放在**偏右侧或右下**，不行才用上面，
> 「用左侧那真的是不得已而为之」。箭头「没隔着字直接拉直线；隔了字，直线不可行，那应该优先
> 考虑弧线 / 贝塞尔曲线；再不行，考虑用三折线」。**箭头和引线的两头必须连接着批注和正文，
> 不能断开**；引线优先从批注文字朝向正文的那一头起笔。

### 0.1 布点：位置优先（不再用视线判据）

1. **右侧（第一优先）**：
   - 先试**锚点同一行高度、整句单行放下**；放得下就放在这一行右侧，框的垂直中心与该行中心对齐；
   - 单行放不下就**折行**：宽度取右侧可用宽，框的垂直中心仍对准该行中心；
   - 折行也放不下（或不足 4 个字）→ 交给下面的优先级，**不硬塞进行尾小缝**。
2. **下方（第二优先）**：同栏、紧贴锚点底边往下找，优先最近的一块；不得跨进别的文字块。
3. **上方（第三优先）**：只有下方被正文占满 / 没有可用空白才启用；不得顶到页边距与页眉。
4. **同栏其他空闲矩形（第四优先）**：按到锚点的欧氏距离取最近、放得下的一块。
5. **左侧（最后）**：左侧是「实在没地方」的退路，排在所有右侧 / 下方 / 上方 / 同栏候选之后。
6. 页边距与版心内空白**同权**；**右侧页边距本身就是第一级候选**（它紧贴锚点行）。
7. **取消视线遮挡判据**：不再判断候选与锚点之间有没有隔着别的文字；只按「同栏 + 位置 + 距离」。
8. **完整优先仍保留**：只要还有能放下整句的候选，就先整句显示；所有候选都放不下整句时，
   才允许截断（最少 4 个字），再没有才退右下角小图标。
9. 同页多条仍按「候选少 → 更近 → 正文靠前」**单向让位**，先挑者不被挤走，不做两两互换。
10. 排序键：**完整 → 位置层级 → 截断档内字多 → 右侧单行优先于折行 → 距离**。
    因此「下方能整句」压过「行尾只能读 4 字」，不会被小缝硬塞。

### 0.2 引线：直线 → 弧线 → 三折，两端必须接住

1. **直线**：框与锚点之间没有字 / 图 / 表 / 线遮挡时直接连直线。
2. **弧线 / 贝塞尔**：直线被字挡住时**优先弧线**，绕过遮挡；弧线两端仍落在框边与锚点字墨迹上。
3. **折线**：弧线也绕不开时才用折线；折数允许到 **三折（4 段）**，优先折数少的。
4. **两端必须接触**：起点在旁注框边界上，终点落在锚点字墨迹边界上，**中间不许留缝**。
5. **起笔端优先朝正文那一头**：批注在正文右侧时，从批注文字的**左侧（头部）**起笔；
   批注在正文左侧时，才用中间 / 尾部（右缘）连接。朝对方的边被挡时才换边。
6. **仍然必画**：除小图标形态外不返回空；所有路径都撞时取「穿得最少、再最短」的一条。

## 1. 用户意见（定稿，2026-10-23）

> 前三轮口径依次是「完整优先」→「折行就近」→「6 行阈值内完整就近」。本节保留第三轮用户意见
> 作历史记录；**现行口径是 §0**，与本节冲突处（例如视线判据、最多两折）一律以 §0 为准。
> 下面九条中仍有参考价值的是「整句优先」「4 字下限」「小图标兜底」「单向让位」。

1. **就近能折行放下，是第一优先级**：一块空白只要能通过折行把整句放下，就先看它离锚点近不近；
   不要因为另一块空白更宽、行数更少，就把旁注丢到更远的地方。
2. **「附近」改用视线判断，不再用行数当尺子**：从候选空白到锚点最近一行墨迹之间，
   视线不被别的文字、图、表格、线条挡住，就算附近。版面空就宽、版面挤就窄，不设固定半径，
   也不需要调参；**但不许为了整句完整穿过别的文字跑到远处**（例如隔着几段正文的页脚）。
3. **附近没有足够空白就最大化显示**：仍用折行争取显示最多字；只有选中的这块仍放不下整句，
   才在末尾加省略号。**截断不是优先级，只是兜底。**
4. **最少可读量只有一条线：4 个字**。能显示 4 个字就显示框（一行也可以）；
   旧的「不足一整行就不显示」与折行能显示的逻辑相反，删除。
5. **实在放不下就退回小图标**：附近没有任何候选、或所有候选都显示不到 4 个字时，
   在原文高亮 / 划线墨迹的**右下角**画一个小小的椭圆，内含省略号；点它打开这条批注。
   这个形态**不画箭头**，也不参与其他旁注的避让。
6. **箭头必须画**：唯一例外是第 5 条的小图标。折数放宽为**最多两折（3 段）**，
   不再是先前的「最多一折」。避让仍用逐字墨迹，可穿两字之间与标点前后的空白。
7. **两条批注抢位置，单向让位**：谁候选最少谁先挑；一样少比谁离空白更近；一样近比正文流里
   靠前（文档顺序）。先挑的拿走自己最近的位置，后来者不许挤走；**永远不做两两互换**，
   不会出现两条一起挪。同一份内容结果恒定。
8. **一切尺寸用排版真实算出的几何**：空白、距离、遮挡都用真实行框与字框，不按字号乘倍率估算；
   行高只用于旁注自己排自己的行。
9. **距离按最近一行量**：旁注框到对应文字**最近那一行**的边到边距离；多行锚点逐行取最近，
   不用整段并集。

这九条同时取代第一轮文档里的「完整优先 → 同级就近」「正交可见图 + A*」。

## 2. 新口径

### 2.1 布点（旁注框）

**候选生成**：整页极大空闲矩形（MaxRects，含四边页边距）+ 逐条折行模拟。
每条批注、每块空白生成一个候选，候选宽度取 `min(整句单行宽, 空白宽)`，高度按折行后的行数定。

**「附近」用视线判断，不设半径**（2026-10-23 第三次修正，`NOTE_NEAR_MAX_LINES` 取消）：

- **判据**：从候选框最近点到锚点**最近一行墨迹**的直线段，若穿过别的文字行框、图形、表格或线条，
  这块空白就不算锚点附近，不参与排序与分配。
- **与锚点墨迹相交的行框要先剔除**（锚点自己所在那一行不能挡住视线），与箭头避让同一处理。
- **行为**：段落下面紧接着的大片空白视线通畅 ⇒ 算附近，整句放得下就完整显示；页脚隔着别的段落 ⇒
  视线被挡 ⇒ 不参与；页边距紧贴锚点行 ⇒ 参与，锚点上方几行的页边距则被中间几行字挡住。
  版面空「附近」就宽，版面挤就窄，**没有需要实机标定的常数**。
- **距离口径**：旁注框到锚点**最近一行墨迹**的边到边距离；多行锚点多行分别量、取最近，
  **不用整段并集**。距离只用于排序，不参与「算不算附近」的判断。
- 页边距与版心内空白同等，不再给页边距或行数加惩罚。

**附近之内排一条主线**：

- **第一优先：能折行放下整句的，取最近的**。按距离升序；距离相同再比行数、版心内、上/左、id。
  **不因为另一块更宽、行数更少而改去更远的那块。**
- **没有完整候选，才最大化显示**：按折行后的显示字数降序，同字数取距离近的，再比行数、上/左、id。
  省略号只在选中的这块仍放不下整句时出现。
- **最少可读量只有 4 个字**：显示 ≥ 4 个字就显示框（只有一行也可以，整句不足 4 字时按整句）；
  「不足一整行就不显示」删除。

**实在放不下：退回小图标**（取代旧的「不显示」）：

- 附近一个候选都没有，或所有候选都显示不到 4 个字时，在原文高亮 / 划线墨迹的**右下角**
  （外侧，不压字）画一个小小的椭圆，内含省略号；点它打开这条批注。
- 该形态**不画箭头**、不参与其他旁注的避让，也不写回任何排版状态。
- 因为页边距通常紧贴锚点行、视线通畅，这个形态只在页面被字/图/线几乎填满时出现。

### 2.2 引线（箭头）

- **形态三种、最多两折**：直线（1 段）、一折（2 段）、两折（3 段，如横→竖→横）。
  **禁止三折及以上**；第一轮的可见图 / A* / 多折路由全部退出。
- **必须画**：唯一不画箭头的情况是框退回了 §2.1 的小图标形态。
  端口、直线与三种折线全撞障碍时，取「穿得最少、再最短」的一条照样画出来——
  宁可线上贴一点字边，也不能让读者不知道这条旁注指向哪里（这是本轮用户明确要求）。
- **避让对象**：文字的**逐字墨迹**、图形、表格框线、线条、其他旁注框；已画引线只作交叉惩罚
  （尽量不穿，不硬堵死）。块底色、`padding` / `margin`、页边距、行间空隙都算空白。
- **文字用逐字墨迹，不用行盒**：行盒把字间与标点周围的空白一起盖住了，箭头因此绕不出去。
  改成逐字墨迹后，线段只要不进入某个字的墨迹内部，就可以从**两字之间**、**标点前后**穿过。
- **自己的锚点墨迹不是障碍**：箭头就是要指到它；只把其他字的墨迹当障碍。
- **不设长度阈值**：框与字离得再远也要画。
- 箭头仍画在旁注框之下，颜色取所属标注的墨色。

```
输入：NoteInk[]（布点用锚点墨迹 + 箭头用锚点逐字墨迹 + 文字） + 四类障碍 + 页面/版心几何
  │
  ├─ A. 布点障碍：正文按行合并成行框（只用于放框，不用于箭头）
  │
  ├─ B. 空白：MaxRects 一次算出整页极大空闲矩形（含四边页边距）
  │
  ├─ C. 候选：每条批注 × 每块空白 → 视线遮挡检查 → 折行模拟 → 完整 / 未完整
  │      · 视线被别的字/图/表/线挡住 ⇒ 不算锚点附近，直接丢弃
  ├─ D. 分配：附近内完整按距离最近；没有完整才按显示字数最多；单向让位，不互换
  │      · 一条都排不下 → 原文右下角小省略号图标（无箭头）
  ├─ E. 引线：逐字墨迹 + 图形/表格/线条 → 直线 / 一折 / 两折端口搜索
```

## 4. 关键实现

### 4.1 布点障碍与空白

沿用第一轮：

- 正文按行合并成行框（`mergeTextLineRects`）：行内字间空隙不当作能放下一句批注的空白；
- 行框 + 图形 + 表格 + 线条作为 `maximalFreeRects` 的障碍；
- 页面边界含四个页边距，块底色 / `padding` / `margin` 不挡；
- 候选框互不重叠是硬约束。
- **布点与箭头用两份文字几何**：布点继续用行框（`pageInkRects` / `decorRects`），
  箭头改用逐字墨迹；`NoteInk` 增加一份箭头用的逐字矩形（默认回退到布点墨迹），
  两份都只读、都不参与排版。

### 4.2 候选、附近判定与完整性

沿用第一轮的折行模拟，排序与过滤按 §1 重写：

```text
inkRects = 锚点在本页的**逐行**墨迹矩形
blockers = 行框 + 图形 + 表格 + 线条，**剔除与锚点墨迹相交的矩形**（锚点自己那行不挡视线）

for each freeRect:
  width    = min(整句单行宽, freeRect.width)
  capacity = floor(freeRect.height / lineH)
  fit      = noteTextFit(text, width - padX, fontPx, capacity)
  rect     = 在 freeRect 内取离锚点最近处（以**最近一行**墨迹为基准，不用整段并集）
  ink      = 距离 rect 最近的那一行锚点墨迹
  distance = rectDistance(rect, ink)                 // 只用于排序
  if (视线 rect→ink 被 blockers 挡住) continue         // 不算附近
  complete = fit.shownChars >= fit.totalChars
  lines    = min(fit.lines, capacity)
```

淘汰规则只有三条：视线被挡、`capacity < 1`、显示不足 4 字（整句不足 4 字时按整句）。
**「不足一整行」不再淘汰**。

排序不再用加权 `cost`：完整候选键 = `(distance, lines, inContent, top, left, id)`；
未完整候选键 = `(-shownChars, distance, lines, top, left, id)`。旧的
`TRUNC_TIER` / `MARGIN_PENALTY_LINES` / `LINE_PENALTY_LINES` / `TRUNC_PENALTY_LINES`
一并删除，避免「页边距 / 行数」再次压过距离。

**没有任何候选时不再返回空**：交给 §2.1 的小图标形态（见 §4.3 的 `NoteBubble` 两种形态）。

> 视线判据用的是布点同一套行框 / 图形 / 表格 / 线条几何，都是排版真实算出来的；
> 不引入行高倍率估算，也不依赖段落 ID。段落下面的大片空白只要中间没有文字，
> 视线就通，自然被算作「附近」。
>
> 实现上「视线」取候选框最近点到最近一行墨迹最近点的线段，与障碍矩形做相交测试
> （贴边不算穿过，容差 `NOTE_GEOM_EPS`）。锚点自己的行框必须剔除，否则锚点所在整行
> 会把所有候选都挡掉。

### 4.3 单向让位分配

- 候选集只含视线通畅的空白；被挡的空白不参与，也不做「远处还有完整空白」的兜底；
- **优先级（先挑者胜，后来者只在自己的候选里找）**：
  1. 候选数少的先挑（最没得选）；
  2. 候选数相同，**候选里最近的那个更近**的先挑（框离空白更近，更该占这块）；
  3. 仍相同，正文流里靠前（文档顺序，即锚点位置）的先挑；
- **单向让位**：先挑的拿走自己最近的完整候选（没有完整则显示字数最多的），
  **后来者不得把它挤走**；后来者跳过冲突候选，在自己剩下的候选里按同一规则取最好的；
- **不做两两互换**：不存在「两条一起挪」，也不存在为了总距离更小而把某条推远；
- 页边距同侧仍按锚点纵序做前推 / 回推（`LANE_GAP`），只影响同一侧页边距里的框；
- 一条都分不到（或全被挡）⇒ 该条退回 §2.1 的**小图标**形态，不消失、不重叠、不压字。

### 4.4 箭头几何

#### 4.4.1 新增逐字墨迹只读几何

现状 `pageInkRects` 走 `decorRects`，每行只产出一个行框，无法知道字与字之间哪里有空隙。
需要在渲染层新增一个**只读**的逐字墨迹查询：

- 输入：行列表、章内字符区间、页面平移量、内容区原点；
- 输出：每个字符一个**紧贴墨迹**的页坐标矩形（不是 advance 盒）；
- 必须复用 `placementFor` / `glyphTrack` / `baselineY` 与字形 `getBounds`，保证与画出来的字同源；
- 空白字符、控制字符不产生矩形；量不到字形边界的字符退回 advance 盒（安全的一侧）；
- 只服务旁注箭头，不参与排版、不参与分页、不写回任何布局状态。

坐标口径与 `decorRects` 保持一致（内容区左缘 + 章内 Y − `readerPageShift`），
调用方直接把结果交给 `noteBubblePlacements` 的箭头阶段。

> 架构说明：这是渲染层提供的**只读几何**，与现有 `decorRects` / `pageImages` 同类；
> 用户层覆盖层只消费几何，不反向改排版，符合层级约束。

#### 4.4.2 端口搜索

对每条最终框：

1. **目标**：锚点在本页的逐字墨迹矩形，按到框的距离从近到远取前几个；
2. **候选端口**：
   - 旁注框四条边，每条边取中点、靠两端内缩点；
   - 目标字墨迹四条边，每条边取中点、靠两端内缩点；
3. **候选路径**（最多两折 = 3 段，禁止 3 折以上）：
   - 直线：端口对直接相连（1 段）；
   - 一折：`(start.x, end.y)` 或 `(end.x, start.y)` 一个拐点（2 段）；
   - 两折：`(start.x, midY) → (end.x, midY)`、`(midX, start.y) → (midX, end.y)` 等两种
     「横→竖→横 / 竖→横→竖」，拐点各取端口坐标或障碍边界坐标（3 段）；
   - 每条路径最多 4 个点、2 个拐点；
4. **判据**：线段不得进入任何障碍矩形内部；文字墨迹可按 0～0.5px 容差，图形/线条按 1px 容差；
   线段贴边不算穿过；
5. **择优**：先比是否穿过已画引线（少者优先），再比折数（直线优先），再比总长度，最后按
   端口顺序稳定排序；
6. **兜底：照样画**。所有端口与三种折线都不通时，在已试过的路径里取
   「穿过的障碍面积最小 → 最短」的一条画出来；**只有框退回小图标形态时才没有箭头**。

#### 4.4.3 箭头避让集合

- 逐字墨迹（排除自己的锚点字）；
- 图形、表格框线、线条；
- 其他旁注框（膨胀 1px）；
- 已画引线（只做交叉惩罚，不硬堵死）；
- 自己的旁注框不挡自己的箭头，但箭头不得穿回自己的框内。

#### 4.4.4 性能

逐字墨迹只对「旁注框 + 锚点墨迹」的并集向外扩一到两行高的范围计算，不扫全页；
同一页内按字符区间缓存一次，翻页 / 换版式即失效。单页几百个字的量级不需要再优化。

## 8. 风险与退路

| 风险 | 退路 |
|---|---|
| 逐字墨迹 API 与画字几何不一致 | 复用 `placementFor` / `glyphTrack` / `baselineY`，加「量画同源」单测 |
| 逐字墨迹太小 / 标点无墨迹 | 量不到就退回 advance 盒，宁可不穿也不压字 |
| 视线判据把锚点行自己算成障碍 | 剔除与锚点墨迹相交的行框；单测钉住「锚点行不挡自己」 |
| 视线判据太松，旁注仍显远 | 先看是否漏剔了锚点行框；判据本身不接受额外半径 |
| 两折仍绕不过 | 全撞时取穿得最少、最短的一条画出，**不退回「不画」** |
| 小图标太频繁 | 先查页边距候选是否被误判遮挡（页边距与版心内同权） |
| 小图标本身压字 | 固定在锚点墨迹右下角外侧，单测断言与锚点墨迹不相交 |
| 表格整体仍缺几何 | 维持现状：只按框线与单元格文字避让 |
