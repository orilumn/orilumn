## 1. 为什么重做

真机截图（1840×2800，book 39 / 第 2 章）上，四条批注全部被塞进正文的窄缝：

| 批注 | 文字 | 实际显示 |
|---|---|---|
| 112 | 用几章来 | `用几…` |
| 115 | 交换 | `…` |
| 116 | 用 val 声明 | `用 …` |
| 117 | 用 var 声明 | `用 …` |

而同一页的右侧页边距、页脚、段间空白其实都还空着。新口径的截图验收标准是：**四条都读出整句**
（允许页边距里折成多行），而不是「有没有显示」。根因不是「没找到空白」，是**模型错了**：

1. **优先级写反**：D-28 原文「就近优先，距离相当再完整显示」⇒ 紧贴锚点的 1 行窄缝
   （只能显示 1～2 个字）必然赢过稍远但能整句放下的页边距。
2. **空白是有损切分**：旧 `buildFreeRects` 每放一个障碍就把空闲矩形切成互不重叠的四块，
   切完不合并，大块空白会被前面的切分切碎，后面再也看不到。
3. **逐条贪心**：没有全页统一评分，也没有「互相换位」；先放的批注占掉好位置，后面的只能更差。
4. **箭头是 ad-hoc 三段式**：直线 → 折线 → 采样弧线，既不能保证绕开，也会出现贴字/穿框。

结论：换成图形学/布线领域的成熟模型，而不是继续给旧贪心打补丁。

## 2. 目标与非目标

**目标**

1. 批注**永远不出现只有省略号的框**；能整句显示就必须整句显示。
2. 整页统一布点：段间空白、块底色、行尾空地、页边距都是候选，用统一代价比较。
3. 同页多条批注不重叠；引线避开文字、图形、表格、线条与其他旁注/引线。
4. 输出稳定、可复现（同一页同一输入 ⇒ 同一结果），翻页/重组不闪烁。
5. 仍是**纯覆盖层**：不改 `Paginator`、不改分页表、不进栅格、不触发重排。

**非目标**

- 不做表格整体矩形的只读几何（引擎入口仍缺，登记在 D-29 前置；当前只按框线与单元格文字避让）。
- 不改批注输入/存库/清单（D-26 / D-27）。
- 不做批注样式设置（D-29）。
- 不引入第三方库（KMP/CMP 共享层要纯 Kotlin；libavoid 是 C++，只借算法）。

1. **完整可读优先**：整句放得下的候选，一律胜过只能显示一截的；
2. **同级就近**：同为完整（或同为截断）时，框到锚点墨迹的边到边距离越小越先；

> 不再使用采样弧线。

## 4. 选用的成熟算法

| 环节 | 算法 | 出处 / 理由 |
|---|---|---|
| 整页空白 | **MaxRects 极大空闲矩形** | Jylänki《A Thousand Ways to Pack the Bin》§2.2；维护极大矩形并剪掉被包含者，不会把大空白切碎 |
| 空白理论 | Maximal / largest empty rectangle | Naamad–Lee–Hsu、Orlowski；CGAL 的 `largest_empty_rectangle` |
| 候选与完整性 | 固定候选 + 完整度评分 | 外部标注综述（Nöllenburg et al. 2019）；技术插图标注论文的「整句 > 缩写 > 拆两段」优先级 |
| 页边距兜底 | **Boundary labeling + 一维排布** | Bekos et al. 2007；同侧标签按锚点纵序排开，天然不重叠、引线少交叉 |
| 内部/外部混合 | **Mixed labeling** | Cmolik et al. 2020：能放内部就内部，放不下转外部，统一消重叠 |
| 全页分配 | 最受限优先贪心 + 有界局部搜索 | 标注领域标准做法（冲突图 + 贪心/局部改进）；批注数量少，不需要模拟退火 |
| 引线路由 | **正交可见图 + A\***（Hanan 网格） | Wybrow/Marriott/Stuckey, GD'09；libavoid 同源，Inkscape 在用 |

## 5. 总体流水线

```
输入：NoteInk[]（锚点墨迹 + 文字） + NoteObstacles（文字/图形/表格/线条） + 页面/版心几何
  │
  ├─ A. 归一化：逐字墨迹 → 行框；障碍去重；页面边界
  │
  ├─ B. 空白：MaxRects 一次算出整页「极大空闲矩形」（含四边页边距）
  │
  ├─ C. 候选：每条批注 × 每个空闲矩形 → 一个候选框
  │      · 宽 = min(整句单行宽, 矩形宽)
  │      · 行数/完整度 = 逐字折行模拟
  │      · 位置 = 矩形内离锚点最近的角落，留 gap
  │      · 淘汰：完整度为 0、少于 4 个字、连一行都读不出
  │
  ├─ D. 全页分配：最受限优先贪心 + 两轮局部换位
  │      · 硬约束：候选框互不重叠
  │      · 代价：完整级 ≫ 页边距惩罚 > 距离 > 行数 > 截断程度
  │      · 页边距同侧再按锚点纵序做一维排布（前推 + 回推）
  │
  ├─ E. 引线：逐条正交可见图 + A*
  │      · 障碍 = 四类障碍 + 其他旁注 + 已画引线；自己的锚点行与自己的框除外
  │      · 代价 = 长度 + 拐弯惩罚 + 交叉惩罚
  │      · 无解 → 直线/单折线兜底 → 仍无解则只画旁注
  │
  └─ 输出：NoteBubble[]（位置、行数、颜色、箭头）
```

`noteBubblePlacements(...)` 的**签名保持不变**（`ReaderScreen` 调用点不动），只换内部实现。

## 6. 数据结构

```kotlin
// 文本折行模拟结果：比「宽/字宽」粗估准，用于完整性判定
internal data class NoteTextFit(
    val lines: Int,        // 整句需要几行
    val shownChars: Int,   // 给这么多行时最多能显示几个字（含换行）
    val totalChars: Int,
) {
    val complete: Boolean get() = shownChars >= totalChars
}

// 一个候选框
private data class NoteCandidate(
    val annotationId: Long,
    val rect: Rect,
    val lines: Int,
    val complete: Boolean,
    val shownFraction: Float,   // 截断时 = shownChars / totalChars
    val inContent: Boolean,     // 完全落在版心内
    val marginSide: MarginSide, // NONE / LEFT / RIGHT / TOP / BOTTOM
    val distance: Float,        // 框到锚点墨迹的边到边最短距离
    val cost: Float,
) {
    fun conflicts(other: NoteCandidate): Boolean = rect.overlaps(other.rect.inflate(2f))
}

private enum class MarginSide { NONE, LEFT, RIGHT, TOP, BOTTOM }
```

`NoteArrow.Arc` 删除（见 §9），`Elbow` 继续表示任意折线。

## 7. 各阶段实现细节

### A. 几何归一化

- `mergeTextLineRects(obstacles.textInk, small)` 不变：逐字墨迹按行合并成行框，词间空隙一并盖住。
- 障碍列表 = 行框 + `figures` + `tables` + `strokes`，按四边取整去重（避免同一障碍重复切分）。
- 页面边界 = `Rect(0, 0, max(contentRight, pageRight), max(contentBottom, pageBottom))`。
- 所有几何都是**页坐标**；调用方已完成 `readerPageShift`，这里不再平移。

### B. MaxRects 极大空闲矩形

```kotlin
internal fun maximalFreeRects(
    bounds: Rect,
    obstacles: List<Rect>,
    minW: Float,
    minH: Float,
    maxRects: Int = 3000,
): List<Rect>
```

对每个障碍 `o`，把每个相交的空闲矩形 `f` 替换为（标准 MaxRects 四切：左右整高、上下整宽）：

```
左：  (f.left, f.top, min(o.left, f.right), f.bottom)          若 o.left > f.left
右：  (max(o.right, f.left), f.top, f.right, f.bottom)         若 o.right < f.right
上：  (f.left, f.top, f.right, min(o.top, f.bottom))           若 o.top > f.top
下：  (f.left, max(o.bottom, f.top), f.right, f.bottom)        若 o.bottom < f.bottom
```

然后**剪掉被其他矩形包含的矩形**（`a` 被 `b` 包含 ⇔ `b` 四边都不比 `a` 紧），
按 `(top,left,right,bottom)` 排序，用 0.5px 容差去重。

- 关键差别：四切得到的是**极大矩形**，不是互斥划分；后续障碍不会再让「跨过旧切口的空白」消失。
- `minW = max(small * 1.2f, 1f)`、`minH = lineH` 先粗筛；候选阶段还有更严的可用性淘汰。
- 复杂度：行框约 30–80 个，空闲矩形剪枝后通常 < 500；超 `maxRects` 时按面积保留前 N 个
  （只会影响极端页面，不影响正确性）。
- 单测：构造两个错位障碍，断言结果里存在一个**同时跨过两者切口**的大矩形，
  且任意两个空闲矩形不存在包含关系。

### C. 候选生成

对每条批注、每个空闲矩形 `f`：

1. **宽度**：`ideal = estimatedNoteTextWidth(text, small) * 1.04f + padX`；
   `w = min(ideal, f.width)`。若 `w - padX < small * 2` 直接放弃（连两个字都放不下）。
2. **折行模拟**：
   - 逐字累加 `noteCharWidth`，超过可用宽就换行；`\n` 强制换行；
   - `needed = 行数`；
   - `capacity = floor(f.height / lineH)`；
   - `lines = min(needed, capacity)`；
   - 在 `lines` 行容量下重新统计 `shownChars`（整句 = `needed <= capacity`）。
3. **淘汰**：
   - `capacity < 1`；
   - 截断且 `shownChars < min(4, totalChars)`（只有「…」或一两个字的不算候选）；
   - 截断且可用宽不足一行（`w - padX < small * 3`）；
   - 完整候选无条件保留（哪怕距离远）。
4. **位置**（框在 `f` 内取离锚点最近处，再留 `gap`）：
   - 水平：`f.right <= anchor.left` ⇒ 右贴 `f.right - w`；`f.left >= anchor.right` ⇒ 左贴 `f.left`；
     否则以锚点中心居中后 clamp 到 `f`。
   - 垂直：`f.bottom <= anchor.top` ⇒ 下贴 `f.bottom - h`；`f.top >= anchor.bottom` ⇒ 上贴 `f.top`；
     否则以锚点中心居中后 clamp 到 `f`。
   - 再按贴边方向补 `gap`（右侧起排 `x = max(f.left, anchor.right + gap)`，下方起排
     `y = max(f.top, anchor.bottom + gap)`），最后 clamp 保证整框在 `f` 内。
5. **区域分类**：
   - `inContent = rect` 完全落在 `[contentLeft, contentRight] × [0, contentBottom]`；
   - 否则按贴边方向归入 `marginSide`（右/左/上/下），供一维排布使用。
6. **距离**：`inkRects.minOf { rectDistance(rect, it) }`（边到边，与旧口径一致）。
7. **代价**：
   ```
   cost = (if (complete) 0 else TRUNC_TIER)      // 完整级：截断永远排在完整之后
        + (if (inContent) 0 else MARGIN_PENALTY) // 页边距只是偏好，不是最后一名
        + distance
        + max(0, lines - 1) * LINE_PENALTY
        + (if (complete) 0 else (1 - shownFraction) * TRUNC_PENALTY)
   ```
   `TRUNC_TIER` 取 `1e6` 级别，保证完整候选绝对优先；其余权重见 §8。

同类候选按 `(cost, top, left)` 稳定排序；每条批注最多保留 `MAX_CANDIDATES_PER_NOTE = 300`
个（按代价取前 N，避免极端页面候选爆炸）。

### D. 全页分配

1. **最受限优先**：按候选数升序排列批注（候选少 = 受限制大），同数按锚点 `top`、`id`。
2. **贪心**：依次为每条批注选「与已放框不冲突」的最低代价候选。
3. **局部搜索**（最多 2 轮，确定性）：
   - 单条移动：移走当前框，若存在不与其他框冲突且代价更低的候选就换过去；
   - 成对交换（可选，批注 ≤ 8 时做）：两条互换候选，若总代价下降且都不冲突就交换；
   - 没有改进就提前结束。
4. **页边距一维排布**：把落在同一侧页边距的框按锚点中心 Y 升序排列，做两遍：
   - 前推：`y = max(目标 y, 上一个框底 + LANE_GAP)`；
   - 回推：`y = min(y, 下一个框顶 - LANE_GAP - 本框高)`，再 clamp 到页面；
   - 若仍放不下（极端密集），把最后一个框退回它的次优内部候选，再跑一次贪心；
     仍不行就放弃最远那条（不画框，但记录仍在清单里）。
   - 目标 y = `anchor.center.y - h/2`（框与锚点同高，引线最短且水平）。
5. **不重叠硬约束**：任何两个框（含 2px 间隙）都不得相交；框与四类障碍天然不相交（候选来自空闲矩形）。

### E. 引线路由

对最终框逐条路由（按锚点 `top`、`id` 顺序，先画先占）：

1. **端口**：
   - target = 离框最近的锚点墨迹矩形；
   - site = target 朝框一侧的边上的点（框在右 ⇒ `target.right`；框在下 ⇒ `target.bottom`，另一轴 clamp 到框中心）；
   - start = 框朝 target 一侧的边上的点（对称）；
   - end = site 朝框方向外移 `NOTE_ARROW_END_GAP_PX`（箭头尖不压字）。
2. **障碍**：
   - 四类障碍 + 其他旁注框 + 已画引线（膨胀 1px）；
   - **排除**与自己的锚点墨迹相交的障碍（即自己所在的行框），否则 site 永远在障碍内部；
   - **排除**自己的旁注框；
   - 块底色 / `padding` / `margin` / 页边距不挡。
3. **可见图**：
   - X 坐标 = 页面左右边 + 每个障碍左右边 + 自己框左右边 + start/end 的 x；
   - Y 坐标同理；
   - 相邻坐标之间连水平/垂直边；边中点在障碍内部（严格内部）则删掉；
   - 节点 = 网格交点；`start`、`end` 保证落在网格线上。
4. **A\***：
   - 状态 = `(节点, 进入方向)`，方向 `{水平, 垂直, 无}`；换向加 `BEND_PENALTY`；
   - 边代价 = 长度 + 穿越已画引线的 `CROSS_PENALTY`；
   - 启发式 = 到 `end` 的曼哈顿距离；
   - 节点数超过 `MAX_VISIBILITY_NODES = 60000` 时放弃图搜索，走兜底。
5. **收尾**：合并共线点、去掉零长段；2 个点 → `Straight`，≥3 个点 → `Elbow`；箭头尖沿用现有画法。
6. **兜底**：可见图无解 ⇒ 直线 → 单折线（先横后竖 / 先竖后横取短）→ 仍无解则不画箭头。
7. **交叉**：用轴对齐线段相交测试；已画引线作为软惩罚（不硬堵死），保证「尽量不交叉」。

## 8. 常量表（建议初值，可调）

| 常量 | 初值 | 含义 |
|---|---|---|
| `NOTE_BUBBLE_FONT_RATIO` | `0.72f` | 旁注字号 / 正文字号（沿用） |
| `NOTE_BUBBLE_LINE_RATIO` | `1.38f` | 旁注行高 / 旁注字号（沿用） |
| `NOTE_BUBBLE_PAD_RATIO` | `0.35f` | 单侧内缩 / 旁注字号（沿用） |
| `NOTE_ARROW_END_GAP_PX` | `2.5f` | 箭头尖离墨迹的距离（沿用） |
| `NOTE_GEOM_EPS` | `0.5f` | 几何容差（沿用） |
| `MARGIN_PENALTY` | `1.5f × lineH` | 页边距相对版心的偏好代价 |
| `LINE_PENALTY` | `0.35f × lineH` | 每多一行 |
| `TRUNC_PENALTY` | `4f × lineH` | 截断程度的附加代价（同属截断级内） |
| `TRUNC_TIER` | `1_000_000f` | 完整 > 截断的分界 |

## 11. 测试计划

### 11.1 必改用例（旧口径）

| 用例 | 旧断言 | 新断言 |
|---|---|---|
| `nearby one-line blank beats a far roomy one` | 近处截断赢 | **远处完整赢**（改名 `useless nearby sliver loses to complete margin note`） |
| `full line falls back to the gap below` | 行间放 1 行 | 优先整句；行间不够时去页边距/页脚，且完整 |
| `long note prefers the roomier blank at the same distance` | 下方大空白 | 保持，并断言 `lines >= needed` |
| `dense page still shows the note in the side margin` | 只要出现 | 断言完整显示（行数 ≥ 折行模拟值）、不压字 |
| `full page falls back to the side margin` | 至少 1 字 + 省略号 | 完整显示；若边距真的连 4 字都放不下则不显示 |
| 箭头弧线用例 | 期望 `Arc` | 删除；改为「可见图绕障」 |

### 11.2 新增用例

1. **MaxRects 极大性**：结果无包含关系；错位障碍下仍存在跨切口的大矩形。
2. **禁止省略号框**：满页 + 只有 1 字宽的缝 ⇒ 不显示（或去页边距完整显示），
   绝不出现 `shownChars < min(4, totalChars)` 的截断框。
3. **完整优先**：近处 2 字窄缝 vs 远处页边距完整 ⇒ 选页边距。
4. **同级就近**：两个完整候选（页边距 vs 版心内），距离近的赢（允许页边距小惩罚）。
5. **页边距排布**：同侧两条锚点相距 5px ⇒ 两个框不重叠，顺序与锚点 Y 一致。
6. **四批注回归**（平板同页）：4 条短批注全部完整、互不重叠、都落在页边距或大空白。
7. **引线**：空旷直线；L 形绕障；U 形绕障；完全封死 ⇒ 无箭头；不穿自己的框；不穿其他框。
8. **确定性**：同一输入调用两次，结果 `==`。
9. **不变性**：榜点墨迹不因旁注改变（纯函数只读输入）。
