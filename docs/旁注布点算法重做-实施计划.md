## 1. 用户新意见（本轮唯一依据）

1. **就近能折行放下，是第一优先级**：一块空白只要能通过折行把整句放下，就先看它离锚点近不近；
   不要因为另一块空白更宽、行数更少，就把旁注丢到更远的地方。
2. **只在「本段落 / 块附近」找**：给锚点设一个局部阈值（默认 6 行正文行高）；近处那块折行放不下整句，
   只在阈值内继续找最近的、能折行放下的空白，**不许为了完整跑到远处**。
3. **局部没有足够空白就最大化显示**：阈值内没有能放下整句的空白时，仍用折行争取显示最多字；
   只有选中的局部空白仍放不下整句，才在末尾加省略号。**截断不是优先级，只是局部兜底。**
4. **离得远也必须画箭头**：现在有些离得远的旁注没有箭头，读者不知道它指哪里；箭头不能因为
   距离远就被省略。
5. **箭头最多一次转折**：直线，或一个折角（先横后竖 / 先竖后横）就够了；引线要避开字、图、线等
   内容，但**可以穿过两个字之间，以及标点前后的空白**。

这五条优先于第一轮文档里的「完整优先 → 同级就近」和「正交可见图 + A*」。

## 2. 新口径

### 2.1 布点（旁注框）

**候选生成**：整页极大空闲矩形（MaxRects，含四边页边距）+ 逐条折行模拟。
每条批注、每块空白生成一个候选，候选宽度取 `min(整句单行宽, 空白宽)`，高度按折行后的行数定；
生成后**先按局部阈值过滤**，阈值外不参与排序与分配。

**先划局部边界，再在边界内排一条主线**：

- **局部阈值是硬边界**：以锚点墨迹的并集为基准，候选框到它的**边到边距离**超过
  `NOTE_NEAR_MAX_LINES × bodyLineH`（默认 6 行正文行高）就直接不参与。页边距与版心内空白同等，
  但都受这个边界约束；阈值外即使有能放下整句的空白，也不用。
- **边界内第一优先：能折行放下整句的，取最近的**。按框到锚点墨迹的边到边距离升序；
  距离相同再比行数、版心内、上/左、id。**不因为另一块更宽、行数更少而改去更远的那块。**
- **边界内没有完整候选，才最大化显示**：按折行后的显示字数降序，同字数取距离近的，
  再比行数、上/左、id。**这不是「截断优先级」**，只是局部兜底；省略号只在选中的这块
  仍放不下整句时出现。
- **最少可读量**：显示不足 4 个字（整句不足 4 字时按整句）或不足一整行，就不显示；
  绝不出现只有省略号的框。
- **不扩边界救完整**：局部放不下就局部最大化显示，绝不为了整句完整而跑到远处页边距或页脚。

### 2.2 引线（箭头）

- **形态只有两种**：直线（0 折）、单折线（1 折，三点，横→竖或竖→横）。
  **禁止两折及以上**；第一轮的可见图 / A* / 多折 `Elbow` 全部退出。
- **避让对象**：文字的**逐字墨迹**、图形、表格框线、线条、其他旁注框；已画引线只作交叉惩罚
  （尽量不穿，不硬堵死）。块底色、`padding` / `margin`、页边距、行间空隙都算空白。
- **文字用逐字墨迹，不用行盒**：行盒把字间与标点周围的空白一起盖住了，箭头因此绕不出去。
  改成逐字墨迹后，线段只要不进入某个字的墨迹内部，就可以从**两字之间**、**标点前后**穿过。
- **自己的锚点墨迹不是障碍**：箭头就是要指到它；只把其他字的墨迹当障碍。
- **已放下的旁注，箭头不设距离阈值**：布点已限制在锚点附近；这里说的是箭头长度——
  框与字离得再远也要画，只有所有端口、直线与两种单折线都撞上字/图/线时才不画
  （宁可少一条线，也不糊住正文）。
- 箭头仍画在旁注框之下，颜色取所属标注的墨色。

## 3. 流水线

```
输入：NoteInk[]（布点用锚点墨迹 + 箭头用锚点逐字墨迹 + 文字） + 四类障碍 + 页面/版心几何
  │
  ├─ A. 布点障碍：正文按行合并成行框（只用于放框，不用于箭头）
  │
  ├─ B. 空白：MaxRects 一次算出整页极大空闲矩形（含四边页边距）
  │
  ├─ C. 候选：每条批注 × **局部阈值内**的空白 → 折行模拟 → 完整 / 未完整
  │
  ├─ D. 分配：局部内完整按距离最近；没有完整才按显示字数最多；竞争只在本局部内换位
  │
  ├─ E. 引线：逐字墨迹 + 图形/表格/线条 → 直线 / 单折线端口搜索
  │      · 起点 / 终点在旁注框与锚点墨迹的四条边上选端口
  │      · 最多一个拐点；不穿墨迹；尽量不穿其他旁注与已画引线
  │
  └─ 输出：NoteBubble[]（位置、行数、颜色、箭头）
```

`noteBubblePlacements(...)` 仍是纯函数；调用方只多传一份「逐字墨迹」给箭头用。
布点、引线都不进分页、不进栅格、不触发重排。

## 4. 关键实现

### 4.1 布点障碍与空白

沿用第一轮：

- 正文按行合并成行框（`mergeTextLineRects`）：行内字间空隙不当作能放下一句批注的空白；
- 行框 + 图形 + 表格 + 线条作为 `maximalFreeRects` 的障碍；
- 页面边界含四个页边距，块底色 / `padding` / `margin` 不挡；
- 候选框互不重叠是硬约束。
- **布点与箭头用两份文字几何**：布点继续用行框（`pageInkRects` / `decorRects`），
  箭头改用逐字墨迹；`NoteInk` 增加一份箭头用的逐字矩形（默认回退到布点墨迹），
  两份都只读、都不参与排版。

### 4.2 候选与完整性

沿用第一轮的折行模拟，只改排序：

```text
anchor   = union(inkRects)
bodyLineH= 正文字号 × 行高倍率（DrawLine.fontSizePx × lineHeightRatio）
nearLimit= NOTE_NEAR_MAX_LINES * bodyLineH     // 默认 6 行

for each freeRect:
  width   = min(整句单行宽, freeRect.width)
  capacity= floor(freeRect.height / lineH)
  fit     = noteTextFit(text, width - padX, fontPx, capacity)
  rect    = 在 freeRect 内取离锚点最近处（现有逻辑）
  distance= min(rectDistance(rect, ink) for ink in inkRects)
  if (distance > nearLimit) continue          // 阈值外不生成候选
  complete= fit.shownChars >= fit.totalChars
  lines   = min(fit.lines, capacity)
```

淘汰规则：`distance > nearLimit`、`capacity < 1`、显示不足 4 字、显示不足一整行，
都直接不算候选。

排序不再用加权 `cost`：完整候选键 = `(distance, lines, inContent, top, left, id)`；
未完整候选键 = `(-shownChars, distance, lines, top, left, id)`。旧的
`TRUNC_TIER` / `MARGIN_PENALTY_LINES` / `LINE_PENALTY_LINES` / `TRUNC_PENALTY_LINES`
一并删除，避免「页边距 / 行数」再次压过距离。

`NOTE_NEAR_MAX_LINES` 是本轮唯一需要真机微调的常数，先取 **6**；它只改边界大小，
不改「完整就近 → 最大化显示」的排序。**阈值单位是正文行高**，不是旁注框自己的 `lineH`——
批注字号可变（D-29），拿旁注行高当尺子会让阈值跟着字号漂。`bodyLineH <= 0` 时按
`fontPx × 1.6` 估一个，不能把阈值算成 0。

> 这里用行高半径近似「本段落/块附近」，不依赖段落 ID 或块几何；将来引擎若直接给块矩形，
> 可以把半径换成块边界，排序规则不变。

### 4.3 局部内统一分配

- 候选集只含局部阈值内的空白；**阈值外不参与分配**，也不做「远处还有完整空白」的兜底；
- 先按「候选数升序」挑受限制最大的批注，再按锚点 `top`、id，保证可复现；
- 贪心：当前有完整候选时，选**不冲突且距离最近**的完整候选；一个完整候选都没有时，
  才按**显示字数最多**选；
- 两条批注争同一块近处空白时，允许做最多两轮局部换位：换位目标按字典序——
  **先让完整批注数最多，再让总距离最小**；任何会减少完整批注数的换位禁止；
- 页边距同侧仍按锚点纵序做前推 / 回推（`LANE_GAP`），只影响同一侧页边距里的框；
- 局部内实在放不下就不显示该条，**不扩阈值、不重叠、不压字**。

### 4.4 箭头几何

#### 4.4.1 新增逐字墨迹只读几何

现状 `pageInkRects` 走 `decorRects`，每行只产出一个行框，无法知道字与字之间哪里有空隙。
需要在渲染层新增一个**只读**的逐字墨迹查询：

- 输入：行列表、章内字符区间、页面平移量、内容区原点；
- 输出：每个字符一个**紧贴墨迹**的页坐标矩形（不是 advance 盒）；
- 必须复用 `placementFor` / `glyphTrack` / `baselineY` 与字形 `getBounds`，保证与画出来的字同源；
- 空白字符、控制字符不产生矩形；量不到字形边界的字符退回 advance 盒（安全的一侧）；
- 只服务旁注箭头，不参与排版、不参与分页、不写回任何布局状态。

坐标口径与 `decorRects` 保持一致（内容区左缘 + 章内 Y − `readerPageShift`），
调用方直接把结果交给 `noteBubblePlacements` 的箭头阶段。

> 架构说明：这是渲染层提供的**只读几何**，与现有 `decorRects` / `pageImages` 同类；
> 用户层覆盖层只消费几何，不反向改排版，符合层级约束。

#### 4.4.2 端口搜索

对每条最终框：

1. **目标**：锚点在本页的逐字墨迹矩形，按到框的距离从近到远取前几个；
2. **候选端口**：
   - 旁注框四条边，每条边取中点、靠两端内缩点；
   - 目标字墨迹四条边，每条边取中点、靠两端内缩点；
3. **候选路径**：
   - 直线：端口对直接相连；
   - 单折线：`(start.x, end.y)` 或 `(end.x, start.y)` 两种拐点；
   - 每条路径最多 3 个点、1 个拐点；
4. **判据**：线段不得进入任何障碍矩形内部；文字墨迹可按 0～0.5px 容差，图形/线条按 1px 容差；
   线段贴边不算穿过；
5. **择优**：先比是否穿过已画引线（少者优先），再比拐点数（直线优先），再比总长度，最后按
   端口顺序稳定排序；
6. **兜底**：所有端口对、直线与两种单折线都不通时，不画箭头（只在页面被完全封死时发生）。

#### 4.4.3 箭头避让集合

- 逐字墨迹（排除自己的锚点字）；
- 图形、表格框线、线条；
- 其他旁注框（膨胀 1px）；
- 已画引线（只做交叉惩罚，不硬堵死）；
- 自己的旁注框不挡自己的箭头，但箭头不得穿回自己的框内。

#### 4.4.4 性能

逐字墨迹只对「旁注框 + 锚点墨迹」的并集向外扩一到两行高的范围计算，不扫全页；
同一页内按字符区间缓存一次，翻页 / 换版式即失效。单页几百个字的量级不需要再优化。

## 6. 测试计划

### 6.1 布点

| 用例 | 断言 |
|---|---|
| 近处窄空白能折行放下 | 选近处，不选阈值内更宽的一行空白 |
| 阈值内远处完整 + 近处只能截断 | 选完整的（「能折行放下」是第一优先） |
| 阈值外完整 + 阈值内只能截断 | 选阈值内截断，**不许为完整远走** |
| 局部无完整候选 | 选局部显示字数最多的；至少 4 字 / 一整行；只有省略号则不显示 |
| 阈值边界 | 距离等于阈值算内，刚超出算外；不外扩 |
| 四条密集批注 | 都完整、不重叠、按锚点顺序 |
| 两条争同一块近处空白 | 输家去次近的局部完整；局部无完整才最大化显示 |
| 长批注（37+ 字） | 局部有高空白时折行完整；没有时局部最大化显示 + 省略号，不跳到远页脚 |
| 同锚点两条 | 页边距里上下排开，不重叠 |
| 确定性 | 同一输入两次结果完全相等 |
| 只读 | 输入墨迹 / 障碍列表不被改写 |

### 6.2 箭头

| 用例 | 断言 |
|---|---|
| 空旷 | 直线，2 点 |
| 单个障碍 | 单折，3 点，不穿障碍 |
| 两字之间 | 线段从字间空隙穿过，不进入任一字的墨迹 |
| 标点前后 | 从标点墨迹外的空白穿过 |
| 字的墨迹 | 不可穿过 |
| 页边距远旁注 | 必须有箭头；不允许因距离远返回 null |
| 其他旁注 / 自己的框 | 不穿其他框；不穿回自己的框 |
| 已画引线 | 优先选不交叉的路径；不能硬堵死 |
| 完全封死 | 才允许不画 |
| 折点数 | 所有结果 `points.size <= 3`，且相邻点共享 x 或 y |

## 8. 风险与退路

| 风险 | 退路 |
|---|---|
| 逐字墨迹 API 与画字几何不一致 | 复用 `placementFor` / `glyphTrack` / `baselineY`，加「量画同源」单测 |
| 逐字墨迹太小 / 标点无墨迹 | 量不到就退回 advance 盒，宁可不穿也不压字 |
| 单折线仍绕不过 | 端口全试；仍无解才不画；不做两折（用户口径优先） |
| 局部阈值太小，长批注总被截断 | 先按默认 6 行高真机看；不够再调大，但必须保持「不跳到远页脚」 |
| 局部阈值太大，旁注仍显远 | 调小；阈值是硬边界，不接受「为完整而远走」 |
| 局部没有完整空白 | 局部最大化显示 + 省略号；至少一整行，绝不只有省略号 |
| 表格整体仍缺几何 | 维持现状：只按框线与单元格文字避让 |
