# 正文修改：块级标记（规格）

> 读者改正文时，**段落长成什么样也要能在修改卡里看见、改得动**：二级标题显示成 `## 标题`，
> 引用显示成 `> 引用`，列表项显示成 `- 项`，代码块显示成围栏；读者删掉标记，这一段就变回普通段落。
> 标记一个字符都不进正文，进的是「这一块该是什么形态」，重放时按它换标签 / 加删包裹层。
>
> 关联：`文本标注与修订方案.md` §8（v3 正文修改）、`正文修改-行内标记语法.md`（行内那一层）。
> 本文不改坐标契约，只加「块形态」这一层显式覆盖。

## 0. 一句话

**卡片里一行 = 一块，行首那一个标记就是这一块的形态；没写标记 = 普通段落。**
提交时标记变成 `TextRevision.blockKinds`（每块一个短码）随修订落库，重放时改叶标签、
增删 `blockquote` / `ul` / `ol`。正文、坐标、`delta`、分页一处都不需要块标记。

## 1. 支持的标记

| 写法 | 落的元素 | 说明 |
|---|---|---|
| （不写） | `p` | 普通段落 |
| `# ` … `###### ` | `h1` … `h6` | 一到六级标题，`#` 后面必须跟空格 |
| `> ` | `p` 套 `blockquote` | `>` 后面空格可有可无 |
| `- ` `* ` `+ ` | `li` 套 `ul` | 三个写法等价（回显一律 `- `） |
| `1. ` `2) ` … | `li` 套 `ol` | 序号由排版自己数，回显一律 `1. ` |
| ` ``` ` | `pre` | 围栏内的行都是这一块的内容，原样不解析 |

**只认 markdown 有的块**：段落、一到六级标题、引用、无序 / 有序列表项、代码块。
表格行与整块图片**不进块形态这一层**（见 §1.1）：卡片另给格结构 / 占位，表格按「整表」改，
图片只能整张删除或保留。

### 1.1 表格与整块图片

| 写法 | 落的元素 | 说明 |
|---|---|---|
| `\| a \| b \|` | `tr > td` | 无合并格、格内无硬换行时的表格行（markdown 管道行） |
| `<tr><td rowspan="2">a</td>…</tr>` | `tr > td / th` | 有 `rowspan` / `colspan` 或格内有硬换行时的退路；只认 `tr` / `td` / `th` 与两个合并属性 |

- 表格行在章字符流里仍是**各格文字按序拼接**（没有格分隔符），卡片显示层额外加管道 / 标签，
  正文坐标一个都不变；
- **表头**：管道行写不出「哪一格是 `<th>`」，整行都是表头时仍按管道行显示，提交时按**来源行**
  把原表的表头补回（新行先按「行文字 + 格形状」对回旧行；删 / 加行后不会把后一行的表头
  套到前一行；读者在 HTML 行里写的 `<th>` 以卡片为准）；
  只有部分格是表头时才退回基本 HTML 行，`<th>` / `<td>` 各归各格；
- **表格结构和整表一起校验**：不管选中整张表还是其中连续几行，读者都可以
  - 改格子里的字（长度随意）；
  - **删整行 / 加整行、删整表 / 加整表**；
  - **每行增删格、改 `rowspan` / `colspan`**；
- **只选其中几行**：卡片只列碰到的那几行（扩到整行，不到整表），但删行 / 加行 / 改格数时，
  提交侧会把未选中的行一起拼回**整张表**，按网格自洽校验后再落一条整表修订；
- 放行判据只看**行列结构自洽**（`TableGrid`）：按 HTML 表格排布逐行落格，整张表能铺成一个
  矩形网格（不重叠、不空洞、`rowspan` 不越过末行）就允许。**0 行 = 删掉整张表**。
  文字怎么变、每格多长都不看；
- 选区夹着表格前后的段落、或卡片里混进非表格行时**不能改结构**，只能逐行改字；
  卡片会就地提示，正文不动；
- **整块图片**（正文里只有一个 `U+FFFC` 占位）只许**整张删除**（把占位删掉）或原样保留；
  换成任何文字都拒绝——那等于把图悄悄变成正文。行内图（段落里的 `<img>`）不算整块图片。

## 2. 卡片里的样子

- **一行一块**：输入区的物理行就是块（回车 = 另一块），与 markdown 的直觉一致；
- **块内换行**（书里的 `<br>`）就写 `<br>`：`上句<br>下句` 是一块里的两行，不是两块
  （回车仍然是「另一块」）。读者写什么、回显就是什么，不再把换行改写成行尾反斜杠；
  旧写法「行尾 `\` + 换行」是同一个意思的另一种写法，解析照旧认，但回显统一写成 `<br>`；
- **代码块靠围栏划界**：围栏内的行照抄，不转义、不解析行内标记；
- **行首长得像标记的文字要转义**：原文以 `# ` / `> ` / `- ` / `1. ` / ` ``` ` / `|` 开头时，
  序列化成 `\# ` / `\> ` / `\- ` / `\1. ` / `\|`（围栏的每个反引号各加一个 `\`），
  解析时去掉反斜杠，落进书里的仍是那几个字；
- **表格行整行显示**：简单表格写成 `| a | b |`，格内的 `|` 转义成 `\|`；有合并格或格内
  有硬换行时退回基本 HTML（`<tr><td rowspan="2">a</td>…</tr>`，格内换行写 `<br>`）。

## 3. 显示（选区 → 卡片）

- 每一块的**块首那一行**写出这一块**现在的**形态标记；普通段落不写标记（保持干净）；
- 每块的形态由引擎按**排版叶**给出（`textEditBlocks`）：标题 / 引用 / 列表 / 代码块 / 段落，
  拿不到排版叶（非盒式排版）就一个标记都不写；**审阅视图照给**——形态是元素的属性
  （`p` / `h1` / `li` / `pre`），与文字用的是哪把尺无关，排版叶也还是同一批；
- **不归 markdown 管的块**（`div` / 表格行这类叶）不写标记，也改不了它的形态；
  例外：这一叶自己就是白名单里的行内元素（书里 `span { display:block }` 之类）时，卡片按
  「整行包一层 `<span>`」把它写出来（只显示，见 `正文修改-行内标记语法.md` §3.9）；
- **表格与整块图片**另外带一份形状（§1.1）：表格行按格结构写成管道行 / 基本 HTML 行，
  整块图片显示 `U+FFFC` 占位；这两类在卡片里都**没有**块形态标记；
- **表格整行进卡**：选区只碰到某一格 / 某一行时，卡片区间（`textEditStart` / `textEditEnd`）
  只扩到**碰到的那几行的整行**——格偏移是按行文字算的，只给半行会错位；不扩到整张表，
  读者选两行就只列两行。删行 / 加行 / 改格数时，提交侧把未选中的行一起拼回整张表校验
  （卡片仍只显示选中的行）。整块图片不扩（只占一个字符）；
- **表格与表外文字一起选中**（拖选从段落跨进某几行）：卡片把两样都列出来——表格只列拖到的
  那几行、写成管道行，表格外的文字照原样带着；不会为了「表格是整表修订」把整张表塞进卡片、
  也不把表当普通文字。提交时按「表格那一段」切成前 / 中 / 后三段（§4）；
- **卡片里装着的字与卡片区间逐字对齐**：普通块只切**落在选区里的那一段**（段首 / 段尾在选区外时
  不多带），表格行整行进卡、区间跟着扩到整行。否则确定时会把多带进来的那几个字当成新写的字
  再插一遍——从一段话中间开始选时，正文就凭空多出一个字；
- **第一行从段落中间开始时不写标记**：读者看到的只有半截文字，承载不了「这一块该长成什么样」；
- 重开旧修改时按落库的**每行形态**回显（`editedBlocks`）；老修订没存过 ⇒ 一个标记都不写，
  行为与引入块标记之前一致。

## 4. 提交（卡片 → 修订）

- 卡片每行都带着**绝对**形态：`## ` ⇒ 二级标题；什么都没写 ⇒ 普通段落。
  **删掉标记就是把它变回段落**，这是块标记最主要的用法；
- **两处例外按「不改形态」提交**（空短码 = 引擎不动这一块）：
  1. 第一行从段落中间开始（半截文字）。读者在这一行写了块标记 ⇒ **拒绝**并就地提示
     「请从段首开始改」；
  2. 宿主给不出块信息（老宿主 / 非盒式排版）⇒ 整套按纯文本，绝不拿「没标记」
     去改结构；
- **与现在形态相同的块不写进修订**：卡片每行都带形态，不筛掉的话每一块都会白落一条
  「什么也没改」的修订，修订清单里全是空条目；
- 文字一个字没改、只改了标记 ⇒ 整段重写（不做公共前后缀裁剪），否则结构改动会被裁成零宽区间；
- **表格**：选区整段落在同一张表里时（整张表，或其中连续几行）按 §1.1 的**网格自洽**
  校验（可以增删行 / 列 / 合并格，0 行 = 删表），落一条**整表结构修订**：
  - 区间 = 整张表的字符区间，**不做公共前后缀裁剪**（行界不是普通文字，裁了会把表切碎）；
  - `text` = 各行文字**直接相接**（行与行之间没有段界字符）；行界由 `editedBlocks` 的
    `t…` 短码长度给出，首行短码用**大写 `T`** 标记「这是整表修订」；
  - 表内已有的逐行修订整段吸收（整表重写后它们不再有意义）；
  - 只选其中几行时，未选中的行原样拼回整张表再校验；新行先按「行文字 + 格形状」对回
    选中的旧行（删行不会被误当成改字），表头再按来源行补回；
  - 选区同时带着表格前后的文字时，一条修订装不下两种改法：卡片按「连续的那一段表格行」
    切成前 / 中 / 后三段，逐段规划（表格段仍走上面的整表校验，文字段走普通区间），
    任一段被拒则整单拒；全部通过后**一次落库、一次重排**；
  - 表格行被文字隔成几段、或一段表格行都不剩时切不了，就地提示、正文不动（删整张表请只选表格）；
- **整块图片**：这一段文字只能是原样的 `U+FFFC`（保留）或空串（整张删除）；
  其他任何写法都拒绝并提示「图片只能整张删除，不能改成文字」。

## 5. 落地（重放时怎么改树）

只对**内存副本**动手（磁盘上的原树一个字节都不动，与修订重放同一口径）：

1. **只动变了的叶**：目标形态与现在相同的块一个节点都不换；
2. **换叶标签**：`p` / `h1`…`h6` / `pre` / `li`，属性原样留着，只去掉 `id`
   （同一本书里 `id` 唯一，复制出两个就重复了）；
3. **包裹层只做一层**：引用一层 `blockquote`，列表一层 `ul` / `ol`，嵌套结构只改最近那一层；
4. **相邻同形态并进同一容器**：`> a` 与 `> b` 挨着就是一个 `blockquote`，不会排成两块带间隔的
   引用；中间夹了别的形态就断开（`> a`、`b`、`> c` ⇒ 引用、段落、引用）；
5. **属性沿用**：新包裹层沿用原包裹层的属性（`class` / `style` 是书的排版）；
6. **结构容器不拆**：`section` / `div` / 表格这类结构层只往下递归，不被摊平；
7. **`li` 不摊平**：`li > p` 这种多段列表项拆开会让兄弟段落丢掉缩进，所以只在它内部换标签；
8. **不归 markdown 管的块一律不动**：`div` / 表格行的叶就算提交里带了形态也跳过
   （它们没有对应的块标记，卡片也就不该改它们）。
9. **表格行按格重建**：目标格结构明确时，按目标格界把新文字分回各格；每格在原树里
   按「格内各块」重建——单块格走整格最小替换（保住节点与行内样式），多块格按实际修订
   逐块落。定不到位（跨格且格内多块）就不改，绝不错位写进邻格；
10. **整块图片删空即移除**：重放后这一叶没有文字（占位被删）就整叶去掉，
    后续叶的起点跟着回退；行内图不受影响（它跟着所在段落走）。
11. **拆出来的块连包装一起换**：叶住在一层纯包装里（`ul > li > p`、`dl > dd > p`）时，
   一段改成几块要换的是那层包装，一块一个列表项；只换叶的话新块会全塞进第一个 `li`，
   其余 `li` 被撤空（读者复报：补一行列表，剩下的项全变成普通段落）。多出来的项照第一个
   包装的样子造，去掉 `id`；包装里还装着别的东西（项目标签、脚注）时不复制，按老路走。
12. **整表结构修订整表重建**（`ChapterRevisionReplay.TableEdit`）：按首行短码的大写 `T` 认出，
   不按叶分段落字 ——
   - 0 行 ⇒ 整张 `table` 移除，后继叶起点回退；
   - 否则按 `t…` 短码切出每行文字，在原位建新的 `tr` / `td` / `th`：旧格属性按位置沿用
     （`class` / `style` 等），`id` 与旧合并属性不复制，`rowspan` / `colspan` 按新结构重写；
   - 旧行叶全部撤掉、新行叶按顺序插回叶表；后面的叶起点按实测长度平移
     （实测与落库 `delta` 的偏差仍由 `MeasuredDeltaFix` 修正）；
   - 行码与文字对不上、或不是同一张表的连续行 ⇒ **不猜**：保持原树、标记需要重算。
   - **审阅视图里按行级对照重建**（`TableReviewPlan`）：没改的行原样保留，删掉的行留在
     原处（红字 + 删除线），新加的行排在原位（绿字），只改了格里的字且行形状没变的
     旧行保留、格内就地插入新字（红删绿增）；行形状变了（增删格 / 改合并）则旧行整行
     标红、紧跟一条新行标绿。审阅空间因此比正常视图多出被删文字，修订表与重放必须用
     **同一份**行级计划。

## 6. 存储

复用 `text_revisions.styles` 那一列的 JSON，**不新增列、不迁移**：

| 键 | 含义 |
|---|---|
| `b` | 每块的形态短码，对齐**修订文字**按段界切开的块（`p` `h1`…`h6` `quote` `ul` `ol` `pre`；`""` = 不改） |
| `eb` | 输入区**每一行**的形态短码，对齐 `editedText` 的行；`-` = 这一行属于上一块（块内换行）；`t…` = 表格行（显示方式 + 各格「长度,表头,rowspan,colspan」）；**`T…`** = 表格**首行**，整条修订是「整表结构」（行数 / 格数可与原来不同） |

- 两个键都可选：老修订没有 = 没有块信息，行为与今天完全一致；
- `b` 随 `ChapterRevisionMap.contentRev` 的算法版本一起参与失效判定（规则一改，旧分页表按章作废）；
- 卡片里那几个标记字符**从不落库**：落库的是短码，正文里永不出现 `# ` / `> ` / 围栏。

## 7. 幂等与 no-op

- `显示 → 解析` 必须等价：块标记连同块内换行写出去、解析回来还是同一组块；
- 打开卡不动、直接确定 ⇒ 不落库、不重排（卡片原文逐字相同 + 结构相同）；
- 只改标记不改字 ⇒ 落一条修订，但**只有真的变了形态的块**带短码。

## 8. 明确不做

- 嵌套块（引用里再套列表、列表里再套引用）：只改最近的一层，更深的保持原样；
- 表格的**结构**修改只支持选区整段落在同一张表里（整张表，或其中连续几行）：选区还带着
  表格前后的段落时，表格那几行照常改结构、表外的文字照常改字，两段各自成立后**一起生效**
  （按段切开，见 §4），不把表当普通文字、也不为了「整表修订」把整张表塞进卡片；审阅视图里整表修订按
  「旧行 + 新行」就地对照（删掉的行 / 字标红、新写的标绿）。拖选整张表（或其中连续几行）再
  打开的是**改完的那张表**，不是「旧行 + 新行」的对照；再改一次仍按原书那张表重算，旧记录被
  吸收，只留一条最终记录。**点按只看改过的字**：点红字 / 绿字 = 再改这处，卡片带出改后的内容
  （审阅视图里按点到的行开行卡片，不框整张表）；点在表格其他区域（没改过的整行、行间空白）
  什么都不做——不框整表、不开卡片、也不翻页。普通阅读视图里正文就是改后的表、没有红绿字可认，
  点表上改动过的字一律打开整表卡片（带出改后的整张表，同样不框整表）。拖选其中一行时选区就停在那一行、不自动扩成整张表，
  卡片也只列这一行（改完的那张表里对应的行）；确定后把这一行拼回整张表再校验：删空这一行 =
  删掉这一行，改列数 / 合并方式仍按整张表铺格校验。删掉的行（红字）在新表里没有对应行，拖到 /
  点到它时按行开卡片、输入区是空白的（这一行的结果就是不存在），不框整张表；选中几行里夹着
  删掉的行时，卡片只列留下来的那几行。表格和表外文字一起选中时按段切开逐段落（见 §4），
  不把表当普通文字改；
- 水平线 / 定义列表 / 分隔线等 markdown 之外的块仍不碰；
- 块标记与行内标记混写进同一行的样式解析（行内标记仍只在块内容里生效，围栏内全字面）；
- 自动纠正（读者写 `#标题` 没有空格就是普通文字，不猜）；
- 富文本工具栏、撤销重做、导出修改（与行内那套一致的「不做」）。

## 9. 验收清单

| # | 用例 | 期望 |
|---|---|---|
| 1 | 选区是一整段 `<p>` | 卡里没有标记；写 `## ` 确定后是 `<h2>` |
| 2 | 选区是 `<h2>` 整段 | 卡里 `## 标题`；删掉 `## ` 确定后变回 `<p>` |
| 3 | 选区是 `<blockquote><p>a</p><p>b</p></blockquote>` | 卡里两行各带 `> `；只删一行的标记 ⇒ 那段移到引用外 |
| 4 | 选区是 `<ul><li>a</li><li>b</li></ul>` | 卡里 `- a` / `- b`；第二行改成 `1. b` ⇒ 列表在 b 处换成 `<ol>` |
| 5 | 选区里有一段 `<pre>` | 卡里是围栏 + 原样内容；删围栏 ⇒ 变普通段落 / 标题 |
| 6 | 选区跨段落（`p` + `h2` + `p`） | 三行各自带自己的标记，确定后形态不变 |
| 7 | 选区起点在段落中间 | 第一行没有标记；在这行写 `# ` ⇒ 拒绝并提示 |
| 8 | 选区里含 `div` / 表格行 | 那一行没有标记，改不了形态；编辑照常 |
| 9 | 原文以 `- ` 开头（普通段落） | 卡里是 `\- `；确定后书里仍是 `- ` |
| 10 | 打开旧修改（有 `editedBlocks`） | 标记按落库的每行形态回显；块内换行的续行并回上一块 |
| 11 | 打开老修订（没存过块信息） | 一个块标记都不写；确定后形态不变 |
| 12 | 打开卡 → 直接确定 | 不落库、不重排 |
| 13 | 同一段写 `> ` 的相邻两行 | 确定后是**一个** `blockquote`，不是两块带间隔的引用 |
| 14 | 引用里改中间一段为段落 | 引用在该处断开：`> a`、`b`、`> c` |
| 15 | 审阅视图（开书默认）里改一段的形态 | 标记照常回显、照常生效：`## ` 确定后变 `<h2>`，审阅痕迹与分页一起重算 |
| 16 | 选区只碰到表格某一格 / 某两行 | 卡片只扩到**碰到的那几行的整行**、显示成 `\| a \| b \|`；删行 / 加行 / 改格数时未选中的行原样拼回整张表，网格自洽即放行 |
| 17 | 整张表里某行的列数改得对不上 | 拒绝并提示「表格的行列对不上…」，卡片不关 |
| 18 | 有 `rowspan` / `colspan` 的表格 | 卡里是 `<tr><td rowspan="2">…` 基本标签；改字、改合并方式都允许（网格自洽即可） |
| 19 | 选区跨到整块图片 | 卡里是 `▯` 占位；删掉它 ⇒ 整张图删除，选区外文字照常改 |
| 20 | 把图片占位改成文字 | 拒绝并提示「图片只能整张删除，不能改成文字」 |
| 21 | 格内文字里本来有 `\|` | 卡里是 `\\\|`；确定后书里仍是 `\|` |
| 22 | 合并格表格行重开旧修改 | 按落库的 `t…` 短码回显成同一个 HTML 行 |
| 23 | 选区正好是一整张表，删掉一整行 | 允许；确定后那张表少一行，后面的正文跟着前移 |
| 24 | 整张表全删（输入区清空） | 允许；整张表移除，不留一张空表 |
| 25 | 拖选从段落跨进表格某几行 | 卡片同时列出那段文字与那几行 `\| a \| b \|`；两处都改，确定后两处一起生效、只重排一次 |
| 26 | 混合物卡片里表格行被文字隔成两段 / 一行表格都不剩 | 就地提示、正文不动（删整张表请只选表格） |
| 27 | 选中几行里夹着删掉的红字行 | 卡片只列留下来的那几行，行号连续 |
| 25 | 每行都加一列 | 允许；只要整张表还能铺成矩形网格 |
| 26 | 表格前后还带着段落时改行列 | 拒绝并提示「请只选中表格的整行（不夹别的段落）」，正文不动 |
| 27 | 表格里已有逐行修订，再改整表 | 旧修订整段吸收，修订清单只留新的整表修订 |
| 28 | 整表修订重开卡片 | 按 `T…` 首码认回整表，行 / 格原样回显，仍可继续增删行 |
| 29 | 只选中一行，删掉这一行 | 允许；那一行从整张表移除，其余行原样保留，整表仍按网格校验 |
| 30 | 审阅视图里拖选改过的整表 | 卡片带出**改完的那张表**（不是旧行 + 新行的对照），清空一行只删那一行，其余行与格内样式都在 |
| 31 | 原书 `a` 改成 `b`，再点 `b` 改成 `c` | 卡片带出 `b`；确认后仍只有一条记录（`a` → `c`），正文显示 `c` |
| 32 | 选中「改过的 `b` + 后面的 `X`」改成 `cY` | 卡片带出 `bX`（当前结果）；确认后旧记录被新记录吸收，最终正文是 `cY` |
| 33 | 在改过的段里只改其中一处（吸收了两端公共字） | 重开卡片带出整段改后文字，不把没显示出来的前后文丢掉 |
| 34 | 审阅视图里拖选改过的表格中的一行 | 松手后选区停在那一行，不自动扩成整张表；卡片只列这一行（改完的那张表里对应的行），确定后只改这一行，其余行原样保留，仍是一条整表记录 |
| 35 | 审阅视图里把行范围卡片删空 / 给这一行多加一格 | 删空 = 只删掉这一行（表还在）；多加一格整表铺不成矩形 ⇒ 拒绝，卡片不关、正文不动 |
| 36 | 审阅视图里点按改过的表格 | 点红字 / 绿字 ⇒ 进入修订状态、卡片带出改后的内容（按点到的行开行卡片，不框整张表）；点没改过的整行或行间空白 ⇒ 什么都不发生（不框整表、不开卡、不翻页切栏） |
| 37 | 普通阅读视图里点按改过的表格 | 点表上改动过的字 ⇒ 打开整表修改卡、带出改后的整张表（不框整表）；没改动过的表格不在此列 |
| 38 | 审阅视图里改过标题后面的零散文字，再把整个标题重选 | 卡片带出这一整段的当前结果（那一段的字都在，段内换行仍是同一行里的 `<br>`）；直接确定不改正文 |
