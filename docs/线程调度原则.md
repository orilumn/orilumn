# 线程调度原则（记录在案）

状态：已通过原则审查（2026-09-25）。排版层（上）所有；触发在用户层（脏标记/参数），渲染层不动；
KMP：commonMain，平台相关仅 `cpuCount()` 一个 expect/actual。其余全共享。

## 0. 为什么需要调度器

现状是五个包工头各干各的（`tempPrefillJob` / `windowPrefillJob` / `canonicalJobs` / `wholeBookJob` /
`openPreflightJob`），外加四套去重代际（epoch/dedup key/quiet 门/park）。文档写着优先级，
没有代码执行——dispatcher 碰运气（canonical 单线程是 FIFO 不是优先级，background 是大锅饭）。
R18 整出来的取消/恢复/park 全是在给“没有调度”擦屁股。本原则用一个中央调度收编全部。

## 1. 任务模型

- 任务三要素：`kind`（见 §2）+ `chapter` + `paramHash` + `dirtyGen`（代际，§5）。
- 两种粒度：
  - PAGE：单页塑形/组装（增量单页；可取消点在页间与块间检查点 P7）。
  - CHAPTER-FULL：整章全量（`fullLayout` 整块，不可再分——P13 并行 chunk 已删，见 §7）。
- 翻页是同步最高优，**不进队列**：调用方线程直排，miss 即塑，只读状态表 fast-path。
  调度器只管后台活。延迟不可控的活不许上翻页关键路径。

## 2. 优先级（高→低）

1. **第一：下页**——落点即时派发。
2. **第二：上页恒覆盖**——即使上页在前章（此时前章整章提到第二优先级；S7 的跨章跳过作废）。
   为 1 页尾页排整章 acceptance（后台、可取消）。
3. **第三：其余页按 |页距| 交错**（方向破平；仅限有表章，无表章由整章任务覆盖，见下）。
4. **第四：本章全量**（B1 语义）。
5. **其后整章**：按章距算法（现行 R7 交错序）。
- 第一/第二是落点**即时派发**，第三及之后是**空闲 drain**——同一距离序，两种急迫度。
- 饥饿策略：低优任务可被无限推迟（翻页有增量兜底，正确性永不依赖后台）。不加 aging。

## 3. 状态表（两张，-pal temp 独立）

- **增量页级表**（当章，页→状态）：`UNLAID / SHAPING / DONE` + `paramHash`。
  R17 的 `pageCache` 即 DONE 存储，转正另加在途态。与 temp 表**单搞不合并**
  （整块页 vs 行锚页，边界对不上，合了指针全乱；temp 沿用现有 prefill，收敛待定）。
- **全量章级表**（全书，章→状态）：`UNLAID / SHAPING / FULL` + `paramHash` + `dirtyGen`。
  现状是散的（各 unit 的表+hash、磁盘文件），调度器第一次收成中央表。
  B2 的 skip-fresh 即查此表（磁盘表即 done 登记）。
- 脏标记只置位不干活：事件（改参/视口/字体/跨章）→ 对应表项 `dirty=true, dirtyGen++`；
  worker 开工快照 gen，完工只清“gen 未变”的，变了就地重排（ABA 必备，非可选）。

## 4. 调度循环

- worker 槽数 = `max(1, cpuCount() - 2)`（给 UI/翻页/系统留空；`cpuCount()` expect/actual）。
  work-conserving：有空槽即取最高优就绪任务。
- 抢占：高优到达取消低优（任务幂等，状态表驱动重启；检查点复用 P7）。
  翻页入口调 `notifyFlip()`：统杀 sub-F 后台活（R18 的散装取消收成这一个钩子）。
- 第三优先级的表前提：无表章的页任务永不就绪（pending 不派发），由第四/后整章任务覆盖。
- 小章（≤120 块）永恒全量，不进增量表（沿用既有阈值）。

## 5. P13 并行 chunk 删除决定

大章全量并行意义不大：全量活没人等（后台 best-effort），并行省的总时长换来抢核/发热/GC，
全打在前台体感上；handoff 时机账也算不过（稳定的中等 temp 翻 > 抖动的翻页+早几秒免费）。
删 `fullLayoutChunked` 整条路径，全量一律串行；`ChunkedCanonicalEquivalenceProbeTest` 同步删除。
附带：嵌套并行审计问题随之消失——调度槽是唯一的并行度来源。

## 6. 与现有机制的收编映射

| 现货 | 收编去向 |
|---|---|
| `tempPrefillJob`（temp 预塑） | 不动（temp 独立，§3） |
| `windowPrefillJob` + delay/dedup | 第一/第二优先级 PAGE 任务 + 代际 |
| `canonicalJobs` 按章槽 | 第四优先级 CHAPTER-FULL 任务（单章去重保留语义） |
| `wholeBookJob` + epoch/park/quiet 门 | 第五及之后 + 代际；quiet 门删除（抢占代替等待） |
| `openPreflightJob`（解析预热） | P 解析任务（最低，仅解析+轻备） |
| `layoutEpoch/lastWholeBookEpoch/b2Yielded/lastWindowPrefillKey` | 代际计数器 + 状态表（删除散装变量） |
| R18 翻页杀后台 | `notifyFlip()` 一个钩子 |
